# 07 · Servicio `media` — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recibir archivos en las salas que lo permiten, solo de los 9 formatos de la lista blanca (PNG, JPEG, GIF, MP3, WAV, MP4, PDF, DOCX y TXT), y procesarlos así:
1. detectar el formato por su firma y validar integridad y tope de su categoría (R9);
2. escanear con ClamAV (R9);
3. analizar con el analizador de su formato: estegoanálisis estadístico (chi² y RS en PNG, SPA en WAV), estructura (datos anexados, metadatos, segmentos desconocidos o no referenciados) y contenido activo en documentos (R6, R9);
4. aplicar la política: rechazo si es inválido, malicioso o tiene contenido activo; cuarentena si es sospechoso; sanitización (CDR), **reanálisis estructural de la versión sanitizada** (RS-36) y publicación en la sala si está limpio.

Las descargas exigen URL firmada y pertenencia a la sala, y siempre se sirven como adjunto (R12). El admin revisa la cuarentena.

**Architecture:**
- `formats/` es el punto de extensión. `base.py` define el contrato `Format(mime, ext, category, detect, validate, analyze, sanitize)` y el veredicto. Cada formato vive en su módulo (`png.py`, `mp3.py`, …) y `formats/__init__.py` arma el registro `FORMATS`, cuyo orden es el de detección (TXT al final, porque no tiene firma).
- `stego.py` contiene los estadísticos: chi², RS y entropía para imágenes; SPA para audio. `ffmpeg.py` envuelve ffprobe y ffmpeg endurecidos (MP3 y MP4).
- `clamav.py` es un cliente INSTREAM con la stdlib.
- `pipeline.py` orquesta: todo lo que parsea bytes no confiables corre en un `ProcessPoolExecutor` con timeout, se reconocen por `clean_sha256` las salidas propias y se publica en `chat`.
- `routes.py` contiene la subida y la descarga; `admin.py`, la cuarentena.

**Tech Stack:** Python 3.13, FastAPI, Pillow, numpy, scipy, pikepdf, lxml, mutagen, ffmpeg/ffprobe (paquete del sistema), asyncio, SQLAlchemy async, ClamAV 1.4, pytest.

**Spec:** `docs/specs/2026-10-12-chat-seguro-design.md` §7.4, §8, §9.6–§9.8, §12, §16.4 (R5, R6, R9, R11, R12, R16).

> **Revisión 3 (2026-10-19).** De 2 formatos de imagen se pasa a la lista blanca de 9 formatos (spec §12.1). `formats.py`, `png.py` y `jpeg.py` pasan al paquete `media_svc/formats/` (MED-2), y cada familia nueva tiene su tarea: GIF (MED-6), audio (MED-7), video (MED-8), documentos (MED-9) y texto (MED-10). > **Revisión 4 (2026-10-20, spec rev. 4).** Toda versión sanitizada pasa por una **segunda inspección** antes de publicarse, al subir (MED-4) y al liberar desde la cuarentena (MED-5): se vuelve a validar y se aplican las reglas estructurales de su formato con `cfg["statistical"] = False`, porque la sanitización de PNG y WAV aleatoriza el LSB a propósito y los estadísticos la marcarían siempre (RS-36). Si ya ejecutaste la rev. 3, reemplaza esos archivos y sus pruebas, y corre `pytest services/media`.

## Global Constraints

Las del índice (`2026-10-13-00-indice.md`). En particular:
- Solo los 9 formatos de la lista blanca, detectados por firma: la extensión y el `Content-Type` del cliente se ignoran.
- Subida ≤ 25 MB. Tope por categoría: imagen 5 MB, audio 10 MB, video 25 MB, documento 10 MB y texto 1 MB. Imagen ≤ 20 MP; GIF ≤ 300 cuadros.
- ClamAV falla cerrado (503).
- Contenido activo (macros, JavaScript, adjuntos, OLE, relaciones externas) → rechazo, nunca cuarentena.
- Todo archivo publicado pasó por la sanitización y por el reanálisis estructural de la versión sanitizada, y toda descarga va con `Content-Disposition: attachment`.
- Ninguna función con complejidad ciclomática mayor que 10 (ruff `C901`, RNF-11).
- Descargas solo con firma HMAC válida, de la misma sesión y de la misma sala.
- ffmpeg y ffprobe solo a través de `media_svc.ffmpeg` (demuxer forzado, `-protocol_whitelist file`, sin shell, con timeout).
- `text()` con parámetros nombrados.
- Commits en español, sin atribución.

"""Servicio media (spec §9.6–§9.8)."""

from collections.abc import Awaitable, Callable

import httpx
from fastapi import FastAPI
from sqlalchemy.ext.asyncio import AsyncEngine, create_async_engine

from media_svc import admin, routes
from media_svc.config import Settings, load_settings
from shared.audit_client import AuditClient
from shared.service_auth import ServiceAuth, ServiceClient
from shared.web import create_base_app

Scanner = Callable[[bytes], Awaitable[str | None]]


def create_app(
    settings: Settings | None = None,
    *,
    engine: AsyncEngine | None = None,
    service_auth: ServiceAuth | None = None,
    transport: httpx.AsyncBaseTransport | None = None,
    scanner: Scanner | None = None,
) -> FastAPI:
    settings = settings or load_settings()
    service_auth = service_auth or ServiceAuth.from_secrets("media", needs_token=True)
    peers = ServiceClient(
        service_auth, {"audit": settings.audit_url, "chat": settings.chat_url}, transport
    )
    app = create_base_app(
        title="media",
        settings=settings,
        engine=engine or create_async_engine(settings.database_url, pool_pre_ping=True),
        service_auth=service_auth,
        audit=AuditClient(peers),
    )
    app.state.peers = peers
    app.state.scanner = scanner  # MED-3 pone ClamAV por defecto
    for module in (routes, admin):
        app.include_router(module.router)
    return app
```

"""Estadísticos de estegoanálisis LSB (spec §12.4, §12.5). Funciones puras sobre arrays numpy:
chi², RS y entropía para imágenes; SPA y entropía 1D para audio."""

import math

import numpy as np
from scipy.stats import chi2

MASK = np.array([0, 1, 1, 0], dtype=bool)


def finite(value: float) -> float | None:
    """jsonb no admite NaN ni infinitos: se guardan como null."""
    value = float(value)
    return value if math.isfinite(value) else None


def chi2_pvalue(values: np.ndarray) -> float:
    """Ataque chi² de Westfeld–Pfitzmann: p ≈ 1 si los pares (2k, 2k+1) están igualados."""
    hist = np.bincount(values.ravel(), minlength=256).astype(np.float64)
    even, odd = hist[0::2], hist[1::2]
    expected = (even + odd) / 2
    mask = expected > 4
    dof = int(mask.sum()) - 1
    if dof < 1:
        return 0.0
    statistic = float((((even - expected) ** 2)[mask] / expected[mask]).sum())
    return float(chi2.sf(statistic, dof))


def chi2_scan(pixels: np.ndarray, min_pixels: int = 1000) -> float:
    """Máximo p sobre prefijos de 10/25/50/100 % por canal (el embedding secuencial deja el prefijo con p ≈ 1)."""
    flat = pixels.reshape(-1, pixels.shape[-1]) if pixels.ndim == 3 else pixels.reshape(-1, 1)
    best = 0.0
    for fraction in (0.1, 0.25, 0.5, 1.0):
        count = int(len(flat) * fraction)
        if count < min_pixels and fraction < 1.0:
            continue
        for channel in range(flat.shape[1]):
            best = max(best, chi2_pvalue(flat[:count, channel]))
    return best


def _groups(channel: np.ndarray) -> np.ndarray:
    """Bloques 2×2 aplanados en zigzag: (0,0) (0,1) (1,1) (1,0)."""
    h, w = channel.shape[0] // 2 * 2, channel.shape[1] // 2 * 2
    blocks = channel[:h, :w].astype(np.int16).reshape(h // 2, 2, w // 2, 2).transpose(0, 2, 1, 3)
    return blocks.reshape(-1, 4)[:, [0, 1, 3, 2]]


def _variation(groups: np.ndarray) -> np.ndarray:
    return np.abs(np.diff(groups, axis=1)).sum(axis=1)


def _rs_counts(groups: np.ndarray) -> tuple[float, float, float, float]:
    base = _variation(groups)
    positive, negative = groups.copy(), groups.copy()
    positive[:, MASK] = positive[:, MASK] ^ 1  # F1: 0↔1, 2↔3, …
    negative[:, MASK] = ((negative[:, MASK] + 1) ^ 1) - 1  # F−1: −1↔0, 1↔2, …
    fp, fn = _variation(positive), _variation(negative)
    return (fp > base).mean(), (fp < base).mean(), (fn > base).mean(), (fn < base).mean()


def rs_estimate(channel: np.ndarray) -> float:
    """Análisis RS (Fridrich, Goljan, Du 2001): tasa de embedding estimada p̂ en [0, 1].

    Degenera cerca del 100 % de embedding; ahí lo cubre el chi².
    """
    groups = _groups(channel)
    if len(groups) == 0:
        return 0.0
    rm, sm, rnm, snm = _rs_counts(groups)
    r1, s1, rn1, sn1 = _rs_counts(groups ^ 1)
    d0, d1, dn0, dn1 = rm - sm, r1 - s1, rnm - snm, rn1 - sn1
    a, b, c = 2 * (d1 + d0), dn0 - dn1 - d1 - 3 * d0, d0 - dn0
    if abs(a) < 1e-12:
        if abs(b) < 1e-12:
            return 0.0
        x = -c / b
    else:
        discriminant = b * b - 4 * a * c
        if discriminant < 0:
            return 0.0
        roots = ((-b + math.sqrt(discriminant)) / (2 * a), (-b - math.sqrt(discriminant)) / (2 * a))
        x = min(roots, key=abs)
    if abs(x - 0.5) < 1e-12:
        return 0.0
    return float(min(max(x / (x - 0.5), 0.0), 1.0))


def lsb_entropy(pixels: np.ndarray, block: int = 64) -> tuple[float, float]:
    """Entropía del plano LSB por bloques: (media, fracción de bloques con H ≥ 0.999). Métrica de apoyo."""
    planes = pixels[..., None] if pixels.ndim == 2 else pixels
    h, w = planes.shape[:2]
    bh, bw = min(block, h), min(block, w)
    nh, nw = h // bh, w // bw
    bits = (planes[: nh * bh, : nw * bw] & 1).astype(np.float64)
    p = bits.reshape(nh, bh, nw, bw, -1).mean(axis=(1, 3))
    with np.errstate(divide="ignore", invalid="ignore"):
        entropy = -(
            np.where(p > 0, p * np.log2(p), 0) + np.where(p < 1, (1 - p) * np.log2(1 - p), 0)
        )
    return float(entropy.mean()), float((entropy >= 0.999).mean())
```

"""Contrato común de los formatos de la lista blanca (spec §12.2)."""

import io
from collections.abc import Callable
from dataclasses import dataclass

from PIL import Image


class Invalid(ValueError):
    """No es un ejemplar íntegro de su formato (o supera un límite): rejected (invalid)."""


@dataclass(frozen=True)
class Format:
    mime: str  # Content-Type con el que se sirve
    ext: str  # extensión del nombre de descarga
    category: str  # image | audio | video | document | text (el tope sale de la configuración)
    detect: Callable[[bytes], bool]  # firma: nunca la extensión ni el Content-Type del cliente
    validate: Callable[[bytes, dict], None]  # lanza Invalid
    # Funciones de módulo: el pipeline las ejecuta en un ProcessPoolExecutor.
    analyze: Callable[[bytes, dict], dict]
    sanitize: Callable[[bytes, dict], bytes]


def verdict(fmt: str, reasons: list[str], metrics: dict, active: list[str] | None = None) -> dict:
    """Veredicto que se guarda en files.verdict. `active` (contenido activo) implica rechazo."""
    active = active or []
    return {
        "format": fmt,
        "suspicious": bool(reasons),
        "active": bool(active),
        "reasons": [*active, *reasons],
        "metrics": metrics,
    }


def validate_image(data: bytes, pil_format: str, max_pixels: int) -> Image.Image:
    """Abre con un solo decodificador (menos superficie), corta bombas y verifica la integridad."""
    with Image.open(io.BytesIO(data), formats=[pil_format]) as image:
        if image.width * image.height > max_pixels:  # antes de decodificar
            raise Invalid("imagen demasiado grande")
        image.verify()
    image = Image.open(io.BytesIO(data), formats=[pil_format])
    image.load()
    return image


def analyze_embedded(data: bytes, cfg: dict) -> list[str]:
    """Motivos de una imagen incrustada (carátula, imagen de un DOCX) según el analizador de su formato."""
    from media_svc.formats import IMAGES  # import tardío: el registro importa este módulo

    for fmt in IMAGES:
        if fmt.detect(data):
            return fmt.analyze(data, cfg)["reasons"]
    return ["imagen de formato no analizable"]

"""PNG: estructura, estegoanálisis en píxeles y sanitización (spec §12.4, §12.9)."""

import io

import numpy as np
from PIL import Image

from media_svc import stego
from media_svc.formats.base import Format, validate_image, verdict

KNOWN_CHUNKS = {
    b"IHDR",
    b"PLTE",
    b"IDAT",
    b"IEND",
    b"tRNS",
    b"cHRM",
    b"gAMA",
    b"iCCP",
    b"sBIT",
    b"sRGB",
    b"cICP",
    b"mDCV",
    b"cLLI",
    b"bKGD",
    b"hIST",
    b"pHYs",
    b"sPLT",
    b"eXIf",
    b"tIME",
    b"acTL",
    b"fcTL",
    b"fdAT",
    b"tEXt",
    b"zTXt",
    b"iTXt",
}
TEXT_CHUNKS = {b"tEXt", b"zTXt", b"iTXt"}
SIGNATURE = b"\x89PNG\r\n\x1a\n"


def detect(data: bytes) -> bool:
    return data.startswith(SIGNATURE)


def validate(data: bytes, cfg: dict) -> None:
    validate_image(data, "PNG", cfg["max_pixels"]).close()


def structure(data: bytes) -> dict:
    position, text_bytes, unknown, trailing = 8, 0, [], 0
    while position + 12 <= len(data):
        length = int.from_bytes(data[position : position + 4], "big")
        ctype = data[position + 4 : position + 8]
        end = position + 12 + length
        if ctype in TEXT_CHUNKS:
            text_bytes += length
        elif ctype not in KNOWN_CHUNKS:
            unknown.append(ctype.decode("latin-1"))
        position = end
        if ctype == b"IEND":
            trailing = max(0, len(data) - end)
            break
    return {"trailing_bytes": trailing, "text_bytes": text_bytes, "unknown_chunks": unknown}


def lsb_statistics(data: bytes, cfg: dict) -> tuple[list[str], dict]:
    """chi², RS y entropía del plano LSB (spec §12.4)."""
    with Image.open(io.BytesIO(data), formats=["PNG"]) as image:
        rgb = np.asarray(image.convert("RGB"))
    chi2_p = stego.chi2_scan(rgb)
    rs_rate = max(stego.rs_estimate(rgb[..., channel]) for channel in range(3))
    entropy_mean, entropy_high = stego.lsb_entropy(rgb)
    reasons = []
    if chi2_p >= cfg["chi2_p"]:
        reasons.append("chi² del plano LSB")
    if rs_rate >= cfg["rs_rate"]:
        reasons.append("análisis RS")
    trigger = cfg.get("entropy_trigger")
    if trigger is not None and entropy_high >= trigger:
        reasons.append("entropía del plano LSB")
    return reasons, {
        "chi2_p": stego.finite(chi2_p),
        "rs_rate": stego.finite(rs_rate),
        "lsb_entropy_mean": stego.finite(entropy_mean),
        "lsb_entropy_high_fraction": stego.finite(entropy_high),
    }


def analyze(data: bytes, cfg: dict) -> dict:
    """Con cfg["statistical"] = False (reanálisis de la versión sanitizada, spec §12.9) solo se
    revisa la estructura: el LSB aleatorizado parecería un embedding al 100 %."""
    found = structure(data)
    reasons = []
    if found["trailing_bytes"]:
        reasons.append("datos después de IEND")
    if found["text_bytes"] > 1024:
        reasons.append("chunks de texto grandes")
    if found["unknown_chunks"]:
        reasons.append("chunks desconocidos")
    if cfg.get("statistical", True):
        lsb_reasons, lsb_metrics = lsb_statistics(data, cfg)
        reasons += lsb_reasons
        found = {**found, **lsb_metrics}
    return verdict("png", reasons, found)


def sanitize(data: bytes, cfg: dict) -> bytes:
    """XOR del plano LSB con bits aleatorios (destruye LSB-1 aunque no se haya detectado) y
    recodificación sin chunks auxiliares. Recodificar sin tocar píxeles NO basta: PNG es sin pérdida."""
    with Image.open(io.BytesIO(data), formats=["PNG"]) as image:
        has_alpha = image.mode in ("RGBA", "LA", "PA") or "transparency" in image.info
        converted = image.convert("RGBA" if has_alpha else "RGB")
    pixels = np.array(converted)
    pixels ^= np.random.default_rng().integers(0, 2, size=pixels.shape, dtype=np.uint8)
    out = io.BytesIO()
    Image.fromarray(pixels).save(out, format="PNG", optimize=True)
    return out.getvalue()


FORMAT = Format("image/png", "png", "image", detect, validate, analyze, sanitize)

"""JPEG: estructura y sanitización (spec §12.4, §12.9). El análisis LSB en píxeles no aplica a JPEG."""

import io

from PIL import Image, ImageOps

from media_svc.formats.base import Format, validate_image, verdict


def detect(data: bytes) -> bool:
    return data.startswith(b"\xff\xd8\xff")


def validate(data: bytes, cfg: dict) -> None:
    validate_image(data, "JPEG", cfg["max_pixels"]).close()


def skip_entropy(data: bytes, position: int) -> int:
    """Tras SOS: salta los datos de entropía hasta el siguiente marcador real."""
    size = len(data)
    while True:
        position = data.find(b"\xff", position)
        if position < 0 or position + 1 >= size:
            return size
        following = data[position + 1]
        if following == 0x00 or 0xD0 <= following <= 0xD7:  # byte escapado o RSTn
            position += 2
            continue
        return position


def structure(data: bytes) -> dict:
    """Recorre los segmentos por su longitud (una miniatura EXIF con su propio FFD9 no confunde)."""
    position, metadata, end, size = 2, 0, None, len(data)
    while position + 1 < size and data[position] == 0xFF:
        marker = data[position + 1]
        if marker == 0xD9:  # EOI
            end = position + 2
            break
        if marker == 0xFF or 0xD0 <= marker <= 0xD7 or marker == 0x01:  # relleno o sin longitud
            position += 1 if marker == 0xFF else 2
            continue
        if position + 4 > size:
            break
        length = int.from_bytes(data[position + 2 : position + 4], "big")
        if 0xE0 <= marker <= 0xEF or marker == 0xFE:  # APPn y COM
            metadata += length
        position += 2 + length
        if marker == 0xDA:  # SOS
            position = skip_entropy(data, position)
    return {"trailing_bytes": size - end if end is not None else 0, "metadata_bytes": metadata}


def analyze(data: bytes, cfg: dict) -> dict:
    found = structure(data)
    reasons = []
    if found["trailing_bytes"] > 16:
        reasons.append("datos después de EOI")
    if found["metadata_bytes"] > 65536:
        reasons.append("metadatos excesivos")

python services/media/tools/stego_lab.py embed <entrada> <salida> [--rate 0.1] [--mode seq|random]

python services/media/tools/stego_lab.py hide-text <entrada.txt> <salida.txt> --message "..." [--method zw|vs|snow]

python services/media/tools/stego_lab.py calibrate <carpeta>

import argparse
import io
import os
import sys
from pathlib import Path

import numpy as np
from PIL import Image

from media_svc.formats import png
from shared.testing import embed_lsb, wav_bytes

RATES = (0.05, 0.10, 0.25, 0.50, 1.00)
CFG = {"chi2_p": 0.95, "rs_rate": 0.08, "wav_rate": 0.08, "entropy_trigger": None}
ZERO_WIDTH = ("​", "‌")  # bit 0, bit 1


def load_rgb(path: str | Path) -> np.ndarray:
    return np.asarray(Image.open(path).convert("RGB")).copy()


def to_png(pixels: np.ndarray) -> bytes:
    buffer = io.BytesIO()
    Image.fromarray(pixels).save(buffer, format="PNG")
    return buffer.getvalue()


def embed(args: argparse.Namespace) -> None:
    data = Path(args.input).read_bytes()
    if data[:4] == b"RIFF" and data[8:12] == b"WAVE":
        from media_svc.formats import wav  # existe desde MED-7

        samples, rate = wav.read_samples(data)
        output = wav_bytes(embed_lsb(samples, args.rate, args.mode), rate)
    else:
        output = to_png(embed_lsb(load_rgb(args.input), args.rate, args.mode))
    Path(args.output).write_bytes(output)
    print(f"escrito {args.output} con LSB {args.mode} al {args.rate:.0%}")


def append(args: argparse.Namespace) -> None:
    Path(args.output).write_bytes(Path(args.input).read_bytes() + os.urandom(args.bytes))
    print(f"escrito {args.output} con {args.bytes} bytes anexados")


def bits(message: bytes):
    for byte in message:
        for shift in range(7, -1, -1):
            yield (byte >> shift) & 1


def hide_text(args: argparse.Namespace) -> None:
    text, message = Path(args.input).read_text(encoding="utf-8"), args.message.encode()
    if args.method == "zw":
        hidden = "".join(ZERO_WIDTH[bit] for bit in bits(message))
        first_space = max(text.find(" "), 0)
        result = text[:first_space] + hidden + text[first_space:]
    elif args.method == "vs":  # un selector por byte, "pegado" al primer carácter
        selectors = "".join(chr(0xFE00 + b) if b < 16 else chr(0xE0100 + b - 16) for b in message)
        result = text[:1] + selectors + text[1:]
    else:  # snow: 8 espacios/tabulaciones (0/1) al final de cada línea, un byte por línea
        lines = text.split("\n")
        if len(lines) < len(message):
            sys.exit(f"se necesitan {len(message)} líneas; el texto tiene {len(lines)}")
        tails = ["".join(" \t"[bit] for bit in bits(bytes([b]))) for b in message]
        result = "\n".join(
            line + (tails[i] if i < len(tails) else "") for i, line in enumerate(lines)
        )
    Path(args.output).write_text(result, encoding="utf-8")
    print(f"escrito {args.output} con {len(message)} bytes ocultos ({args.method})")


def report(variants: dict, metric: str) -> None:
    print(f"{'variante':<12} {'detectadas':>12} {'no concluyente':>15} {metric + ' (mediana)':>18}")
    for name, verdicts in variants.items():
        values = [v["metrics"][metric] for v in verdicts if v["metrics"].get(metric) is not None]
        hits = sum(v["suspicious"] for v in verdicts)
        median = np.median(values) if values else float("nan")
        print(
            f"{name:<12} {hits:>5}/{len(verdicts):<6} {len(verdicts) - len(values):>15} {median:>18.4f}"
        )

"""Cliente mínimo de clamd (protocolo INSTREAM) con la stdlib (spec §9.6, riesgo 9)."""

import asyncio
import struct

CHUNK = 64 * 1024


class ClamAVUnavailable(Exception):
    """clamd no respondió: el pipeline falla cerrado (503)."""


async def scan(host: str, port: int, data: bytes, timeout: float = 30.0) -> str | None:
    """Nombre de la firma si hay malware; None si está limpio."""
    try:
        reader, writer = await asyncio.wait_for(asyncio.open_connection(host, port), timeout)
    except (OSError, TimeoutError) as exc:
        raise ClamAVUnavailable(str(exc)) from exc
    try:
        writer.write(b"zINSTREAM\0")
        for start in range(0, len(data), CHUNK):
            chunk = data[start : start + CHUNK]
            writer.write(struct.pack("!I", len(chunk)) + chunk)
        writer.write(struct.pack("!I", 0))
        await writer.drain()
        raw = await asyncio.wait_for(reader.readuntil(b"\0"), timeout)
    except (OSError, TimeoutError, asyncio.IncompleteReadError) as exc:
        raise ClamAVUnavailable(str(exc)) from exc
    finally:
        writer.close()
    reply = raw.rstrip(b"\0").decode(errors="replace")
    if reply.endswith(" OK"):
        return None
    if reply.endswith(" FOUND"):
        return reply.removeprefix("stream: ").removesuffix(" FOUND")
    raise ClamAVUnavailable(reply)
```

"""Pipeline de subida (spec §9.6–§9.7; riesgos 6, 9 y 12)."""

import asyncio
import json
import logging
import os
from concurrent.futures import ProcessPoolExecutor
from dataclasses import dataclass
from pathlib import Path
from uuid import uuid4

import httpx
from fastapi import HTTPException
from sqlalchemy import text
from starlette.concurrency import run_in_threadpool

from media_svc import formats
from media_svc.clamav import ClamAVUnavailable
from media_svc.formats.base import verdict as make_verdict
from shared.crypto import sha256
from shared.identity import SessionIdentity

log = logging.getLogger("media.pipeline")
_POOL: ProcessPoolExecutor | None = None

INSERT_FILE = text(
    "INSERT INTO files (id, room_id, session_id, user_id, alias, storage_name, mime, size, sha256, "
    "clean_sha256, status, verdict) VALUES (:id, :room, :session, :user, :alias, :name, :mime, :size, "
    ":sha, :clean_sha, :status, CAST(CAST(:verdict AS text) AS jsonb))"
)


def pool(workers: int) -> ProcessPoolExecutor:
    # ponytail: pool global de MEDIA_WORKERS procesos. Un trabajo que excede el timeout sigue
    # corriendo hasta terminar (un worker no se puede matar); ffmpeg sí muere por su propio timeout.
    global _POOL
    if _POOL is None:
        _POOL = ProcessPoolExecutor(max_workers=workers)
    return _POOL


async def isolated(app, function, *args, timeout: float):
    """Todo lo que parsea bytes no confiables corre fuera del proceso web y con timeout."""
    loop = asyncio.get_running_loop()
    executor = pool(app.state.settings.media_workers)
    return await asyncio.wait_for(loop.run_in_executor(executor, function, *args), timeout)


@dataclass(frozen=True)
class Result:
    status: str  # clean | quarantined | rejected
    file_id: str | None


def storage_dir(settings, kind: str) -> Path:
    path = settings.media_dir / kind
    path.mkdir(parents=True, exist_ok=True)
    return path


def write_private(path: Path, data: bytes) -> None:
    path.write_bytes(data)
    os.chmod(path, 0o640)


def file_row(
    file_id, who: SessionIdentity, name, mime, data, digest, clean_sha, status, verdict
) -> dict:
    return {
        "id": file_id,
        "room": who.room_id,
        "session": who.session_id,
        "user": who.user_id,
        "alias": who.alias,
        "name": name,
        "mime": mime,
        "size": len(data),
        "sha": digest,
        "clean_sha": clean_sha,
        "status": status,
        "verdict": json.dumps(verdict, ensure_ascii=False),
    }


async def reject(
    app, who, data, digest, reason, mime, ip, severity="warning", details=None
) -> Result:
    """No se guarda el archivo; queda constancia de hash, tipo y motivo (spec §9.6)."""
    async with app.state.engine.begin() as conn:
        row = file_row(
            str(uuid4()),
            who,
            None,
            mime,
            data,
            digest,
            None,
            "rejected",
            {"reason": reason, **(details or {})},
        )
        await conn.execute(INSERT_FILE, row)
    await app.state.audit.emit(
        severity,
        f"file.rejected.{reason}",
        actor=f"session:{who.session_id}",
        ip=ip,
        details={"sha256": digest.hex(), "mime": mime, **(details or {})},
    )
    return Result("rejected", None)


async def is_own_output(app, digest: bytes) -> bool:
    """¿Son bytes que el propio sistema sanitizó y publicó? (spec §9.6, paso 5)."""
    async with app.state.engine.connect() as conn:
        found = await conn.execute(
            text(
                "SELECT 1 FROM files WHERE clean_sha256 = :sha AND status IN ('clean', 'released') LIMIT 1"
            ),
            {"sha": digest},
        )
        return found.first() is not None


async def analyze(app, fmt: formats.Format, data: bytes) -> dict:
    settings = app.state.settings
    try:
        return await isolated(
            app, fmt.analyze, data, settings.format_config, timeout=settings.stego_timeout_s
        )
    except TimeoutError:
        return make_verdict(fmt.ext, ["timeout del análisis"], {})
    except Exception:  # un analizador que falla no deja pasar el archivo: va a revisión
        log.exception("falló el análisis de un %s", fmt.mime)
        return make_verdict(fmt.ext, ["error del análisis"], {})


async def sanitize(app, fmt: formats.Format, data: bytes) -> bytes:
    settings = app.state.settings
    return await isolated(
        app, fmt.sanitize, data, settings.format_config, timeout=settings.sanitize_timeout_s
    )


async def publish(
    app, room_id: str, file_id: str, session_id: str, alias: str, mime: str, size: int
) -> None:
    try:
        response = await app.state.peers.post(
            "chat",
            f"/internal/rooms/{room_id}/files",
            json={
                "file_id": file_id,
                "session_id": session_id,
                "alias": alias,
                "mime": mime,
                "size": size,
            },
        )
    except httpx.HTTPError:
        response = None
    if response is None or response.status_code != 204:
        log.error("chat no publicó el archivo %s; queda sin URL firmada (spec §9.7)", file_id)
        raise HTTPException(503, "no se pudo publicar el archivo")


async def recheck(app, fmt: formats.Format, clean: bytes) -> list[str]:
    """Segunda inspección de la versión sanitizada antes de publicarla (spec §12.9, RS-36): se vuelve
    a validar y a pasar por las reglas estructurales de su formato. Los estadísticos del LSB se omiten,
    porque la sanitización de PNG y WAV aleatoriza ese plano a propósito. Devuelve los motivos."""
    settings = app.state.settings
    cfg = {**settings.format_config, "statistical": False}
    try:
        await isolated(app, fmt.validate, clean, cfg, timeout=settings.stego_timeout_s)
        found = await isolated(app, fmt.analyze, clean, cfg, timeout=settings.stego_timeout_s)
    except Exception:  # una salida que no se puede volver a leer tampoco se publica
        log.exception("falló el reanálisis de un %s sanitizado", fmt.mime)
        return ["la versión sanitizada no es válida"]
    return found["reasons"] if found["suspicious"] or found["active"] else []


async def screen(app, who, data: bytes, digest: bytes, ip) -> formats.Format | Result:
    """Tamaño, firma, validación y ClamAV (riesgo 9). Devuelve el formato o el rechazo."""
    settings, audit = app.state.settings, app.state.audit
    if len(data) > settings.upload_max_bytes:
        return await reject(app, who, data, digest, "size", "unknown", ip)
    fmt = await run_in_threadpool(formats.detect, data)
    if fmt is None:
        return await reject(app, who, data, digest, "type", "unknown", ip)
    if len(data) > settings.max_bytes(fmt.category):
        return await reject(app, who, data, digest, "size", fmt.mime, ip)
    try:
        await isolated(
            app, fmt.validate, data, settings.format_config, timeout=settings.stego_timeout_s
        )
    except Exception:  # cualquier fallo al decodificar o parsear (o timeout) = archivo inválido
        return await reject(app, who, data, digest, "invalid", fmt.mime, ip)
    try:
        signature = await app.state.scanner(data)
    except ClamAVUnavailable:
        await audit.emit("warning", "clamav.unavailable", actor=f"session:{who.session_id}", ip=ip)
        raise HTTPException(503, "análisis no disponible") from None
    if signature:
        return await reject(
            app,
            who,
            data,
            digest,
            "malware",
            fmt.mime,
            ip,
            severity="critical",
            details={"signature": signature},
        )
    return fmt


async def quarantine(app, who, fmt, data: bytes, digest: bytes, verdict: dict, ip) -> Result:
    file_id, name = str(uuid4()), uuid4().hex
    write_private(storage_dir(app.state.settings, "quarantine") / name, data)
    async with app.state.engine.begin() as conn:
        await conn.execute(
            INSERT_FILE,
            file_row(file_id, who, name, fmt.mime, data, digest, None, "quarantined", verdict),
        )
    await app.state.audit.emit(
        "warning",
        "file.quarantined",
        actor=f"session:{who.session_id}",
        target=file_id,
        ip=ip,
        details={"reasons": verdict["reasons"], "metrics": verdict["metrics"]},
    )
    return Result("quarantined", file_id)


async def accept(app, who, fmt, data: bytes, digest: bytes, verdict: dict, ip) -> Result:
    """Sanitiza, reanaliza la salida, la guarda y la publica en la sala."""
    try:
        clean = await sanitize(app, fmt, data)
    except Exception:  # si no hay versión limpia, no se publica nada
        return await reject(
            app, who, data, digest, "invalid", fmt.mime, ip, details={"stage": "sanitize"}
        )
    problems = await recheck(app, fmt, clean)
    if problems:
        return await reject(
            app, who, data, digest, "recheck", fmt.mime, ip, details={"reasons": problems}
        )
    file_id, name = str(uuid4()), uuid4().hex
    path = storage_dir(app.state.settings, "media") / name
    write_private(path, clean)
    try:
        async with app.state.engine.begin() as conn:
            await conn.execute(
                INSERT_FILE,
                file_row(
                    file_id, who, name, fmt.mime, data, digest, sha256(clean), "clean", verdict
                ),
            )
            await app.state.audit.emit(
                "info",
                "file.accepted",
                actor=f"session:{who.session_id}",
                target=file_id,
                ip=ip,
                required=True,
            )
    except Exception:
        path.unlink(missing_ok=True)  # sin fila no puede quedar un archivo huérfano en disco
        raise
    await publish(app, who.room_id, file_id, who.session_id, who.alias, fmt.mime, len(clean))
    return Result("clean", file_id)


async def process(app, who: SessionIdentity, data: bytes, ip: str | None) -> Result:
    digest = sha256(data)
    fmt = await screen(app, who, data, digest, ip)
    if isinstance(fmt, Result):
        return fmt
    if await is_own_output(app, digest):
        verdict = {**make_verdict(fmt.ext, [], {}), "known_output": True}
    else:
        verdict = await analyze(app, fmt, data)
    if verdict["active"]:  # macros, JavaScript, adjuntos, OLE…: no se publican ni se guardan
        return await reject(
            app, who, data, digest, "active", fmt.mime, ip, details={"reasons": verdict["reasons"]}
        )
    if verdict["suspicious"]:
        return await quarantine(app, who, fmt, data, digest, verdict, ip)
    return await accept(app, who, fmt, data, digest, verdict, ip)

import time
from uuid import UUID

from fastapi import APIRouter, Depends, HTTPException, Request, UploadFile

from media_svc import formats, pipeline
from shared.crypto import verify_url

router = APIRouter()


@router.post("/api/media/files")
async def upload(
    request: Request, file: UploadFile, who: SessionIdentity = Depends(require_session)
) -> dict:
    settings, engine, audit = (
        request.app.state.settings,
        request.app.state.engine,
        request.app.state.audit,
    )
    ip = client_ip(request)
    if who.mode not in ("media", "both"):
        await audit.emit(
            "warning", "file.rejected.forbidden", actor=f"session:{who.session_id}", ip=ip
        )
        raise HTTPException(403, "la sala no permite archivos")
    async with engine.connect() as conn:
        recent = (
            await conn.execute(
                text(
                    "SELECT count(*) FROM files "
                    "WHERE session_id = :session AND created_at > now() - interval '1 minute'"
                ),
                {"session": who.session_id},
            )
        ).scalar_one()
    if recent >= settings.upload_per_min:
        raise HTTPException(429, "demasiadas subidas; espera un minuto")
    data = await file.read(settings.upload_max_bytes + 1)
    result = await pipeline.process(request.app, who, data, ip)
    if result.status == "rejected":
        raise HTTPException(422, "archivo no permitido")
    return {"file_id": result.file_id, "status": result.status}


@router.get("/api/media/files/{file_id}")
async def download(
    file_id: UUID,
    request: Request,
    exp: int = 0,
    sig: str = "",
    who: SessionIdentity = Depends(require_session),
):
    settings, fid = request.app.state.settings, str(file_id)
    async with request.app.state.engine.connect() as conn:
        row = (
            await conn.execute(
                text(
                    "SELECT room_id::text AS room_id, storage_name, mime, status FROM files WHERE id = :id"
                ),
                {"id": fid},
            )
        ).first()
    allowed = (
        row is not None
        and row.status in ("clean", "released")
        and row.room_id == who.room_id
        and verify_url(settings.url_signing_key, fid, who.session_id, exp, sig, int(time.time()))
    )
    if not allowed:  # 404 genérico: no revela si el archivo existe
        await request.app.state.audit.emit(
            "warning",
            "file.download.denied",
            actor=f"session:{who.session_id}",
            target=fid,
            ip=client_ip(request),
        )
        raise HTTPException(404, "no encontrado")
    return FileResponse(
        settings.media_dir / "media" / row.storage_name,
        media_type=row.mime,
        headers={
            "X-Content-Type-Options": "nosniff",
            # attachment para todo: el navegador nunca interpreta el archivo en el origen del chat.
            "Content-Disposition": f'attachment; filename="archivo.{formats.FORMATS[row.mime].ext}"',
            "Cache-Control": "private, no-store",
        },
    )

"""GIF: bloques, extensiones, paleta y sanitización por recuantización (spec §12.4, §12.9)."""

import io

import numpy as np
from PIL import Image, ImageSequence

from media_svc import stego
from media_svc.formats.base import Format, Invalid, validate_image, verdict

ANIMATION_APPS = {b"NETSCAPE2.0", b"ANIMEXTS1.0"}


def detect(data: bytes) -> bool:
    return data[:6] in (b"GIF87a", b"GIF89a")


def validate(data: bytes, cfg: dict) -> None:
    with validate_image(data, "GIF", cfg["max_pixels"]) as image:
        frames = getattr(image, "n_frames", 1)
        if frames > cfg["gif_max_frames"]:
            raise Invalid("demasiados cuadros")
        for frame in ImageSequence.Iterator(image):
            frame.load()


def _sub_blocks(data: bytes, position: int) -> tuple[bytes, int]:
    """Concatena sub-bloques (longitud + datos) hasta el terminador 0."""
    parts = []
    while position < len(data) and data[position]:
        size = data[position]
        parts.append(data[position + 1 : position + 1 + size])
        position += 1 + size
    return b"".join(parts), position + 1


def _color_table(data: bytes, position: int, flags: int) -> tuple[bytes, int]:
    if not flags & 0x80:
        return b"", position
    size = 3 * 2 ** ((flags & 0x07) + 1)
    return data[position : position + size], position + size


def structure(data: bytes) -> dict:
    palette, position = _color_table(data, 13, data[10])
    comments, apps, plain_text, end = 0, [], 0, None
    while position < len(data):
        block = data[position]
        if block == 0x3B:  # trailer
            end = position + 1
            break
        if block == 0x2C:  # descriptor de imagen
            _, position = _color_table(data, position + 10, data[position + 9])
            _, position = _sub_blocks(data, position + 1)  # +1: tamaño mínimo de código LZW
        elif block == 0x21:  # extensión
            label = data[position + 1]
            body, position = _sub_blocks(data, position + 2)
            if label == 0xFE:
                comments += len(body)
            elif label == 0xFF:
                apps.append(body[:11].decode("latin-1"))
            elif label == 0x01:
                plain_text += 1
        else:
            break  # byte inesperado: lo que sigue cuenta como datos anexados
    return {
        "trailing_bytes": len(data) - (end if end is not None else position),
        "comment_bytes": comments,
        "app_extensions": apps,
        "plain_text_blocks": plain_text,
        "palette": palette,
    }


def close_color_fraction(palette: bytes) -> float:
    """Fracción de colores de la paleta con un vecino a distancia ≤ 2 por canal (S-Tools, EzStego)."""
    colors = np.unique(np.frombuffer(palette, np.uint8).reshape(-1, 3), axis=0).astype(np.int16)
    if len(colors) < 2:
        return 0.0
    distance = np.abs(colors[:, None, :] - colors[None, :, :]).max(axis=2)
    np.fill_diagonal(distance, 255)
    return float((distance.min(axis=1) <= 2).mean())


def analyze(data: bytes, cfg: dict) -> dict:
    found = structure(data)
    palette = found.pop("palette")
    found["close_color_fraction"] = stego.finite(close_color_fraction(palette)) if palette else None
    reasons = []
    if found["trailing_bytes"]:
        reasons.append("datos después del trailer")
    if found["comment_bytes"] > 1024:
        reasons.append("comentarios grandes")
    if any(app.encode("latin-1") not in ANIMATION_APPS for app in found["app_extensions"]):
        reasons.append("extensiones de aplicación desconocidas")
    if found["plain_text_blocks"]:
        reasons.append("extensiones de texto plano")
    trigger = cfg.get("gif_palette_trigger") if cfg.get("statistical", True) else None
    if trigger is not None and (found["close_color_fraction"] or 0) >= trigger:
        reasons.append("paleta con colores casi idénticos")
    return verdict("gif", reasons, found)


def sanitize(data: bytes, cfg: dict) -> bytes:
    """Recuantiza cada cuadro con una paleta nueva: reescribe paleta e índices (EzStego, Gifshuffle).
    Conserva duraciones y bucle; no escribe comentarios ni más extensiones que NETSCAPE2.0."""
    with Image.open(io.BytesIO(data), formats=["GIF"]) as image:
        loop = image.info.get("loop")
        frames, durations = [], []
        for frame in ImageSequence.Iterator(image):
            durations.append(frame.info.get("duration", 100))
            rgba = frame.convert("RGBA")
            rgba.info = {}  # convert() copia info (comentarios incluidos) del original
            frames.append(rgba)
    out = io.BytesIO()
    options = {"save_all": True, "append_images": frames[1:], "duration": durations, "disposal": 2}
    if loop is not None:
        options["loop"] = loop
    frames[0].save(out, format="GIF", **options)
    return out.getvalue()


FORMAT = Format("image/gif", "gif", "image", detect, validate, analyze, sanitize)
```

La carátula pasa por el analizador de su formato. La sanitización recodifica con LAME sin etiquetas.

# --- Audio (WAV, MED-7) -----------------------------------------------------------------
# SPA solo es concluyente con suficientes pares en la traza 0 (señal suave a escala del LSB).
# Prototipo 2026-10-19: con estos mínimos, ningún falso positivo en voz sintética.
SPA_MIN_PAIRS = 20_000
SPA_MIN_FRACTION = 0.10
SPA_PREFIXES = (0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1.0)


def spa_estimate(channel: np.ndarray) -> float | None:
    """Sample Pair Analysis (Dumitrescu, Wu, Wang 2003) en el marco de conjuntos de traza de Ker.

    Pares de muestras consecutivas (u, v); traza t = ⌊v/2⌋ − ⌊u/2⌋ (invariante al cambiar LSB).
    Si en la señal original los pares con diferencia impar se reparten por igual entre "el mayor
    es par" y "el mayor es impar", la tasa p de reemplazo de LSB cumple, con k = 1 − p:
        (N₀/2)·k² − W·k + (Σ₀ − N₀/2) = 0
    N₀: pares en la traza 0 · Σ₀: de ellos, con paridad distinta ·
    W: Σ_{t<0} (#par→impar − #impar→par) − Σ_{t>0} (lo mismo).
    Devuelve p̂ en [0, 1], o None si la traza 0 es demasiado escasa para concluir.
    """
    samples = channel.astype(np.int64).ravel()
    u, v = samples[:-1], samples[1:]
    trace = (v >> 1) - (u >> 1)
    n0 = int(np.count_nonzero(trace == 0))
    if n0 < SPA_MIN_PAIRS or n0 < SPA_MIN_FRACTION * len(trace):
        return None
    lu, lv = u & 1, v & 1
    sigma0 = int(np.count_nonzero((trace == 0) & (lu != lv)))
    delta = ((lu == 0) & (lv == 1)).astype(np.int64) - ((lu == 1) & (lv == 0)).astype(np.int64)
    w = int(delta[trace <= -1].sum() - delta[trace >= 1].sum())
    discriminant = w * w - 2 * n0 * (sigma0 - n0 / 2)
    if discriminant < 0:
        return 0.0
    k = (w + math.sqrt(discriminant)) / n0  # la raíz mayor: la de menor tasa
    return float(min(max(1 - k, 0.0), 1.0))


def spa_scan(samples: np.ndarray) -> float | None:
    """Máximo p̂ por canal sobre prefijos de 1 % a 100 % (el embedding secuencial empieza al inicio).

    None si ningún prefijo es concluyente (señal fuerte o ruidosa: lo cubre la sanitización).
    Degenera cerca del 100 % de embedding, igual que RS.
    """
    columns = samples.reshape(len(samples), -1)
    estimates = [
        estimate
        for fraction in SPA_PREFIXES
        for channel in range(columns.shape[1])
        if (estimate := spa_estimate(columns[: int(len(columns) * fraction), channel])) is not None
    ]
    return max(estimates) if estimates else None


def lsb_entropy_1d(values: np.ndarray, block: int = 4096) -> tuple[float, float]:
    """Entropía del plano LSB de una señal por bloques: (media, fracción con H ≥ 0.999). De apoyo."""
    bits = (values.reshape(-1) & 1).astype(np.float64)
    blocks = len(bits) // block
    if blocks == 0:
        return 0.0, 0.0
    p = bits[: blocks * block].reshape(blocks, block).mean(axis=1)
    with np.errstate(divide="ignore", invalid="ignore"):
        entropy = -(
            np.where(p > 0, p * np.log2(p), 0) + np.where(p < 1, (1 - p) * np.log2(1 - p), 0)
        )
    return float(entropy.mean()), float((entropy >= 0.999).mean())

"""ffprobe y ffmpeg endurecidos para entrada no confiable (spec §12.9).

- Demuxer forzado (-f): nunca autodetección (evita que un "MP4" se lea como lista HLS o concat).
- -protocol_whitelist file: sin red ni archivos referenciados desde la entrada.
- Sin shell, con timeout y, en Linux, topes de memoria y CPU con prlimit.
"""

import json
import shutil
import subprocess  # noqa: S404 — se ejecutan binarios fijos con argumentos en lista
import tempfile
from pathlib import Path

LIMITS = ["--as=2147483648", "--cpu=120"]  # 2 GiB de memoria virtual y 120 s de CPU por proceso


class ToolError(Exception):
    """ffmpeg/ffprobe falló o venció: el archivo se trata como inválido."""


def _command(tool: str, args: list[str]) -> list[str]:
    binary = shutil.which(tool)
    if binary is None:
        raise ToolError(f"{tool} no está instalado")
    prlimit = shutil.which("prlimit")  # Linux (contenedor); en Windows/macOS se omite
    prefix = [prlimit, *LIMITS, "--"] if prlimit else []
    quiet = ["-hide_banner", "-v", "error"] + (["-nostdin"] if tool == "ffmpeg" else [])
    return [*prefix, binary, *quiet, *args]


def _run(tool: str, args: list[str], timeout: float) -> bytes:
    try:
        result = subprocess.run(  # noqa: S603 — binario resuelto con shutil.which, sin shell
            _command(tool, args), capture_output=True, timeout=timeout, check=False
        )
    except subprocess.TimeoutExpired:
        raise ToolError(f"{tool}: timeout") from None
    if result.returncode != 0:
        raise ToolError(f"{tool}: {result.stderr.decode(errors='replace')[-300:]}")
    return result.stdout


def probe(data: bytes, demuxer: str, timeout: float, *, packets: bool = False) -> dict:
    """Streams y formato (y, si se pide, posición y tamaño de cada paquete) en JSON."""
    entries = "stream=index,codec_type,codec_name:stream_disposition=attached_pic:format=bit_rate,duration"
    if packets:
        entries += ":packet=stream_index,pos,size"
    with tempfile.TemporaryDirectory() as folder:
        source = Path(folder) / "entrada"
        source.write_bytes(data)
        args = ["-protocol_whitelist", "file", "-f", demuxer, "-show_streams", "-show_format"]
        if packets:
            args.append("-show_packets")
        output = _run(
            "ffprobe", [*args, "-show_entries", entries, "-of", "json", str(source)], timeout
        )
    return json.loads(output)


def convert(data: bytes, demuxer: str, output_args: list[str], timeout: float) -> bytes:
    """Lee la entrada con el demuxer forzado y escribe la salida que describen output_args."""
    with tempfile.TemporaryDirectory() as folder:
        source, target = Path(folder) / "entrada", Path(folder) / "salida"
        source.write_bytes(data)
        _run(
            "ffmpeg",
            [
                "-protocol_whitelist",
                "file",
                "-f",
                demuxer,
                "-i",
                str(source),
                *output_args,
                str(target),
            ],
            timeout,
        )
        return target.read_bytes()

"""WAV (PCM de 16 bits): estructura RIFF, Sample Pair Analysis y sanitización (spec §12.5, §12.9)."""

import io
import wave

import numpy as np

from media_svc import stego
from media_svc.formats.base import Format, Invalid, verdict

ALLOWED_CHUNKS = {
    b"fmt ",
    b"data",
    b"fact",
    b"LIST",
    b"id3 ",
    b"bext",
    b"cue ",
    b"smpl",
    b"JUNK",
    b"PAD ",
}
METADATA_CHUNKS = {b"LIST", b"id3 ", b"bext"}
PADDING_CHUNKS = {b"JUNK", b"PAD "}


def detect(data: bytes) -> bool:
    return data[:4] == b"RIFF" and data[8:12] == b"WAVE"


def chunks(data: bytes) -> tuple[list[tuple[bytes, int, int]], int]:
    """([(id, inicio del cuerpo, tamaño)], bytes después del tamaño declarado del RIFF)."""
    declared_end = 8 + int.from_bytes(data[4:8], "little")
    if declared_end > len(data):
        raise Invalid("RIFF truncado")
    found, position = [], 12
    while position + 8 <= declared_end:
        size = int.from_bytes(data[position + 4 : position + 8], "little")
        if position + 8 + size > declared_end:
            raise Invalid("chunk fuera del RIFF")
        found.append((data[position : position + 4], position + 8, size))
        position += 8 + size + (size & 1)  # los chunks se alinean a 2 bytes
    return found, len(data) - declared_end


def read_samples(data: bytes) -> tuple[np.ndarray, int]:
    """Muestras int16 con forma (n, canales) y frecuencia. Lanza Invalid si no es PCM de 16 bits."""
    try:
        with wave.open(io.BytesIO(data)) as source:
            channels, width, rate = (
                source.getnchannels(),
                source.getsampwidth(),
                source.getframerate(),
            )
            frames = source.readframes(source.getnframes())
    except (wave.Error, EOFError) as exc:
        raise Invalid(f"WAV inválido: {exc}") from None
    if width != 2 or channels not in (1, 2) or not 8000 <= rate <= 48000:
        raise Invalid("solo PCM de 16 bits, 1–2 canales y 8–48 kHz")
    if len(frames) % (2 * channels):
        raise Invalid("datos incompletos")
    return np.frombuffer(frames, "<i2").reshape(-1, channels), rate


def validate(data: bytes, cfg: dict) -> None:
    chunks(data)
    read_samples(data)


def analyze(data: bytes, cfg: dict) -> dict:
    found, trailing = chunks(data)
    unknown = [cid.decode("latin-1") for cid, _, _ in found if cid not in ALLOWED_CHUNKS]
    metadata = sum(size for cid, _, size in found if cid in METADATA_CHUNKS)
    padding = sum(
        np.count_nonzero(np.frombuffer(data[start : start + size], np.uint8))
        for cid, start, size in found
        if cid in PADDING_CHUNKS
    )
    samples, _ = read_samples(data)
    statistical = cfg.get("statistical", True)  # False en el reanálisis de la versión sanitizada
    rate = stego.spa_scan(samples) if statistical else None
    entropy_mean, entropy_high = stego.lsb_entropy_1d(samples) if statistical else (None, None)
    reasons = []
    if trailing:
        reasons.append("datos después del RIFF")
    if unknown:
        reasons.append("chunks desconocidos")
    if metadata > 65536:
        reasons.append("metadatos excesivos")
    if padding:
        reasons.append("relleno con datos")
    if rate is not None and rate >= cfg["wav_rate"]:
        reasons.append("análisis SPA")
    metrics = {
        "trailing_bytes": trailing,
        "unknown_chunks": unknown,
        "metadata_bytes": metadata,
        "padding_nonzero_bytes": int(padding),
        "spa_rate": None if rate is None else stego.finite(rate),  # None: no concluyente
        "lsb_entropy_mean": None if entropy_mean is None else stego.finite(entropy_mean),
        "lsb_entropy_high_fraction": None if entropy_high is None else stego.finite(entropy_high),
    }
    return verdict("wav", reasons, metrics)


def sanitize(data: bytes, cfg: dict) -> bytes:
    """Solo fmt + data, con el LSB de cada muestra aleatorizado (ruido a −96 dB, inaudible)."""
    samples, rate = read_samples(data)
    noisy = samples ^ np.random.default_rng().integers(0, 2, samples.shape, dtype=np.int16)
    out = io.BytesIO()
    with wave.open(out, "wb") as target:
        target.setnchannels(samples.shape[1])
        target.setsampwidth(2)
        target.setframerate(rate)
        target.writeframes(noisy.astype("<i2").tobytes())
    return out.getvalue()


FORMAT = Format("audio/wav", "wav", "audio", detect, validate, analyze, sanitize)

"""MP3: etiquetas, flujo de tramas, bits de cabecera y recodificación (spec §12.5, §12.9)."""

import io

from mutagen.id3 import ID3, ID3NoHeaderError

from media_svc import ffmpeg
from media_svc.formats.base import Format, Invalid, analyze_embedded, verdict

# kbps por índice de bitrate (Layer III). Clave: MPEG-1 o MPEG-2/2.5.
BITRATES = {
    "1": (0, 32, 40, 48, 56, 64, 80, 96, 112, 128, 160, 192, 224, 256, 320),
    "2": (0, 8, 16, 24, 32, 40, 48, 56, 64, 80, 96, 112, 128, 144, 160),
}
SAMPLE_RATES = {3: (44100, 48000, 32000), 2: (22050, 24000, 16000), 0: (11025, 12000, 8000)}


def frame_length(data: bytes, position: int) -> int:
    """Longitud de la trama Layer III que empieza en `position`, o 0 si no hay una cabecera válida."""
    if position + 4 > len(data) or data[position] != 0xFF:
        return 0
    b1, b2 = data[position + 1], data[position + 2]
    version, layer = (b1 >> 3) & 0x03, (b1 >> 1) & 0x03
    bitrate_index, rate_index, padding = b2 >> 4, (b2 >> 2) & 0x03, (b2 >> 1) & 0x01
    if b1 & 0xE0 != 0xE0 or version == 1 or layer != 1 or rate_index == 3:
        return 0
    if bitrate_index in (0, 15):  # "free format" o inválido
        return 0
    kbps = BITRATES["1" if version == 3 else "2"][bitrate_index]
    factor = 144 if version == 3 else 72
    return factor * kbps * 1000 // SAMPLE_RATES[version][rate_index] + padding


def detect(data: bytes) -> bool:
    return data[:3] == b"ID3" or frame_length(data, 0) > 0


def id3v2_end(data: bytes) -> int:
    if data[:3] != b"ID3" or len(data) < 10:
        return 0
    size = (data[6] << 21) | (data[7] << 14) | (data[8] << 7) | data[9]  # entero "syncsafe"
    return 10 + size + (10 if data[5] & 0x10 else 0)


def audio_end(data: bytes) -> int:
    """Fin del audio: descuenta ID3v1, APEv2 y Lyrics3 del final."""
    end = len(data)
    if end >= 128 and data[end - 128 : end - 125] == b"TAG":
        end -= 128
    if end >= 32 and data[end - 32 : end - 24] == b"APETAGEX":
        size = int.from_bytes(data[end - 20 : end - 16], "little")
        has_header = int.from_bytes(data[end - 12 : end - 8], "little") & 0x80000000
        end = max(0, end - size - (32 if has_header else 0))
    if end >= 15 and data[end - 9 : end] == b"LYRICS200" and data[end - 15 : end - 9].isdigit():
        end = max(0, end - 15 - int(data[end - 15 : end - 9]))
    return end


def walk(data: bytes, start: int, end: int) -> dict:
    """Recorre las tramas por su longitud. Al perder la sincronía, avanza byte a byte y solo acepta
    una cabecera si la siguiente también es válida (evita falsas sincronías dentro de datos ajenos)."""
    position, frames, outside, truncated, bits = start, 0, 0, 0, set()
    synced = True
    while position + 4 <= end:
        length = frame_length(data, position)
        following = position + length
        valid = length > 0 and (synced or following >= end or frame_length(data, following) > 0)
        if valid and following > end:
            truncated = end - position  # última trama cortada: común en archivos reales
            position = end
            break
        if valid:
            frames += 1
            bits.add(
                (data[position + 2] & 0x01, data[position + 3] & 0x0C)
            )  # private; copyright+original
            position, synced = following, True
            continue
        outside += 1
        position, synced = position + 1, False
    outside += end - position
    return {
        "frames": frames,
        "outside_bytes": outside,
        "truncated_bytes": truncated,
        "header_bits": len(bits),
    }


def tags(data: bytes) -> dict:
    try:
        found = ID3(io.BytesIO(data))
    except ID3NoHeaderError:
        return {
            "frames": [],
            "unknown": 0,
            "geob": 0,
            "priv_bytes": 0,
            "pictures": [],
            "text_bytes": 0,
        }
    frames = list(found.values())
    pictures = [frame.data for frame in frames if frame.FrameID == "APIC"]
    return {
        "frames": sorted({frame.FrameID for frame in frames}),
        "unknown": len(found.unknown_frames),
        "geob": sum(frame.FrameID == "GEOB" for frame in frames),
        "priv_bytes": max(
            (len(frame.data) for frame in frames if frame.FrameID == "PRIV"), default=0
        ),
        "pictures": pictures,
        "text_bytes": id3v2_end(data) - sum(len(picture) for picture in pictures),
    }


def validate(data: bytes, cfg: dict) -> None:
    try:
        info = ffmpeg.probe(data, "mp3", cfg["stego_timeout_s"])
    except ffmpeg.ToolError as exc:
        raise Invalid(str(exc)) from None
    streams = info.get("streams", [])
    audio = [s for s in streams if s.get("codec_type") == "audio"]
    others = [
        s
        for s in streams
        if s.get("codec_type") != "audio" and not s.get("disposition", {}).get("attached_pic")
    ]
    if len(audio) != 1 or audio[0].get("codec_name") != "mp3" or others:
        raise Invalid("se espera un único flujo de audio MP3")
    if walk(data, id3v2_end(data), audio_end(data))["frames"] == 0:
        raise Invalid("sin tramas MP3")


def analyze(data: bytes, cfg: dict) -> dict:
    found = tags(data)
    stream = walk(data, id3v2_end(data), audio_end(data))
    reasons = []
    if stream["outside_bytes"]:
        reasons.append("datos fuera de las tramas")
    if stream["header_bits"] > 1:
        reasons.append("bits de cabecera variables")
    if found["geob"]:
        reasons.append("objetos encapsulados en las etiquetas")
    if found["priv_bytes"] > 1024:
        reasons.append("etiquetas privadas grandes")
    if found["unknown"]:
        reasons.append("etiquetas desconocidas")
    tail_tags = len(data) - audio_end(data)
    if found["text_bytes"] + tail_tags > 65536:
        reasons.append("metadatos excesivos")
    for picture in found["pictures"]:
        reasons += [f"carátula: {reason}" for reason in analyze_embedded(picture, cfg)]
    metrics = {
        **stream,
        "id3_frames": found["frames"],
        "tag_bytes": found["text_bytes"] + tail_tags,
    }
    return verdict("mp3", reasons, metrics)


def sanitize(data: bytes, cfg: dict) -> bytes:
    """Recodifica con LAME (mismo bitrate, tope 192 kbps) y sin etiquetas: destruye etiquetas, tramas
    ajenas, bits de cabecera y el payload de MP3Stego (que vive en la cuantización)."""
    info = ffmpeg.probe(data, "mp3", cfg["sanitize_timeout_s"])
    kbps = min(192, int(info.get("format", {}).get("bit_rate") or 128_000) // 1000)
    return ffmpeg.convert(
        data,
        "mp3",
        [
            "-map",
            "0:a:0",
            "-c:a",
            "libmp3lame",
            "-b:a",
            f"{max(kbps, 32)}k",
            "-map_metadata",
            "-1",
            "-id3v2_version",
            "0",
            "-write_xing",
            "0",
            "-f",
            "mp3",
        ],
        cfg["sanitize_timeout_s"],
    )


FORMAT = Format("audio/mpeg", "mp3", "audio", detect, validate, analyze, sanitize)

"""MP4 (ISO BMFF): cajas, metadatos, relleno, bytes no referenciados y remultiplexado (spec §12.6, §12.9)."""

from media_svc import ffmpeg
from media_svc.formats.base import Format, Invalid, analyze_embedded, verdict

BRANDS = {b"isom", b"iso2", b"iso3", b"iso4", b"iso5", b"iso6", b"mp41", b"mp42", b"avc1", b"M4V "}
TOP_LEVEL = {
    b"ftyp",
    b"moov",
    b"mdat",
    b"free",
    b"skip",
    b"wide",
    b"uuid",
    b"meta",
    b"udta",
    b"pdin",
    b"moof",
    b"mfra",
    b"sidx",
    b"styp",
}
CONTAINERS = {
    b"moov",
    b"trak",
    b"mdia",
    b"minf",
    b"stbl",
    b"edts",
    b"dinf",
    b"mvex",
    b"moof",
    b"traf",
    b"mfra",
}
METADATA = {b"udta", b"meta", b"uuid"}
PADDING = {b"free", b"skip", b"wide"}


def detect(data: bytes) -> bool:
    return data[4:8] == b"ftyp" and data[8:12] in BRANDS


def boxes(data: bytes, start: int, end: int, *, lenient: bool = False) -> tuple[list[tuple], int]:
    """([(tipo, inicio, inicio del cuerpo, fin)], bytes sobrantes). Con lenient, una cabecera
    imposible corta el recorrido y lo que queda cuenta como sobrante (datos anexados)."""
    found, position = [], start
    while position < end:
        size, kind, header = (
            int.from_bytes(data[position : position + 4], "big"),
            data[position + 4 : position + 8],
            8,
        )
        if size == 1 and position + 16 <= end:
            size, header = int.from_bytes(data[position + 8 : position + 16], "big"), 16
        elif size == 0:
            size = end - position  # la última caja llega hasta el final
        if position + 8 > end or size < header or position + size > end or not kind.isascii():
            if lenient:
                break
            raise Invalid("caja fuera de rango")
        found.append((kind, position, position + header, position + size))
        position += size
    return found, end - position


def _inside(data: bytes, start: int, end: int) -> list[tuple]:
    """Todas las cajas bajo los contenedores conocidos, sin entrar en los metadatos."""
    result = []
    for box in boxes(data, start, end)[0]:
        result.append(box)
        if box[0] in CONTAINERS:
            result += _inside(data, box[2], box[3])
    return result


def _covers(data: bytes, start: int, end: int) -> list[bytes]:
    """Imágenes de carátula (ilst/covr/data) dentro de una caja de metadatos; tolera variantes."""
    images = []
    for offset in (4, 0):  # 'meta' es FullBox en ISO, pero no en QuickTime
        try:
            children = boxes(data, start + offset, end)[0]
        except Invalid:
            continue
        for kind, _, body, box_end in children:
            if kind == b"covr":
                images += [
                    data[b + 8 : e] for k, _, b, e in boxes(data, body, box_end)[0] if k == b"data"
                ]
            elif kind in (b"meta", b"ilst", b"udta"):
                images += _covers(data, body, box_end)
        break
    return images


def structure(data: bytes) -> dict:
    top, trailing = boxes(data, 0, len(data), lenient=True)
    every = list(top)
    for kind, _, body, end in top:
        if kind in CONTAINERS:
            every += _inside(data, body, end)
    covers = [
        img for kind, _, body, end in every if kind in METADATA for img in _covers(data, body, end)
    ]
    return {
        "top": top,
        "trailing_bytes": trailing,
        "unknown_boxes": sorted({k.decode("latin-1") for k, *_ in top if k not in TOP_LEVEL}),
        "metadata_bytes": sum(end - start for kind, start, _, end in every if kind in METADATA)
        - sum(len(c) for c in covers),
        "padding_nonzero_bytes": sum(
            len(data[body:end]) - data[body:end].count(0)
            for kind, _, body, end in every
            if kind in PADDING
        ),
        "covers": covers,
    }


def _streams(info: dict) -> tuple[list[dict], list[dict], list[dict]]:
    streams = info.get("streams", [])
    video = [
        s
        for s in streams
        if s.get("codec_type") == "video" and not s.get("disposition", {}).get("attached_pic")
    ]
    audio = [s for s in streams if s.get("codec_type") == "audio"]
    others = [s for s in streams if s.get("codec_type") not in ("video", "audio")]
    return video, audio, others


def validate(data: bytes, cfg: dict) -> None:
    kinds = {box[0] for box in boxes(data, 0, len(data), lenient=True)[0]}
    if b"moov" not in kinds or not kinds & {b"mdat", b"moof"}:
        raise Invalid("faltan las cajas moov/mdat")
    try:
        video, audio, _ = _streams(ffmpeg.probe(data, "mp4", cfg["stego_timeout_s"]))
    except ffmpeg.ToolError as exc:
        raise Invalid(str(exc)) from None
    if (
        not video
        or video[0].get("codec_name") != "h264"
        or any(a.get("codec_name") != "aac" for a in audio)
    ):
        raise Invalid("solo video H.264 con audio AAC")


def unreferenced_mdat_bytes(data: bytes, top: list[tuple], packets: list[dict]) -> int:
    """Bytes de los mdat que no pertenecen a ningún paquete de audio o video."""
    spans = sorted(
        (int(p["pos"]), int(p["pos"]) + int(p["size"]))
        for p in packets
        if int(p.get("pos", -1)) >= 0
    )
    total = 0
    for kind, _, body, end in top:
        if kind != b"mdat":
            continue
        covered, cursor = 0, body
        for start, stop in spans:
            start, stop = max(start, cursor), min(stop, end)
            if stop > start:
                covered += stop - start
                cursor = stop
        total += (end - body) - covered
    return total


def analyze(data: bytes, cfg: dict) -> dict:
    found = structure(data)
    info = ffmpeg.probe(data, "mp4", cfg["stego_timeout_s"], packets=True)
    video, audio, others = _streams(info)
    unreferenced = unreferenced_mdat_bytes(data, found.pop("top"), info.get("packets", []))
    covers = found.pop("covers")
    reasons = []
    if found["trailing_bytes"]:
        reasons.append("datos después de la última caja")
    if found["unknown_boxes"]:
        reasons.append("cajas desconocidas")
    if found["metadata_bytes"] > 65536:
        reasons.append("metadatos excesivos")
    if found["padding_nonzero_bytes"] > 1024:
        reasons.append("relleno con datos")
    if unreferenced > 4096:
        reasons.append("bytes del mdat sin referenciar")
    if len(video) > 1 or len(audio) > 1 or others:
        reasons.append("flujos adicionales")
    for cover in covers:
        reasons += [f"carátula: {reason}" for reason in analyze_embedded(cover, cfg)]
    metrics = {
        **found,
        "unreferenced_mdat_bytes": unreferenced,
        "streams": len(info.get("streams", [])),
    }
    return verdict("mp4", reasons, metrics)


def sanitize(data: bytes, cfg: dict) -> bytes:
    """Remultiplexa sin recodificar: un video y un audio, sin metadatos, capítulos ni cajas extra.
    Los payloads dentro del flujo de video sobreviven (limitación declarada, spec §3)."""
    video, audio, _ = _streams(ffmpeg.probe(data, "mp4", cfg["sanitize_timeout_s"]))
    maps = ["-map", f"0:{video[0]['index']}"] + (
        ["-map", f"0:{audio[0]['index']}"] if audio else []
    )
    return ffmpeg.convert(
        data,
        "mp4",
        [
            *maps,
            "-c",
            "copy",
            "-map_metadata",
            "-1",
            "-map_chapters",
            "-1",
            "-fflags",
            "+bitexact",
            "-flags:v",
            "+bitexact",
            "-flags:a",
            "+bitexact",
            "-movflags",
            "+faststart",
            "-f",
            "mp4",
        ],
        cfg["sanitize_timeout_s"],
    )


FORMAT = Format("video/mp4", "mp4", "video", detect, validate, analyze, sanitize)

def _open(data: bytes) -> pikepdf.Pdf:
    try:
        pdf = pikepdf.open(io.BytesIO(data))
    except (pikepdf.PdfError, pikepdf.PasswordError) as exc:
        raise Invalid(f"PDF inválido: {exc}") from None
    if pdf.is_encrypted:
        pdf.close()
        raise Invalid("PDF cifrado")
    return pdf


def validate(data: bytes, cfg: dict) -> None:
    with _open(data) as pdf:
        if len(pdf.pages) == 0:
            raise Invalid("PDF sin páginas")


def _name(value) -> str | None:
    return str(value) if isinstance(value, pikepdf.Name) else None


def walk(pdf: pikepdf.Pdf) -> tuple[set[tuple[int, int]], set[str]]:
    """Objetos alcanzables desde el trailer y contenido activo encontrado en el camino."""
    seen: set[tuple[int, int]] = set()
    active: set[str] = set()
    stack = [pdf.trailer]
    while stack:
        obj = stack.pop()
        if not isinstance(
            obj, pikepdf.Object
        ):  # pikepdf entrega números y booleanos como tipos de Python
            continue
        if obj.is_indirect:
            if obj.objgen in seen:
                continue
            seen.add(obj.objgen)
        if isinstance(obj, pikepdf.Array):
            stack.extend(obj)
        elif isinstance(obj, (pikepdf.Dictionary, pikepdf.Stream)):
            keys = set(obj.keys())
            active.update(reason for key, reason in ACTIVE_KEYS.items() if key in keys)
            action, subtype, kind = (
                _name(obj.get("/S")),
                _name(obj.get("/Subtype")),
                _name(obj.get("/Type")),
            )
            if action in ACTIVE_ACTIONS:
                active.add(ACTIVE_ACTIONS[action])
            if subtype in ACTIVE_SUBTYPES:
                active.add(ACTIVE_SUBTYPES[subtype])
            if kind == "/EmbeddedFile":
                active.add("archivos incrustados")
            stack.extend(obj[key] for key in keys)
    return seen, active


def _size(obj: pikepdf.Object) -> int:
    return (
        len(obj.read_raw_bytes())
        if isinstance(obj, pikepdf.Stream)
        else len(obj.unparse(resolved=True))
    )


def analyze(data: bytes, cfg: dict) -> dict:
    with _open(data) as pdf:
        reachable, active = walk(pdf)
        orphan_bytes = sum(
            _size(obj)
            for obj in pdf.objects
            if obj.objgen not in reachable and obj.objgen != (0, 0)
        )
        info = pdf.trailer.get("/Info")
        metadata = (_size(info) if info is not None else 0) + (
            _size(pdf.Root.Metadata) if "/Metadata" in pdf.Root else 0
        )
    trailing = len(data) - (data.rfind(b"%%EOF") + 5)
    reasons = []
    if trailing > 2:
        reasons.append("datos después de %%EOF")
    if orphan_bytes > 1024:
        reasons.append("objetos huérfanos")
    if metadata > 65536:
        reasons.append("metadatos excesivos")
    metrics = {
        "trailing_bytes": trailing,
        "orphan_bytes": orphan_bytes,
        "metadata_bytes": metadata,
        "revisions": data.count(b"%%EOF"),
    }
    return verdict("pdf", reasons, metrics, sorted(active))


def sanitize(data: bytes, cfg: dict) -> bytes:
    """Reescritura completa: qpdf solo escribe objetos alcanzables (sin huérfanos, revisiones
    anteriores ni datos tras %%EOF) y se quitan el diccionario Info y los metadatos XMP."""
    with _open(data) as pdf:
        if "/Info" in pdf.trailer:
            del pdf.trailer["/Info"]
        if "/Metadata" in pdf.Root:
            del pdf.Root["/Metadata"]
        out = io.BytesIO()
        pdf.save(out, deterministic_id=True)
    return out.getvalue()


FORMAT = Format("application/pdf", "pdf", "document", detect, validate, analyze, sanitize)

        return etree.fromstring(raw, PARSER)

def _content_types(archive: zipfile.ZipFile) -> tuple[dict, dict]:

def validate(data: bytes, cfg: dict) -> None:
    try:
        with zipfile.ZipFile(io.BytesIO(data)) as archive:
            infos = archive.infolist()
            names = [info.filename for info in infos]
            if len(infos) > MAX_ENTRIES or len(set(names)) != len(names):
                raise Invalid("demasiadas entradas o entradas duplicadas")
            if sum(info.file_size for info in infos) > MAX_UNCOMPRESSED:
                raise Invalid("demasiado grande al descomprimir")
            for info in infos:
                parts = info.filename.split("/")

                    info.flag_bits & 0x1
                    or info.filename.startswith("/")
                    or "\\" in info.filename
                    or ".." in parts

                    raise Invalid("entrada cifrada o con ruta no permitida")
                if info.compress_size and info.file_size / info.compress_size > MAX_RATIO:
                    raise Invalid("tasa de compresión de bomba")
            if archive.testzip() is not None:
                raise Invalid("CRC inválido")

def outside_bytes(data: bytes, archive: zipfile.ZipFile) -> int:
    """Bytes que no pertenecen a ninguna entrada, al directorio central ni al registro de fin."""
    eocd = data.rfind(b"PK\x05\x06")
    comment = int.from_bytes(data[eocd + 20 : eocd + 22], "little")
    cd_size, cd_offset = (
        int.from_bytes(data[eocd + 12 : eocd + 16], "little"),
        int.from_bytes(data[eocd + 16 : eocd + 20], "little"),
    )
    spans = [(cd_offset, cd_offset + cd_size), (eocd, eocd + 22 + comment)]
    for info in archive.infolist():
        start = info.header_offset
        local = (
            start
            + 30
            + int.from_bytes(data[start + 26 : start + 28], "little")
            + int.from_bytes(data[start + 28 : start + 30], "little")
        )
        end = local + info.compress_size
        if info.flag_bits & 0x08:  # descriptor de datos tras la entrada
            end += 16 if data[end : end + 4] == b"PK\x07\x08" else 12
        spans.append((start, end))
    covered, cursor = 0, 0
    for start, end in sorted(spans):
        start = max(start, cursor)
        if end > start:
            covered, cursor = covered + end - start, end
    return len(data) - covered

            for name in sorted(seen)
            if name.startswith(TEXT_PARTS) and name.endswith(".xml")
            for run in _hidden(_xml(archive, name))
        ),
        "custom_metadata_bytes": custom_metadata(archive, names),
        "images": sum(1 for n in seen if n.startswith("word/media/")),
    }


RULES = (
    ("outside_bytes", "bytes fuera de las entradas del ZIP"),
    ("comment_bytes", "comentario del ZIP"),
    ("unknown_extra_fields", "campos extra en las entradas"),
    ("unreferenced_parts", "partes sin relación"),
    ("hidden_chars", "texto oculto"),
)


def analyze(data: bytes, cfg: dict) -> dict:
    with zipfile.ZipFile(io.BytesIO(data)) as archive:
        names = {name for name in archive.namelist() if not name.endswith("/")}
        seen, rels = reachable(archive)
        defaults, overrides = _content_types(archive)
        active = active_content(names, rels, [*defaults.values(), *overrides.values()])
        found = measure(data, archive, names, seen)
        image_reasons = [
            f"imagen {posixpath.basename(n)}: {r}"
            for n in sorted(n for n in seen if n.startswith("word/media/"))
            for r in analyze_embedded(archive.read(n), cfg)
        ]
    reasons = [reason for key, reason in RULES if found[key]]
    if found["custom_metadata_bytes"] > 65536:
        reasons.append("metadatos personalizados excesivos")
    return verdict("docx", reasons + image_reasons, found, active)


def _serialize(root: etree._Element) -> bytes:
    return etree.tostring(root, xml_declaration=True, encoding="UTF-8", standalone=True)


def _without_dropped_overrides(archive, name: str, dropped: set[str]) -> bytes:
    root = _xml(archive, name)
    for override in list(root.iter(f"{CT}Override")):
        if override.get("PartName", "").lstrip("/") in dropped:
            root.remove(override)
    return _serialize(root)


def _without_dropped_relationships(archive, name: str, dropped: set[str]) -> bytes:
    root, source = _xml(archive, name), _source_of(name)
    for rel in list(root.iter(f"{REL}Relationship")):
        target_part = posixpath.normpath(
            posixpath.join(posixpath.dirname(source), rel.get("Target", ""))
        )
        if rel.get("TargetMode") != "External" and target_part.lstrip("/") in dropped:
            root.remove(rel)
    return _serialize(root)


def _without(archive, name: str, elements) -> bytes:
    """La parte XML sin los elementos que devuelve `elements(root)`."""
    root = _xml(archive, name)
    for element in list(elements(root)):
        element.getparent().remove(element)
    return _serialize(root)


def clean_part(archive, name: str, dropped: set[str], cfg: dict) -> bytes:
    from media_svc.formats import IMAGES  # import tardío: el registro importa este módulo

    payload = archive.read(name)
    if name == "[Content_Types].xml":
        return _without_dropped_overrides(archive, name, dropped)
    if name.endswith(".rels"):
        return _without_dropped_relationships(archive, name, dropped)
    if name in ("docProps/core.xml", "docProps/app.xml"):
        return CORE if name.endswith("core.xml") else APP
    if name == "word/settings.xml":
        return _without(archive, name, lambda root: root.iter(f"{W}docVars"))
    if name.startswith(TEXT_PARTS) and name.endswith(".xml"):
        return _without(archive, name, _hidden)
    if name.startswith("word/media/"):
        image = next((fmt for fmt in IMAGES if fmt.detect(payload)), None)
        return image.sanitize(payload, cfg) if image is not None else payload
    return payload


def sanitize(data: bytes, cfg: dict) -> bytes:
    """Reconstruye el ZIP solo con las partes alcanzables; quita metadatos, texto oculto y variables
    de documento; sanitiza cada imagen con su formato. El ZIP nuevo no tiene comentario ni extras."""
    with zipfile.ZipFile(io.BytesIO(data)) as archive:
        seen, _ = reachable(archive)
        dropped = {
            n
            for n in seen
            if n == "docProps/custom.xml" or n.startswith(("customXml/", "docProps/thumbnail"))
        }
        keep = (seen - dropped - {_rels_name(n) for n in dropped}) & set(archive.namelist())
        out = io.BytesIO()
        with zipfile.ZipFile(out, "w", zipfile.ZIP_DEFLATED) as target:
            for name in sorted(keep, key=lambda n: (n != "[Content_Types].xml", n)):
                info = zipfile.ZipInfo(name, date_time=(1980, 1, 1, 0, 0, 0))
                info.compress_type = zipfile.ZIP_DEFLATED
                target.writestr(info, clean_part(archive, name, dropped, cfg))
    return out.getvalue()

"""TXT (UTF-8): caracteres invisibles, selectores, espacios finales y homoglifos (spec §12.8, §12.9)."""

import unicodedata

from media_svc.formats.base import Format, Invalid, verdict
from shared import text

ALLOWED_CONTROLS = {"\t", "\n", "\r"}


def _decode(data: bytes) -> str | None:
    """Texto si es UTF-8 estricto y no tiene controles salvo \\t, \\n y \\r; si no, None (es binario)."""
    try:
        decoded = data.decode("utf-8")
    except UnicodeDecodeError:
        return None
    if any(unicodedata.category(c) == "Cc" and c not in ALLOWED_CONTROLS for c in decoded):
        return None
    return decoded


def detect(data: bytes) -> bool:
    """Sin firma: se prueba al final del registro, después de todos los formatos binarios."""
    return bool(data) and _decode(data) is not None


def validate(data: bytes, cfg: dict) -> None:
    if _decode(data) is None:
        raise Invalid("no es texto UTF-8")


def analyze(data: bytes, cfg: dict) -> dict:
    found = text.scan(_decode(data) or "")
    reasons = []
    if found["invisible"]:
        reasons.append("caracteres invisibles")
    if found["extra_selectors"]:
        reasons.append("selectores de variación encadenados")
    if found["trailing_tabs"] or found["trailing_spaces"] > cfg["txt_trailing"]:
        reasons.append("espacios al final de línea")
    if found["mixed_script_words"]:
        reasons.append("homoglifos")
    return verdict("txt", reasons, found)


def sanitize(data: bytes, cfg: dict) -> bytes:
    """UTF-8 sin BOM, saltos \\n, sin invisibles, selectores sobrantes ni espacios finales."""
    return text.clean(_decode(data) or "")[0].encode("utf-8")


FORMAT = Format("text/plain; charset=utf-8", "txt", "text", detect, validate, analyze, sanitize)
```

"""Tiempo de análisis y sanitización por formato (spec §21; RNF-03).

python services/media/tools/bench_formats.py <carpeta> [--runs 5]
    Mide cada archivo de la carpeta (usa ejemplos reales del tamaño máximo de cada categoría) y
    reporta el percentil 95 por formato. Falla (código 1) si alguno supera su objetivo:
    validación + análisis ≤ STEGO_TIMEOUT_S (10 s) y sanitización ≤ SANITIZE_TIMEOUT_S (30 s).
"""

import argparse
import statistics
import sys
import time
from collections import defaultdict
from pathlib import Path

from media_svc import formats
from media_svc.config import Settings

SETTINGS = Settings(database_url="", url_signing_key=b"\x00" * 32)
CFG = SETTINGS.format_config


def timed(function, *args) -> float:
    started = time.perf_counter()
    function(*args)
    return time.perf_counter() - started


def inspect(fmt, data: bytes) -> None:
    fmt.validate(data, CFG)
    fmt.analyze(data, CFG)


def p95(values: list[float]) -> float:
    ordered = sorted(values)
    return ordered[min(len(ordered) - 1, int(0.95 * len(ordered)))]


def measure(folder: Path, runs: int) -> dict[str, dict[str, list[float]]]:
    found: dict[str, dict[str, list[float]]] = defaultdict(lambda: defaultdict(list))
    for path in sorted(p for p in folder.iterdir() if p.is_file()):
        data = path.read_bytes()
        fmt = formats.detect(data)
        if fmt is None or len(data) > SETTINGS.max_bytes(fmt.category):
            print(f"se omite {path.name}: formato no permitido o supera el tope", file=sys.stderr)
            continue
        for _ in range(runs):
            found[fmt.ext]["análisis"].append(timed(inspect, fmt, data))
            found[fmt.ext]["sanitización"].append(timed(fmt.sanitize, data, CFG))
    return found


def main() -> None:
    parser = argparse.ArgumentParser(description="Tiempos por formato (RNF-03)")
    parser.add_argument("folder")
    parser.add_argument("--runs", type=int, default=5)
    args = parser.parse_args()
    limits = {"análisis": SETTINGS.stego_timeout_s, "sanitización": SETTINGS.sanitize_timeout_s}
    failed = False
    print("formato | etapa | n | mediana (s) | p95 (s) | objetivo (s)")
    for ext, stages in sorted(measure(Path(args.folder), args.runs).items()):
        for stage, values in stages.items():
            ok = p95(values) <= limits[stage]
            failed |= not ok
            print(
                f"{ext} | {stage} | {len(values)} | {statistics.median(values):.2f} | "
                f"{p95(values):.2f} | {limits[stage]:.0f}{'' if ok else '  ← SUPERA'}"
            )
    sys.exit(1 if failed else 0)


if __name__ == "__main__":
    main()
```
