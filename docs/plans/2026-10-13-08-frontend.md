# 08 · Frontend (SPA) — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Interfaz web con tres partes:
- **Participante:** entrar a una sala; chatear por WebSocket con el protocolo cifrado (hello firmado, ECDH, AES-GCM); subir y ver imágenes.
- **Admin:** login con TOTP; gestión de salas; auditoría con verificación de la cadena; cuarentena.
- **Cripto:** interopera con Python según los vectores compartidos.

**Architecture:** React 19 + Vite + TypeScript estricto, sin librería de UI.
- `src/lib/crypto.ts` concentra toda la WebCrypto.
- `src/lib/ws.ts` maneja una conexión: handshake, colas de entrada y salida ordenadas, reconexión.
- `src/lib/api.ts` es la única puerta HTTP (cookies HttpOnly, errores `{"error"}`).
- `src/lib/chatEvents.ts` es un reductor puro de eventos del chat, con su test.
- La sesión de sala vive solo en memoria (estado de React). La SPA la sirve el gateway.

**Tech Stack:** Node 24 LTS, React 19, react-router 7, Vite, TypeScript ≥ 5.7, vitest.

**Spec:** `docs/specs/2026-10-12-chat-seguro-design.md` §8.1, §9.4–§9.7, §10, §13 (CSP), §17 (reglas del frontend).

## Global Constraints

Las del índice (`2026-10-13-00-indice.md`) y `.claude/rules/frontend.md`:
- Nunca `dangerouslySetInnerHTML`.
- Claves `CryptoKey` no extraíbles y solo en memoria.
- Nada en `localStorage`/`sessionStorage`.
- Sin estilos ni scripts inline (CSP).
- Sin `StrictMode`.
- `wss://${location.host}/ws`, nunca `ws://`.
- Textos de UI en español.
- Mensaje ≤ 2000 caracteres (`maxLength` del textarea).
- Commits en español, sin atribución.

## Review Focus

- **#1 Mensajes largos:** el `<textarea>` usa `maxLength={2000}` (cuenta unidades UTF-16, así que nunca supera los 2000 caracteres que valida el servidor).
- **#5 Recargar la pestaña:** la sesión no se persiste; al recargar se vuelve a `/` y hay que entrar de nuevo. Es intencional (spec §9.3).

`frontend/src/lib/crypto.ts`:
```ts
/** Protocolo del chat en el navegador (spec §10). Toda la criptografía de la SPA pasa por aquí. */
export const PROTOCOL = "secure-chat/v1";
export type Dir = "c2s" | "s2c";
export type Frame = { seq: number; n: string; c: string };

const encoder = new TextEncoder();
const decoder = new TextDecoder();
const ECDH = { name: "ECDH", namedCurve: "P-256" } as const;
const ECDSA = { name: "ECDSA", namedCurve: "P-256" } as const;

/** Bytes UTF-8 respaldados por un ArrayBuffer propio (lo que espera WebCrypto). */
export function utf8(text: string): Uint8Array<ArrayBuffer> {
  return new Uint8Array(encoder.encode(text));
}

export function b64e(bytes: Uint8Array): string {
  let binary = "";
  for (const byte of bytes) binary += String.fromCharCode(byte);
  return btoa(binary).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

export function b64d(text: string): Uint8Array<ArrayBuffer> {
  const normalized = text.replace(/-/g, "+").replace(/_/g, "/");
  const binary = atob(normalized + "=".repeat((4 - (normalized.length % 4)) % 4));
  return Uint8Array.from(binary, (char) => char.charCodeAt(0));
}

/** Par ECDH efímero; la clave privada no es extraíble. */
export function generateKeyPair(): Promise<CryptoKeyPair> {
  return crypto.subtle.generateKey(ECDH, false, ["deriveBits"]);
}

export async function exportPublic(key: CryptoKey): Promise<string> {
  return b64e(new Uint8Array(await crypto.subtle.exportKey("raw", key)));
}

export function helloTranscript(roomId: string, sessionId: string, clientPub: string, serverPub: string, salt: string) {
  return utf8(`${PROTOCOL}/hello|${roomId}|${sessionId}|${clientPub}|${serverPub}|${salt}`);
}

export function importSigningKey(publicB64: string): Promise<CryptoKey> {
  return crypto.subtle.importKey("raw", b64d(publicB64), ECDSA, false, ["verify"]);
}

/** Firma ECDSA P-256/SHA-256 en formato P1363 (r‖s), el mismo que produce chat. */
export function verifyHello(signingKey: CryptoKey, signatureB64: string, transcript: Uint8Array<ArrayBuffer>): Promise<boolean> {
  return crypto.subtle.verify({ name: "ECDSA", hash: "SHA-256" }, signingKey, b64d(signatureB64), transcript);
}

export async function deriveSessionKey(
  privateKey: CryptoKey,
  serverPubB64: string,
  saltB64: string,
  roomId: string,
  sessionId: string,
): Promise<CryptoKey> {
  const serverPub = await crypto.subtle.importKey("raw", b64d(serverPubB64), ECDH, false, []);
  const shared = await crypto.subtle.deriveBits({ name: "ECDH", public: serverPub }, privateKey, 256);
  const hkdf = await crypto.subtle.importKey("raw", shared, "HKDF", false, ["deriveKey"]);
  return crypto.subtle.deriveKey(
    { name: "HKDF", hash: "SHA-256", salt: b64d(saltB64), info: utf8(`${PROTOCOL}|${roomId}|${sessionId}`) },
    hkdf,
    { name: "AES-GCM", length: 256 },
    false,
    ["encrypt", "decrypt"],
  );
}

function frameAad(roomId: string, sessionId: string, seq: number, dir: Dir) {
  return utf8(`v1|${roomId}|${sessionId}|${seq}|${dir}`);
}

export async function encryptFrame(
  key: CryptoKey,
  roomId: string,
  sessionId: string,
  seq: number,
  dir: Dir,
  payload: unknown,
  nonce?: Uint8Array<ArrayBuffer>,
): Promise<Frame> {
  const iv = nonce ?? crypto.getRandomValues(new Uint8Array(12));
  const ciphertext = await crypto.subtle.encrypt(
    { name: "AES-GCM", iv, additionalData: frameAad(roomId, sessionId, seq, dir) },
    key,
    utf8(JSON.stringify(payload)),
  );
  return { seq, n: b64e(iv), c: b64e(new Uint8Array(ciphertext)) };
}

export async function decryptFrame(
  key: CryptoKey,
  roomId: string,
  sessionId: string,
  dir: Dir,
  frame: Frame,
): Promise<Record<string, unknown>> {
  const plaintext = await crypto.subtle.decrypt(
    { name: "AES-GCM", iv: b64d(frame.n), additionalData: frameAad(roomId, sessionId, frame.seq, dir) },
    key,
    b64d(frame.c),
  );
  return JSON.parse(decoder.decode(plaintext)) as Record<string, unknown>;
}
```

```ts
export class ApiError extends Error {
  readonly status: number;

  constructor(status: number, message: string) {
    super(message);
    this.status = status;
  }
}

type Options = { method?: string; json?: unknown; body?: BodyInit };

/** Única puerta HTTP de la SPA: cookies HttpOnly del mismo origen y errores {"error"} del backend. */
export async function api<T = void>(path: string, options: Options = {}): Promise<T> {
  const { method = "GET", json, body } = options;
  const response = await fetch(`/api${path}`, {
    method,
    credentials: "same-origin",
    headers: json === undefined ? undefined : { "content-type": "application/json" },
    body: json === undefined ? body : JSON.stringify(json),
  });
  if (!response.ok) {
    const data = (await response.json().catch(() => ({}))) as { error?: string };
    throw new ApiError(response.status, data.error ?? "error de red");
  }
  if (response.status === 204) return undefined as T;
  return (await response.json()) as T;
}

export function errorText(error: unknown): string {
  return error instanceof ApiError ? error.message : "no se pudo conectar con el servidor";
}
```

```tsx
import { type FormEvent, useState } from "react";
import { useNavigate } from "react-router";
import { api, errorText } from "../lib/api";

export default function AdminLogin() {
  const navigate = useNavigate();
  const [step, setStep] = useState<"password" | "totp">("password");
  const [error, setError] = useState("");

  async function submitPassword(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setError("");
    const form = new FormData(event.currentTarget);
    try {
      await api("/auth/login", {
        method: "POST",
        json: { username: form.get("username"), password: form.get("password") },
      });
      setStep("totp");
    } catch (err) {
      setError(errorText(err));
    }
  }

  async function submitCode(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setError("");
    const form = new FormData(event.currentTarget);
    try {
      await api("/auth/totp", { method: "POST", json: { code: form.get("code") } });
      navigate("/admin");
    } catch (err) {
      setError(errorText(err));
    }
  }

  return (
    <main className="card">
      <h1>Administración</h1>
      {step === "password" ? (
        <form key="password" onSubmit={submitPassword}>
          <label>
            Usuario
            <input name="username" required autoComplete="username" />
          </label>
          <label>
            Contraseña
            <input name="password" type="password" required autoComplete="current-password" />
          </label>
          <button>Continuar</button>
        </form>
      ) : (
        <form key="totp" onSubmit={submitCode}>
          <label>
            Código de tu app autenticadora
            <input name="code" required inputMode="numeric" pattern="\d{6}" maxLength={6} autoComplete="one-time-code" />
          </label>
          <button>Entrar</button>
        </form>
      )}
      {error && (
        <p className="error" role="alert">
          {error}
        </p>
      )}
    </main>
  );
}
```

```ts
import {
  type Frame,
  decryptFrame,
  deriveSessionKey,
  encryptFrame,
  exportPublic,
  generateKeyPair,
  helloTranscript,
  importSigningKey,
  verifyHello,
} from "./crypto";

export type Mode = "text" | "media" | "both";
export type Session = { sessionId: string; roomId: string; roomCode: string; mode: Mode; alias: string };
export type ChatMessage = { t: "msg"; id: number; from: string; body: string; ts: string };
export type ChatFile = { t: "file"; id: string; from: string; url: string; ts: string };
export type ChatEvent =
  | ChatMessage
  | ChatFile
  | { t: "file_url"; file_id: string; url: string }
  | { t: "system"; event: "join" | "leave"; alias: string }
  | { t: "history"; items: Array<ChatMessage | ChatFile> };
type Outgoing = { t: "msg"; body: string } | { t: "file_url"; file_id: string };
type Handlers = { onReady: () => void; onEvent: (event: ChatEvent) => void; onClose: (code: number) => void };

let signingKey: Promise<CryptoKey> | null = null;

/** Clave pública de firma del chat: la sirve el propio gateway, no viaja por la red interna (spec §10.1). */
function chatSigningKey(): Promise<CryptoKey> {
  signingKey ??= fetch("/chat-key.json", { credentials: "omit" })
    .then(async (response) => {
      if (!response.ok) throw new Error("sin clave de firma del chat");
      const { pub } = (await response.json()) as { pub: string };
      return importSigningKey(pub);
    })
    .catch((error: unknown) => {
      signingKey = null; // reintentar en la próxima conexión
      throw error;
    });
  return signingKey;
}

export class ChatConnection {
  private ws: WebSocket | null = null;
  private key: CryptoKey | null = null;
  private sendSeq = 0;
  private recvSeq = 0;
  private incoming: Promise<void> = Promise.resolve();
  private outgoing: Promise<void> = Promise.resolve();
  private readonly session: Session;
  private readonly handlers: Handlers;

  constructor(session: Session, handlers: Handlers) {
    this.session = session;
    this.handlers = handlers;
  }

  /** Abre (o reabre) la conexión. Cada conexión hace su handshake y tiene su propia clave. */
  open(): void {
    const ws = new WebSocket(`wss://${location.host}/ws`);
    const pair = generateKeyPair();
    let clientPub = "";
    this.ws = ws;
    this.key = null;
    this.sendSeq = 0;
    this.recvSeq = 0;
    ws.onopen = () => {
      this.incoming = this.incoming.then(async () => {
        clientPub = await exportPublic((await pair).publicKey);
        ws.send(JSON.stringify({ t: "hello", pub: clientPub }));
      });
    };
    ws.onmessage = (message) => {
      const raw = String(message.data);
      // Las tramas se procesan en orden: el descifrado es asíncrono y el seq debe crecer.
      this.incoming = this.incoming
        .then(() => (this.key ? this.handleFrame(raw) : this.handleHello(raw, pair, clientPub)))
        .catch(() => ws.close(4400));
    };
    ws.onclose = (event) => {
      if (this.ws === ws) this.handlers.onClose(event.code);
    };
  }

  private async handleHello(raw: string, pair: Promise<CryptoKeyPair>, clientPub: string): Promise<void> {
    const hello = JSON.parse(raw) as { t?: string; pub: string; salt: string; sig: string };
    if (hello.t !== "hello") throw new Error("se esperaba el hello del servidor");
    const { roomId, sessionId } = this.session;
    // La firma cubre NUESTRA clave pública: si alguien la sustituyó en el camino, no valida.
    const transcript = helloTranscript(roomId, sessionId, clientPub, hello.pub, hello.salt);
    if (!(await verifyHello(await chatSigningKey(), hello.sig, transcript))) {
      throw new Error("la firma del servidor no es válida");
    }
    this.key = await deriveSessionKey((await pair).privateKey, hello.pub, hello.salt, roomId, sessionId);
    this.handlers.onReady();
  }

  private async handleFrame(raw: string): Promise<void> {
    const key = this.key;
    const frame = JSON.parse(raw) as Frame;
    if (!key || !(frame.seq > this.recvSeq)) throw new Error("trama fuera de orden o repetida");
    const payload = await decryptFrame(key, this.session.roomId, this.session.sessionId, "s2c", frame);
    this.recvSeq = frame.seq;
    this.handlers.onEvent(payload as unknown as ChatEvent);
  }

  send(payload: Outgoing): void {
    const ws = this.ws;
    const key = this.key;
    if (!ws || !key) return;
    this.outgoing = this.outgoing.then(async () => {
      this.sendSeq += 1;
      const frame = await encryptFrame(key, this.session.roomId, this.session.sessionId, this.sendSeq, "c2s", payload);
      if (ws.readyState === WebSocket.OPEN) ws.send(JSON.stringify(frame));
    });
  }

  close(): void {
    const ws = this.ws;
    this.ws = null;
    ws?.close(1000);
  }
}
```

```ts
import type { ChatEvent, ChatFile, ChatMessage } from "./ws";

export type Item =
  | { kind: "msg"; id: number; from: string; body: string; ts: string }
  | { kind: "file"; id: string; from: string; url: string; ts: string }
  | { kind: "system"; key: string; text: string };

let systemCounter = 0;

function toItem(event: ChatMessage | ChatFile): Item {
  return event.t === "msg"
    ? { kind: "msg", id: event.id, from: event.from, body: event.body, ts: event.ts }
    : { kind: "file", id: event.id, from: event.from, url: event.url, ts: event.ts };
}

/** Reductor puro: estado de la conversación + evento del servidor → nuevo estado. */
export function apply(items: Item[], event: ChatEvent): Item[] {
  switch (event.t) {
    case "history":
      return event.items.map(toItem);
    case "msg":
    case "file":
      return [...items, toItem(event)];
    case "file_url":
      return items.map((item) => (item.kind === "file" && item.id === event.file_id ? { ...item, url: event.url } : item));
    case "system":
      systemCounter += 1;
      return [
        ...items,
        { kind: "system", key: `system-${systemCounter}`, text: `${event.alias} ${event.event === "join" ? "entró" : "salió"}` },
      ];
  }
}
```

```tsx
  const [notice, setNotice] = useState("");
  const refreshed = useRef(new Set<string>());

  async function uploadImage(event: ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    event.target.value = "";
    if (!file) return;
    const body = new FormData();
    body.append("file", file);
    try {
      const result = await api<{ status: "clean" | "quarantined" }>("/media/files", { method: "POST", body });
      setNotice(result.status === "quarantined" ? "El archivo quedó retenido para revisión." : "");
    } catch (err) {
      setNotice(errorText(err));
    }
  }

  function renewUrl(fileId: string) {
    if (refreshed.current.has(fileId)) return; // un solo reintento por imagen
    refreshed.current.add(fileId);
    connection.current?.send({ t: "file_url", file_id: fileId });
  }
```

- [ ] **Step 2: Pestaña de cuarentena**

`frontend/src/pages/admin/QuarantinePanel.tsx`:
```tsx
import { useCallback, useEffect, useState } from "react";
import { api, errorText } from "../../lib/api";

type Quarantined = {
  id: string;
  alias: string;
  mime: string;
  size: number;
  sha256: string;
  verdict: { reasons?: string[] };
  created_at: string;
};

export default function QuarantinePanel() {
  const [files, setFiles] = useState<Quarantined[]>([]);
  const [error, setError] = useState("");
  const load = useCallback(
    () => api<Quarantined[]>("/admin/quarantine").then(setFiles).catch((err: unknown) => setError(errorText(err))),
    [],
  );

  useEffect(() => {
    void load();
  }, [load]);

  async function act(file: Quarantined, action: "release" | "delete") {
    const question =
      action === "release"
        ? `¿Liberar la imagen de ${file.alias}? Se sanitizará y se publicará en su sala.`
        : `¿Eliminar definitivamente la imagen de ${file.alias}?`;
    if (!window.confirm(question)) return;
    try {
      await api(action === "release" ? `/admin/quarantine/${file.id}/release` : `/admin/quarantine/${file.id}`, {
        method: action === "release" ? "POST" : "DELETE",
      });
      await load();
    } catch (err) {
      setError(errorText(err));
    }
  }

  return (
    <section>
      {error && (
        <p className="error" role="alert">
          {error}
        </p>
      )}
      {files.length === 0 && <p className="muted">No hay archivos en cuarentena.</p>}
      <table>
        <thead>
          <tr>
            <th>Fecha</th>
            <th>Alias</th>
            <th>Tipo</th>
            <th>Tamaño</th>
            <th>Motivos</th>
            <th>SHA-256</th>
            <th />
          </tr>
        </thead>
        <tbody>
          {files.map((file) => (
            <tr key={file.id}>
              <td>{new Date(file.created_at).toLocaleString()}</td>
              <td>{file.alias}</td>
              <td>{file.mime}</td>
              <td>{Math.ceil(file.size / 1024)} KB</td>
              <td>{(file.verdict.reasons ?? []).join(", ")}</td>
              <td title={file.sha256}>{file.sha256.slice(0, 12)}…</td>
              <td>
                <button onClick={() => act(file, "release")}>Liberar</button>{" "}
                <button onClick={() => act(file, "delete")}>Eliminar</button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </section>
  );
}
```
