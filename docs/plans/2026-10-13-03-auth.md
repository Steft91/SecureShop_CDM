# 03 · Servicio `auth` — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dos identidades separadas:
- **Administrador:** usuario + contraseña (Argon2id) + TOTP, con bloqueo y retraso progresivo, sesiones revocables y el endpoint `verify-admin` que usa el gateway (riesgos R4 y R5). El secreto TOTP queda cifrado con una KEK rotable (R2).
- **Cuentas de usuario (rev. 3 y 4):** crear una cuenta es obligatorio para entrar a una sala. Registro con **correo verificado por código**, **alias** elegido en el primer ingreso, login con bloqueo, **una sola sesión activa por cuenta atada al dispositivo**, logout que también corta la sala y el endpoint `verify-user` (R13, R17).

**Architecture:**
- Rutas públicas del admin: `/api/auth/login`, `/totp`, `/logout`, `/me`; de usuarios: `/api/users/register`, `/verify`, `/verify/resend`, `/login`, `/alias`, `/logout`, `/me`. Todas con `require_gateway`.
- Dos rutas internas para el `auth_request` de Nginx: `/internal/verify-admin` y `/internal/verify-user`, con `allow("gateway")`.
- Usuarios y admins viven en tablas, cookies (`__Host-user` / `__Host-admin`) y verificaciones distintas: registrarse nunca crea un admin.
- Sesiones en la tabla `admin_sessions`: etapa `preauth` y luego `full`, con un token nuevo al completar el TOTP.
- Eventos a `audit` vía `AuditClient`; `admin.login.ok`, `user.register`, `user.verify.ok`, `user.login.ok` y `user.alias.set` son obligatorios.
- Los códigos de verificación salen por SMTP hacia el contenedor `mailer` (Mailpit) de la red interna `mail`; auth no tiene salida a internet.
- Un CLI crea admins, otro rota la KEK y otro crea cuentas de carga (E2E-4).

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy async, Alembic, argon2-cffi (vía `shared.passwords`), pyotp, qrcode, pytest.

**Spec:** `docs/specs/2026-10-12-chat-seguro-design.md` §7.1, §8.1–§8.2, §9.1–§9.2, §11, §14.4, §16.4 (R2, R4, R5, R11, R13, R16, R17).

> **Revisión 3 (2026-10-19).** ATH-2 renombra las claves de bloqueo del admin (`admin:<u>` y `admin_ip:<ip>`; así los fallos de usuarios detrás de la misma IP no bloquean al admin) y se agrega **ATH-5: cuentas de usuario**. Si ya ejecutaste ATH-1…ATH-4, solo cambia `login_limits` y sigue con ATH-5.

ATH-1…ATH-4 no cambian. Depende de FND-9 (`UserIdentity.alias`, correlación y métricas).

```python
"""Servicio auth (spec §9.1)."""

import time

import httpx
from fastapi import FastAPI
from sqlalchemy.ext.asyncio import AsyncEngine, create_async_engine

from auth_svc import routes
from auth_svc.config import Settings, load_settings
from shared.audit_client import AuditClient
from shared.service_auth import ServiceAuth, ServiceClient
from shared.web import create_base_app


def create_app(
    settings: Settings | None = None,
    *,
    engine: AsyncEngine | None = None,
    service_auth: ServiceAuth | None = None,
    transport: httpx.AsyncBaseTransport | None = None,
) -> FastAPI:
    settings = settings or load_settings()
    service_auth = service_auth or ServiceAuth.from_secrets("auth", needs_token=True)
    peers = ServiceClient(service_auth, {"audit": settings.audit_url}, transport)
    app = create_base_app(
        title="auth",
        settings=settings,
        engine=engine or create_async_engine(settings.database_url, pool_pre_ping=True),
        service_auth=service_auth,
        audit=AuditClient(peers),
    )
    app.state.peers = peers
    app.state.clock = time.time
    app.include_router(routes.router)
    return app
```

```python
"""Alta de administradores (spec §9.1, paso 7). No existen credenciales por defecto."""

import re
from uuid import uuid4

import pyotp
from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine

from auth_svc.config import Settings
from shared.crypto import seal, totp_aad
from shared.passwords import hash_secret_async, strong_enough

USERNAME_RE = re.compile(r"[a-z0-9_.-]{3,32}")


async def create_admin(engine: AsyncEngine, settings: Settings, audit, username: str, password: str) -> str:
    """Crea el admin y devuelve su secreto TOTP (base32) para mostrarlo una sola vez."""
    username = username.strip().lower()
    if not USERNAME_RE.fullmatch(username):
        raise ValueError("usuario inválido: 3–32 caracteres a-z, 0-9, '_', '.' o '-'")
    if not strong_enough(password, forbid=username):
        raise ValueError(
            "contraseña débil: ≥ 12 caracteres y 3 tipos (minúsculas, mayúsculas, dígitos, símbolos)"
        )
    admin_id, secret = str(uuid4()), pyotp.random_base32()
    password_hash = await hash_secret_async(password)
    async with engine.begin() as conn:
        await conn.execute(
            text(
                "INSERT INTO admins (id, username, password_hash, totp_secret, kek_version) "
                "VALUES (:id, :username, :hash, :totp, :version)"
            ),
            {
                "id": admin_id,
                "username": username,
                "hash": password_hash,
                "totp": seal(settings.kek, secret.encode(), totp_aad(admin_id)),
                "version": settings.current_kek_version,
            },
        )
        await audit.emit("info", "admin.create", actor="system", target=username, required=True)
    return secret
```

```python
"""Crea un administrador e imprime su QR de TOTP (spec §9.1, paso 7).

Uso dentro del contenedor:  python -m auth_svc.create_admin <usuario> [--password-stdin]
"""

import argparse
import asyncio
import sys
from getpass import getpass

import pyotp
import qrcode
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import create_async_engine

from auth_svc.admins import create_admin
from auth_svc.config import load_settings
from shared.audit_client import AuditClient
from shared.service_auth import ServiceAuth, ServiceClient


def read_password(from_stdin: bool) -> str:
    if from_stdin:
        return sys.stdin.readline().rstrip("\n")
    password = getpass("Contraseña: ")
    if password != getpass("Repite la contraseña: "):
        sys.exit("las contraseñas no coinciden")
    return password


async def run(username: str, password: str) -> str:
    settings = load_settings()
    engine = create_async_engine(settings.database_url)
    peers = ServiceClient(ServiceAuth.from_secrets("auth", needs_token=True), {"audit": settings.audit_url})
    try:
        return await create_admin(engine, settings, AuditClient(peers), username, password)
    finally:
        await engine.dispose()


def main() -> None:
```

```python
"""TOTP (RFC 6238) con anti-reuso: un código vale una sola vez (spec §9.1, paso 5)."""

import hmac

import pyotp

STEP_SECONDS = 30


def verify_totp(secret: str, code: str, last_step: int, now: float) -> int | None:
    """Devuelve el paso de tiempo aceptado (ventana ±1) o None. Rechaza pasos ya usados."""
    totp = pyotp.TOTP(secret)
    current = int(now) // STEP_SECONDS
    for step in (current - 1, current, current + 1):
        if step > last_step and hmac.compare_digest(totp.at(step * STEP_SECONDS), code):
            return step
    return None
```

```python
"""Re-envuelve los secretos TOTP con la KEK vigente (spec §11.3).

Procedimiento: montar kek_auth_v{n+1}, poner CURRENT_KEK_VERSION=n+1, reiniciar auth y ejecutar
    docker compose -f deploy/docker-compose.yml exec auth python -m auth_svc.rotate_kek
Después ya se puede retirar el secreto de la versión anterior.
"""

import asyncio

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine, create_async_engine

from auth_svc.config import Settings, load_settings
from shared.audit_client import AuditClient
from shared.crypto import seal, totp_aad, unseal
from shared.service_auth import ServiceAuth, ServiceClient


async def rotate(engine: AsyncEngine, settings: Settings, audit) -> int:
    target = settings.current_kek_version
    async with engine.begin() as conn:
        rows = (
            await conn.execute(
                text("SELECT id, totp_secret, kek_version FROM admins WHERE kek_version <> :v FOR UPDATE"),
                {"v": target},
            )
        ).all()
        for row in rows:
            aad = totp_aad(str(row.id))
            secret = unseal(settings.keks[row.kek_version], bytes(row.totp_secret), aad)
            await conn.execute(
                text("UPDATE admins SET totp_secret = :secret, kek_version = :v WHERE id = :id"),
                {"secret": seal(settings.kek, secret, aad), "v": target, "id": row.id},
            )
        if rows:
            await audit.emit(
                "info", "key.rotate.auth", actor="system", details={"to": target, "admins": len(rows)},
                required=True,
            )
    return len(rows)


async def _main() -> int:
    settings = load_settings()
    engine = create_async_engine(settings.database_url)
    peers = ServiceClient(ServiceAuth.from_secrets("auth", needs_token=True), {"audit": settings.audit_url})
    try:
        return await rotate(engine, settings, AuditClient(peers))
    finally:
        await engine.dispose()


if __name__ == "__main__":
    count = asyncio.run(_main())
    print(f"{count} secretos TOTP re-envueltos con la KEK vigente")
```

  - `POST /api/users/verify {email, code}` → 204 · 400 (`código inválido o vencido`) · 429;
  - `POST /api/users/verify/resend {email}` → 202 · 429;
  - `POST /api/users/login {email, password}` → 200 `{alias}` (`null` si falta elegirlo) + cookie `__Host-user` · 401 · 403 (`cuenta sin verificar…`, solo con la contraseña correcta) · 409 (`la cuenta tiene una sesión activa en otro dispositivo`) · 429 · 503;
  - `POST /api/users/alias {alias}` → 200 `{alias}` · 401 · 409 (ya elegido o no disponible) · 422;
  - `GET /api/users/me` → `{email, alias}` (desliza la inactividad) · 401; `POST /api/users/logout` → 204 (también corta la sala);
  - `GET /internal/verify-user` (solo gateway) → 204 con `X-User-Id` y `X-User-Name` (alias *percent-encoded*) · 401 · 403 (`alias pendiente`);
  - `Settings` suma `rooms_url`, los límites de usuarios y registro, `verify_code_ttl_min=15`, `verify_max_attempts=5`, `verify_max_fails_ip=20`, `resend_max_per_window=3`, `resend_window_min=60`, `smtp_host="mailer"`, `smtp_port=1025` y `mail_from`;

```python
class Outbox:
    """Servidor SMTP falso: guarda los correos; `down = True` simula el servidor caído."""

    def __init__(self) -> None:
        self.messages: list[tuple[str, str, str]] = []
        self.down = False

    async def send(self, to: str, subject: str, body: str) -> None:
        if self.down:
            raise MailUnavailable("smtp caído (simulado)")
        self.messages.append((to, subject, body))

        [body] = [b for to, _, b in self.messages if to == email][-1:]
```

```python
import smtplib
from email.message import EmailMessage

from starlette.concurrency import run_in_threadpool


class MailUnavailable(Exception):
    """No se pudo entregar el correo al servidor SMTP."""


class SmtpMailer:
    def __init__(self, host: str, port: int, sender: str, timeout: float = 5.0) -> None:
        self.host, self.port, self.sender, self.timeout = host, port, sender, timeout

    def _send(self, to: str, subject: str, body: str) -> None:
        message = EmailMessage()
        message["From"], message["To"], message["Subject"] = self.sender, to, subject
        message.set_content(body)
        try:
            with smtplib.SMTP(self.host, self.port, timeout=self.timeout) as smtp:
                smtp.send_message(message)
        except (OSError, smtplib.SMTPException) as exc:
            raise MailUnavailable(str(exc)) from None

    async def send(self, to: str, subject: str, body: str) -> None:
        await run_in_threadpool(self._send, to, subject, body)
```

Decisiones que el código hace cumplir (spec §9.2):
- **Registro sin enumeración:** la respuesta es 202 exista o no la cuenta. Si el correo ya tiene una cuenta verificada, se le avisa por correo y no se toca nada. Si tiene una cuenta **sin** verificar, se renueva con la contraseña nueva y un código nuevo: así nadie bloquea un correo ajeno, porque solo su dueño recibe el código.
- **Código de verificación:** 6 dígitos con `secrets`, guardado como HMAC con la KEK de auth (una copia de la BD no basta para probar los 10⁶ valores), 15 minutos de vigencia y 5 intentos; además, 20 fallos por IP en 15 minutos → 429.
- **Alias:** 3–24 caracteres del alfabeto latino (con tildes y ñ), dígitos, espacios simples, `_`, `.` y `-`. Es único por su forma canónica (sin tildes, mayúsculas ni separadores), así que `Ana.Pérez` y `ana perez` no pueden convivir; se elige una sola vez. Sin cirílico ni griego no hay homoglifos.
- **Logout:** además de terminar la sesión de usuario, pide a `rooms` que termine la sesión de sala y cierre el WebSocket. Si `rooms` no responde, la cuenta igual se cierra y queda la advertencia `user.logout.partial`.

```python
def normalize_email(raw: str) -> str:
    email = raw.strip().lower()
    if len(email) > 254 or not EMAIL_RE.fullmatch(email):
        raise HTTPException(422, "correo inválido")
    return email


def alias_key(alias: str) -> str:
    """Forma canónica para la unicidad: sin tildes, mayúsculas ni separadores ('Ana.Pérez' = 'ana perez')."""
    plain = unicodedata.normalize("NFKD", alias)
    plain = "".join(c for c in plain if not unicodedata.combining(c)).casefold()
    return re.sub(r"[ _.-]", "", plain)


def normalize_alias(raw: str) -> tuple[str, str]:
    alias = unicodedata.normalize("NFC", raw.strip())
    if not 3 <= len(alias) <= 24 or not ALIAS_RE.fullmatch(alias):
        raise HTTPException(
            422, "alias inválido: 3–24 letras, números, espacios simples, '_', '.' o '-'"
        )
    key = alias_key(alias)
    if len(key) < 3 or key in RESERVED:
        raise HTTPException(422, "alias no permitido")
    return alias, key

def code_hash(settings, user_id: str, code: str) -> bytes:
    """HMAC con la KEK de auth: una copia de la BD no basta para probar los 10⁶ códigos."""
    return hmac.new(settings.kek, f"verify|{user_id}|{code}".encode(), "sha256").digest()

    contraseña: así nadie bloquea un correo ajeno, porque solo su dueño recibe el código."""
    settings, audit, code = app.state.settings, app.state.audit, new_code()
    async with app.state.engine.begin() as conn:
        user_id = str(uuid4())
        inserted = (

                    "ON CONFLICT (email) DO NOTHING RETURNING id"

            )
        ).first()
        row = (
            await conn.execute(

            return "verified", None

async def check_code(conn, settings, row, code: str) -> bool:
    """Compara en tiempo constante. Tras VERIFY_MAX_ATTEMPTS fallos el código deja de servir."""
    if row is None or row.verify_code_hash is None:
        return False
    usable = row.fresh and row.verify_attempts < settings.verify_max_attempts
    if usable and hmac.compare_digest(
        bytes(row.verify_code_hash), code_hash(settings, row.id, code)
    ):
        await conn.execute(
            text(
                "UPDATE users SET verified_at = now(), verify_code_hash = NULL, "
                "verify_expires_at = NULL, verify_attempts = 0 WHERE id = :id"
            ),
            {"id": row.id},
        )
        return True
    await conn.execute(
        text("UPDATE users SET verify_attempts = verify_attempts + 1 WHERE id = :id"),
        {"id": row.id},
    )
    return False

async def open_session(conn, settings, user_id: str, device: bytes, token: str) -> bool:
    """Transacción única del riesgo 13. Devuelve False si hay una sesión activa desde otro dispositivo."""
    await conn.execute(
        text(
            "UPDATE user_sessions SET ended_at = now(), end_reason = 'expired' "
            "WHERE user_id = :u AND ended_at IS NULL "
            "AND (expires_at <= now() OR last_seen <= now() - make_interval(mins => :idle))"
        ),
        {"u": user_id, "idle": settings.user_idle_min},
    )
    active = (
        await conn.execute(
            text(
                "SELECT id, device_hash FROM user_sessions WHERE user_id = :u AND ended_at IS NULL FOR UPDATE"
            ),
            {"u": user_id},
        )
    ).first()
    if active is not None and bytes(active.device_hash) != device:
        return False  # R13: política del equipo, se rechaza el ingreso nuevo
    if active is not None:  # mismo dispositivo: la sesión nueva reemplaza a la anterior
        await conn.execute(
            text(
                "UPDATE user_sessions SET ended_at = now(), end_reason = 'replaced' WHERE id = :id"
            ),
            {"id": active.id},
        )
    await conn.execute(
        text(
            "INSERT INTO user_sessions (user_id, token_hash, device_hash, expires_at) "
            "VALUES (:u, :token, :device, now() + make_interval(hours => :hours))"
        ),
        {
            "u": user_id,
            "token": token_hash(token),
            "device": device,
            "hours": settings.user_abs_hours,
        },
    )
    return True

        await audit.emit("warning", "user.login.fail", actor=f"ip:{ip}", target=email, ip=ip)
        await asyncio.sleep(
            min(settings.login_delay_base * 2 ** (fails - 1), 4)
        )  # retraso progresivo
        raise HTTPException(401, "credenciales inválidas")
    return user


@router.post("/api/users/login", dependencies=[Depends(require_gateway)])
async def login(body: Credentials, request: Request, response: Response) -> dict:
    app, ip, device = request.app, client_ip(request), device_hash(request)
    email = body.email.strip().lower()
    user = await check_password(app, email, body.password, ip)
    if user.verified_at is None:  # solo se revela a quien ya probó la contraseña
        await app.state.audit.emit(
            "warning", "user.login.unverified", actor=f"user:{user.id}", ip=ip
        )
        raise HTTPException(403, "cuenta sin verificar: revisa tu correo")
    token, opened = new_token(), False
    try:
        async with app.state.engine.begin() as conn:
            opened = await open_session(conn, app.state.settings, user.id, device, token)
            if opened:
                await app.state.audit.emit(
                    "info", "user.login.ok", actor=f"user:{user.id}", ip=ip, required=True
                )
    except IntegrityError:  # otro login ganó la carrera: el índice único deja una sola sesión
        opened = False
    if not opened:
        await app.state.audit.emit(
            "warning", "user.login.device_conflict", actor=f"user:{user.id}", ip=ip
        )
        raise HTTPException(409, "la cuenta tiene una sesión activa en otro dispositivo")
    set_cookie(response, USER_COOKIE, token)
    return {"alias": user.alias}


async def active_user(request: Request):
    """Sesión vigente (absoluta e inactividad) desde el MISMO dispositivo; desliza last_seen."""
    token, device = request.cookies.get(USER_COOKIE), request.cookies.get(DEVICE_COOKIE)
    if not token or not device:
        return None
    async with request.app.state.engine.begin() as conn:
        return (
            await conn.execute(
                text(
                    "UPDATE user_sessions s SET last_seen = now() FROM users u "
                    "WHERE u.id = s.user_id AND s.token_hash = :hash AND s.device_hash = :device "
                    "AND s.ended_at IS NULL AND s.expires_at > now() "
                    "AND s.last_seen > now() - make_interval(mins => :idle) "
                    "RETURNING u.id::text AS user_id, u.email, u.alias"
                ),
                {
                    "hash": token_hash(token),
                    "device": sha256(device.encode()),
                    "idle": request.app.state.settings.user_idle_min,
                },
            )
        ).first()


async def current_user(request: Request):
    user = await active_user(request)
    if user is None:
        raise HTTPException(401, "no autenticado")
    return user


@router.post("/api/users/alias", dependencies=[Depends(require_gateway)])
async def choose_alias(body: AliasIn, request: Request) -> dict:
    """Primer ingreso: el alias se elige una sola vez y es único (spec §9.2)."""
    user = await current_user(request)
    if user.alias is not None:
        raise HTTPException(409, "el alias ya fue elegido")
    alias, key = normalize_alias(body.alias)
    try:
        async with request.app.state.engine.begin() as conn:
            updated = (
                await conn.execute(
                    text(
                        "UPDATE users SET alias = :alias, alias_key = :key "
                        "WHERE id = :id AND alias IS NULL RETURNING id"
                    ),
                    {"alias": alias, "key": key, "id": user.user_id},
                )
            ).first()
            if updated is not None:

                    actor=f"user:{user.user_id}",
                    details={"alias": alias},
                    required=True,
                )
    except IntegrityError:
        raise HTTPException(409, "alias no disponible") from None
    if updated is None:  # otra pestaña lo eligió primero
        raise HTTPException(409, "el alias ya fue elegido")
    return {"alias": alias}


@router.get("/internal/verify-user", status_code=204, dependencies=[Depends(allow("gateway"))])
async def verify_user(request: Request, response: Response) -> None:

    if user is None:
        ip = client_ip(request)

        raise HTTPException(403, "alias pendiente")

async def end_room_sessions(app, user_id: str) -> None:
    """Cerrar la cuenta también corta la sala y el WebSocket, aunque la SPA no llame a leave."""
    try:
        response = await app.state.peers.post(
            "rooms", f"/internal/users/{user_id}/sessions/end", json={}
        )
        if response.status_code == 204:
            return
    except httpx.HTTPError:
        pass
    log.warning("rooms no confirmó el cierre de las sesiones de sala de %s", user_id)
    await app.state.audit.emit("warning", "user.logout.partial", actor=f"user:{user_id}")


@router.post("/api/users/logout", status_code=204, dependencies=[Depends(require_gateway)])
async def logout(request: Request, response: Response) -> None:
    token, user_id = request.cookies.get(USER_COOKIE), None
    if token:
        async with request.app.state.engine.begin() as conn:
            user_id = (
                await conn.execute(
                    text(
                        "UPDATE user_sessions SET ended_at = now(), end_reason = 'logout' "
                        "WHERE token_hash = :hash AND ended_at IS NULL RETURNING user_id::text"
                    ),
                    {"hash": token_hash(token)},
                )
            ).scalar()
    if user_id:
        await request.app.state.audit.emit(
            "info", "user.logout", actor=f"user:{user_id}", ip=client_ip(request)
        )
        await end_room_sessions(request.app, user_id)
    clear_cookie(response, USER_COOKIE)
```

```python
"""Crea cuentas verificadas y con alias para las pruebas de carga (spec §21; RNF-01, RNF-02, RNF-06).

Solo se ejecuta dentro del contenedor (no hay ruta HTTP): quien puede hacerlo ya administra el
servidor. Las cuentas usan el dominio reservado .test y quedan auditadas como cualquier alta.

Uso:  echo '<contraseña>' | python -m auth_svc.seed_users <prefijo> <cantidad>
Imprime un correo por línea.
"""

import argparse
import asyncio
import sys
from uuid import uuid4

from sqlalchemy import text
from sqlalchemy.ext.asyncio import create_async_engine

from auth_svc.config import load_settings
from auth_svc.users import alias_key
from shared.audit_client import AuditClient
from shared.passwords import hash_secret, strong_enough
from shared.service_auth import ServiceAuth, ServiceClient


async def seed(engine, audit, prefix: str, count: int, password: str) -> list[str]:
    if not strong_enough(password, forbid=prefix):
        raise ValueError("contraseña débil")
    password_hash = hash_secret(password)  # la misma para todas: son cuentas de prueba
    emails = [f"{prefix}{i:04d}@carga.test" for i in range(count)]
    async with engine.begin() as conn:
        for i, email in enumerate(emails):
            alias = f"{prefix} {i:04d}"
            await conn.execute(
                text(
                    "INSERT INTO users (id, email, password_hash, verified_at, alias, alias_key) "
                    "VALUES (:id, :email, :hash, now(), :alias, :key)"
                ),
                {
                    "id": str(uuid4()),
                    "email": email,
                    "hash": password_hash,
                    "alias": alias,
                    "key": alias_key(alias),
                },
            )
        await audit.emit(
            "info",
            "user.seed",
            actor="system",
            details={"prefix": prefix, "count": count},
            required=True,
        )
    return emails


async def run(prefix: str, count: int, password: str) -> list[str]:
    settings = load_settings()
    engine = create_async_engine(settings.database_url)
    auth = ServiceAuth.from_secrets("auth", needs_token=True)
    try:
        return await seed(
            engine,
            AuditClient(ServiceClient(auth, {"audit": settings.audit_url})),
            prefix,
            count,
            password,
        )
    finally:
        await engine.dispose()


def main() -> None:
    parser = argparse.ArgumentParser(description="Cuentas verificadas para pruebas de carga")
    parser.add_argument("prefix", help="letras minúsculas, por ejemplo 'carga'")
    parser.add_argument("count", type=int)
    args = parser.parse_args()
    if not args.prefix.isalpha() or not args.prefix.islower() or not 1 <= args.count <= 1000:
        sys.exit("prefijo de letras minúsculas y cantidad entre 1 y 1000")
    try:
        emails = asyncio.run(run(args.prefix, args.count, sys.stdin.readline().rstrip("\n")))
    except ValueError as exc:
        sys.exit(str(exc))
    print("\n".join(emails))


if __name__ == "__main__":
    main()
```
