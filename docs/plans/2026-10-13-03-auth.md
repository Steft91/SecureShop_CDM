# 03 · Servicio `auth` — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dos identidades separadas:
- **Administrador:** usuario + contraseña (Argon2id) + TOTP, con bloqueo y retraso progresivo, sesiones revocables y el endpoint `verify-admin` que usa el gateway (riesgos R4 y R5). El secreto TOTP queda cifrado con una KEK rotable (R2).
- **Cuentas de usuario (rev. 3):** crear una cuenta es obligatorio para entrar a una sala. Registro con rate limit, login con bloqueo, **una sola sesión activa por cuenta atada al dispositivo** y el endpoint `verify-user` (R13, R17).

**Architecture:**
- Rutas públicas del admin: `/api/auth/login`, `/totp`, `/logout`, `/me`; de usuarios: `/api/users/register`, `/login`, `/logout`, `/me`. Todas con `require_gateway`.
- Dos rutas internas para el `auth_request` de Nginx: `/internal/verify-admin` y `/internal/verify-user`, con `allow("gateway")`.
- Usuarios y admins viven en tablas, cookies (`__Host-user` / `__Host-admin`) y verificaciones distintas: registrarse nunca crea un admin.
- Sesiones en la tabla `admin_sessions`: etapa `preauth` y luego `full`, con un token nuevo al completar el TOTP.
- Eventos a `audit` vía `AuditClient`; `admin.login.ok` es obligatorio.
- Un CLI crea admins y otro rota la KEK.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy async, Alembic, argon2-cffi (vía `shared.passwords`), pyotp, qrcode, pytest.

**Spec:** `docs/specs/2026-10-12-chat-seguro-design.md` §7.1, §8.1–§8.2, §9.1–§9.2, §11, §14.4, §16.4 (R2, R4, R5, R11, R13, R16, R17).

> **Revisión 3 (2026-10-19).** ATH-2 renombra las claves de bloqueo del admin (`admin:<u>` y `admin_ip:<ip>`; así los fallos de usuarios detrás de la misma IP no bloquean al admin) y se agrega **ATH-5: cuentas de usuario**. Si ya ejecutaste ATH-1…ATH-4, solo cambia `login_limits` y sigue con ATH-5.

## Global Constraints

Las del índice (`2026-10-13-00-indice.md`). En particular:
- `text()` con parámetros nombrados.
- Todas las rutas exigen `X-Service-Token` salvo `/health`.
- Errores `{"error": "..."}` genéricos.
- Cookies `__Host-admin` y `__Host-user` con `Secure`, `HttpOnly` y `SameSite=Strict`.
- Argon2id con ≤ 4 cálculos concurrentes.
- Commits en español, sin atribución.

## Review Focus

Ningún caso del índice cae aquí. A vigilar:
- El usuario se normaliza a minúsculas tanto al crear el admin como al hacer login (`ROOT` y `root` son el mismo); lo cubre `test_usuario_en_mayusculas_es_el_mismo`.
- Dos logins simultáneos de la misma cuenta desde dispositivos distintos: el índice único deja exactamente uno (`test_r13_logins_concurrentes_dejan_una_sola_sesion`, ATH-5).

```python
import time

import httpx
from fastapi import FastAPI
from sqlalchemy.ext.asyncio import AsyncEngine, create_async_engine

from auth_svc import routes
from auth_svc.config import Settings, load_settings
from shared.audit_client import AuditClient
from shared.service_auth import ServiceAuth, ServiceClient
from shared.web import create_base_app


def create_app(
    settings: Settings | None = None,
    *,
    engine: AsyncEngine | None = None,
    service_auth: ServiceAuth | None = None,
    transport: httpx.AsyncBaseTransport | None = None,
) -> FastAPI:
    settings = settings or load_settings()
    service_auth = service_auth or ServiceAuth.from_secrets("auth", needs_token=True)
    peers = ServiceClient(service_auth, {"audit": settings.audit_url}, transport)
    app = create_base_app(
        title="auth",
        settings=settings,
        engine=engine or create_async_engine(settings.database_url, pool_pre_ping=True),
        service_auth=service_auth,
        audit=AuditClient(peers),
    )
    app.state.peers = peers
    app.state.clock = time.time
    app.include_router(routes.router)
    return app
```

```python
"""Alta de administradores (spec §9.1, paso 7). No existen credenciales por defecto."""

import re
from uuid import uuid4

import pyotp
from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine

from auth_svc.config import Settings
from shared.crypto import seal, totp_aad
from shared.passwords import hash_secret_async, strong_enough

USERNAME_RE = re.compile(r"[a-z0-9_.-]{3,32}")


async def create_admin(engine: AsyncEngine, settings: Settings, audit, username: str, password: str) -> str:
    """Crea el admin y devuelve su secreto TOTP (base32) para mostrarlo una sola vez."""
    username = username.strip().lower()
    if not USERNAME_RE.fullmatch(username):
        raise ValueError("usuario inválido: 3–32 caracteres a-z, 0-9, '_', '.' o '-'")
    if not strong_enough(password, forbid=username):
        raise ValueError(
            "contraseña débil: ≥ 12 caracteres y 3 tipos (minúsculas, mayúsculas, dígitos, símbolos)"
        )
    admin_id, secret = str(uuid4()), pyotp.random_base32()
    password_hash = await hash_secret_async(password)
    async with engine.begin() as conn:
        await conn.execute(
            text(
                "INSERT INTO admins (id, username, password_hash, totp_secret, kek_version) "
                "VALUES (:id, :username, :hash, :totp, :version)"
            ),
            {
                "id": admin_id,
                "username": username,
                "hash": password_hash,
                "totp": seal(settings.kek, secret.encode(), totp_aad(admin_id)),
                "version": settings.current_kek_version,
            },
        )
        await audit.emit("info", "admin.create", actor="system", target=username, required=True)
    return secret
```

`services/auth/auth_svc/create_admin.py`:
```python
"""Crea un administrador e imprime su QR de TOTP (spec §9.1, paso 7).

Uso dentro del contenedor:  python -m auth_svc.create_admin <usuario> [--password-stdin]
"""

import argparse
import asyncio
import sys
from getpass import getpass

import pyotp
import qrcode
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import create_async_engine

from auth_svc.admins import create_admin
from auth_svc.config import load_settings
from shared.audit_client import AuditClient
from shared.service_auth import ServiceAuth, ServiceClient


def read_password(from_stdin: bool) -> str:
    if from_stdin:
        return sys.stdin.readline().rstrip("\n")
    password = getpass("Contraseña: ")
    if password != getpass("Repite la contraseña: "):
        sys.exit("las contraseñas no coinciden")
    return password


async def run(username: str, password: str) -> str:
    settings = load_settings()
    engine = create_async_engine(settings.database_url)
    peers = ServiceClient(ServiceAuth.from_secrets("auth", needs_token=True), {"audit": settings.audit_url})
    try:
        return await create_admin(engine, settings, AuditClient(peers), username, password)
    finally:
        await engine.dispose()


def main() -> None:
    parser = argparse.ArgumentParser(description="Crea un administrador con TOTP")
    parser.add_argument("username")
    parser.add_argument("--password-stdin", action="store_true", help="lee la contraseña de stdin")
    args = parser.parse_args()
    try:
        secret = asyncio.run(run(args.username, read_password(args.password_stdin)))
    except ValueError as exc:
        sys.exit(str(exc))
    except IntegrityError:
        sys.exit("ese usuario ya existe")
    uri = pyotp.TOTP(secret).provisioning_uri(name=args.username.strip().lower(), issuer_name="Chat Seguro")
    qr = qrcode.QRCode(border=1)
    qr.add_data(uri)
    qr.print_ascii(invert=True)
    print("Escanea el QR con tu app TOTP o ingresa el secreto manualmente. No se volverá a mostrar.")
    print(f"TOTP_SECRET={secret}")


if __name__ == "__main__":
    main()
```

```python
    return HTTPException(
        429, "demasiados intentos", headers={"Retry-After": str(settings.login_window_min * 60)}

    ip, username = client_ip(request), body.username.strip().lower()
    limits = login_limits(settings, username, ip)
    async with engine.connect() as conn:
        locked = await ratelimit.any_over(conn, limits, settings.login_window_min)
        admin = (
            await conn.execute(
                text("SELECT id, password_hash FROM admins WHERE username = :u"), {"u": username}
            )
        ).first()
    if locked:
        await audit.emit("warning", "admin.login.locked", actor=f"ip:{ip}", target=username, ip=ip)
        raise too_many(settings)
    if not await verify_secret_async(admin.password_hash if admin else None, body.password):
        async with engine.begin() as conn:
            fails = await ratelimit.record(conn, [key for key, _ in limits], settings.login_window_min)
        await audit.emit("warning", "admin.login.fail", actor=f"ip:{ip}", target=username, ip=ip)
        await asyncio.sleep(min(settings.login_delay_base * 2 ** (fails - 1), 4))  # retraso progresivo
        raise HTTPException(401, "credenciales inválidas")
    token = new_token()
    async with engine.begin() as conn:
        await conn.execute(
            text(
                "INSERT INTO admin_sessions (admin_id, token_hash, stage, expires_at) "
                "VALUES (:admin, :hash, 'preauth', now() + make_interval(secs => :ttl))"
            ),
            {"admin": admin.id, "hash": token_hash(token), "ttl": PREAUTH_SECONDS},
```

```python
"""TOTP (RFC 6238) con anti-reuso: un código vale una sola vez (spec §9.1, paso 5)."""

import hmac

import pyotp

STEP_SECONDS = 30


def verify_totp(secret: str, code: str, last_step: int, now: float) -> int | None:
    """Devuelve el paso de tiempo aceptado (ventana ±1) o None. Rechaza pasos ya usados."""
    totp = pyotp.TOTP(secret)
    current = int(now) // STEP_SECONDS
    for step in (current - 1, current, current + 1):
        if step > last_step and hmac.compare_digest(totp.at(step * STEP_SECONDS), code):
            return step
    return None
```

```python
"""Re-envuelve los secretos TOTP con la KEK vigente (spec §11.3).

Procedimiento: montar kek_auth_v{n+1}, poner CURRENT_KEK_VERSION=n+1, reiniciar auth y ejecutar
    docker compose -f deploy/docker-compose.yml exec auth python -m auth_svc.rotate_kek
Después ya se puede retirar el secreto de la versión anterior.
"""

import asyncio

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine, create_async_engine

from auth_svc.config import Settings, load_settings
from shared.audit_client import AuditClient
from shared.crypto import seal, totp_aad, unseal
from shared.service_auth import ServiceAuth, ServiceClient


async def rotate(engine: AsyncEngine, settings: Settings, audit) -> int:
    target = settings.current_kek_version
    async with engine.begin() as conn:
        rows = (
            await conn.execute(
                text("SELECT id, totp_secret, kek_version FROM admins WHERE kek_version <> :v FOR UPDATE"),
                {"v": target},
            )
        ).all()
        for row in rows:
            aad = totp_aad(str(row.id))
            secret = unseal(settings.keks[row.kek_version], bytes(row.totp_secret), aad)
            await conn.execute(
                text("UPDATE admins SET totp_secret = :secret, kek_version = :v WHERE id = :id"),
                {"secret": seal(settings.kek, secret, aad), "v": target, "id": row.id},
            )
        if rows:
            await audit.emit(
                "info", "key.rotate.auth", actor="system", details={"to": target, "admins": len(rows)},
                required=True,
            )
    return len(rows)


async def _main() -> int:
    settings = load_settings()
    engine = create_async_engine(settings.database_url)
    peers = ServiceClient(ServiceAuth.from_secrets("auth", needs_token=True), {"audit": settings.audit_url})
    try:
        return await rotate(engine, settings, AuditClient(peers))
    finally:
        await engine.dispose()


if __name__ == "__main__":
    count = asyncio.run(_main())
    print(f"{count} secretos TOTP re-envueltos con la KEK vigente")
```

```python
"""Cuentas de usuario: registro, login con sesión única por dispositivo y verify-user (spec §9.2;
riesgos 13 y 17). Separadas de los admins: otra tabla, otra cookie y otra verificación."""

import asyncio
import re
from uuid import uuid4

from fastapi import APIRouter, Depends, HTTPException, Request, Response
from pydantic import BaseModel, Field
from sqlalchemy import text
from sqlalchemy.exc import IntegrityError

from shared import ratelimit
from shared.crypto import new_token, sha256, token_hash
from shared.identity import client_ip, require_gateway
from shared.passwords import hash_secret_async, strong_enough, verify_secret_async
from shared.service_auth import allow
from shared.web import DEVICE_COOKIE, USER_COOKIE, clear_cookie, set_cookie

router = APIRouter()
USERNAME_RE = re.compile(r"[a-z0-9_.-]{3,32}")
RESERVED = {"admin", "administrador", "root", "system", "sistema", "soporte"}


class Credentials(BaseModel):
    username: str = Field(min_length=1, max_length=64)
    password: str = Field(min_length=1, max_length=256)


def device_hash(request: Request) -> bytes:
    device = request.cookies.get(DEVICE_COOKIE)
    if not device:
        raise HTTPException(400, "dispositivo no inicializado")
    return sha256(device.encode())


def too_many(minutes: int) -> HTTPException:
    return HTTPException(429, "demasiados intentos", headers={"Retry-After": str(minutes * 60)})


@router.post("/api/users/register", status_code=201, dependencies=[Depends(require_gateway)])
async def register(body: Credentials, request: Request) -> dict:
    settings, engine, audit = (
        request.app.state.settings,
        request.app.state.engine,
        request.app.state.audit,
    )
    ip, device, username = client_ip(request), device_hash(request), body.username.strip().lower()
    limits = [
        (f"register_device:{device.hex()}", settings.register_max_per_device),
        (f"register_ip:{ip}", settings.register_max_per_ip),
    ]
    async with engine.begin() as conn:
        limited = await ratelimit.any_over(conn, limits, settings.register_window_min)
        if not limited:  # cada intento cuenta, exitoso o no
            await ratelimit.record(conn, [key for key, _ in limits], settings.register_window_min)
    if limited:
        await audit.emit(
            "warning", "user.register.ratelimited", actor=f"ip:{ip}", target=username, ip=ip
        )
        raise too_many(settings.register_window_min)
    if not USERNAME_RE.fullmatch(username) or username in RESERVED:
        raise HTTPException(
            422, "nombre de usuario inválido: 3–32 caracteres a-z, 0-9, '_', '.' o '-'"
        )
    if not strong_enough(body.password, forbid=username):
        raise HTTPException(
            422, "contraseña débil: ≥ 12 caracteres, 3 tipos y distinta del usuario"
        )
    password_hash = await hash_secret_async(body.password)
    try:
        async with engine.begin() as conn:
            await conn.execute(
                text(
                    "INSERT INTO users (id, username, password_hash) VALUES (:id, :username, :hash)"
                ),
                {"id": str(uuid4()), "username": username, "hash": password_hash},
            )
            await audit.emit(
                "info", "user.register", actor=f"user:{username}", ip=ip, required=True
            )
    except IntegrityError:
        # Revela que el nombre existe: inevitable al elegir nombre; lo acota el rate limit.
        await audit.emit("warning", "user.register.taken", actor=f"ip:{ip}", target=username, ip=ip)
        raise HTTPException(409, "nombre de usuario no disponible") from None
    return {"username": username}


@router.post("/api/users/login", dependencies=[Depends(require_gateway)])
async def login(body: Credentials, request: Request, response: Response) -> dict:
    settings, engine, audit = (
        request.app.state.settings,
        request.app.state.engine,
        request.app.state.audit,
    )
    ip, device, username = client_ip(request), device_hash(request), body.username.strip().lower()
    limits = [
        (f"user:{username}", settings.user_login_max_fails),
        (f"user_ip:{ip}", settings.user_login_max_fails_ip),
    ]
    async with engine.connect() as conn:
        locked = await ratelimit.any_over(conn, limits, settings.login_window_min)
        user = (
            await conn.execute(
                text("SELECT id, password_hash FROM users WHERE username = :u"), {"u": username}
            )
        ).first()
    if locked:
        await audit.emit("warning", "user.login.locked", actor=f"ip:{ip}", target=username, ip=ip)
        raise too_many(settings.login_window_min)
    if not await verify_secret_async(user.password_hash if user else None, body.password):
        async with engine.begin() as conn:
            fails = await ratelimit.record(
                conn, [key for key, _ in limits], settings.login_window_min
            )
        await audit.emit("warning", "user.login.fail", actor=f"ip:{ip}", target=username, ip=ip)
        await asyncio.sleep(
            min(settings.login_delay_base * 2 ** (fails - 1), 4)
        )  # retraso progresivo
        raise HTTPException(401, "credenciales inválidas")

    token, conflict = new_token(), False
    try:
        async with engine.begin() as conn:
            await conn.execute(
                text(
                    "UPDATE user_sessions SET ended_at = now(), end_reason = 'expired' "
                    "WHERE user_id = :u AND ended_at IS NULL "
                    "AND (expires_at <= now() OR last_seen <= now() - make_interval(mins => :idle))"
                ),
                {"u": user.id, "idle": settings.user_idle_min},
            )
            active = (
                await conn.execute(
                    text(
                        "SELECT id, device_hash FROM user_sessions WHERE user_id = :u AND ended_at IS NULL FOR UPDATE"
                    ),
                    {"u": user.id},
                )
            ).first()
            if active is not None and bytes(active.device_hash) != device:
                conflict = True  # R13: política del equipo, se rechaza el ingreso nuevo
            else:
                if active is not None:  # mismo dispositivo: la sesión nueva reemplaza a la anterior
                    await conn.execute(
                        text(
                            "UPDATE user_sessions SET ended_at = now(), end_reason = 'replaced' WHERE id = :id"
                        ),
                        {"id": active.id},
                    )
                await conn.execute(
                    text(
                        "INSERT INTO user_sessions (user_id, token_hash, device_hash, expires_at) "
                        "VALUES (:u, :token, :device, now() + make_interval(hours => :hours))"
                    ),
                    {
                        "u": user.id,
                        "token": token_hash(token),
                        "device": device,
                        "hours": settings.user_abs_hours,
                    },
                )
                await audit.emit(
                    "info", "user.login.ok", actor=f"user:{username}", ip=ip, required=True
                )
    except IntegrityError:  # otro login ganó la carrera: el índice único deja una sola sesión
        conflict = True
    if conflict:
        await audit.emit(
            "warning", "user.login.device_conflict", actor=f"ip:{ip}", target=username, ip=ip
        )
        raise HTTPException(409, "la cuenta tiene una sesión activa en otro dispositivo")
    set_cookie(response, USER_COOKIE, token)
    return {"username": username}


async def active_user(request: Request):
    """Sesión vigente (absoluta e inactividad) desde el MISMO dispositivo; desliza last_seen."""
    token, device = request.cookies.get(USER_COOKIE), request.cookies.get(DEVICE_COOKIE)
    if not token or not device:
        return None
    async with request.app.state.engine.begin() as conn:
        return (
            await conn.execute(
                text(
                    "UPDATE user_sessions s SET last_seen = now() FROM users u "
                    "WHERE u.id = s.user_id AND s.token_hash = :hash AND s.device_hash = :device "
                    "AND s.ended_at IS NULL AND s.expires_at > now() "
                    "AND s.last_seen > now() - make_interval(mins => :idle) "
                    "RETURNING u.id::text AS user_id, u.username"
                ),
                {
                    "hash": token_hash(token),
                    "device": sha256(device.encode()),
                    "idle": request.app.state.settings.user_idle_min,
                },
            )
        ).first()


@router.get("/internal/verify-user", status_code=204, dependencies=[Depends(allow("gateway"))])
async def verify_user(request: Request, response: Response) -> None:

    if user is None:
        ip = client_ip(request)

            "gateway.reject.user",
            actor=f"ip:{ip}",
            target=request.headers.get("x-original-uri"),
            ip=ip,
        )
        raise HTTPException(401, "no autenticado")
    response.headers["X-User-Id"] = user.user_id
    response.headers["X-User-Name"] = user.username

    if user is None:
        raise HTTPException(401, "no autenticado")
```
