# 09 · Pruebas de punta a punta, despliegue y cierre — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Demostrar contra el stack real lo que cruza servicios:
- chat cifrado de punta a punta;
- reglas del gateway: `/internal` cerrado, identidad no falsificable, TLS 1.3 obligatorio;
- imágenes publicadas o en cuarentena con su alerta.

Además: desplegar en un VPS con certificado válido, calibrar el estegoanálisis con fotos reales y dejar la trazabilidad R1–R16 completa, el guion de la demo y el estado de `CLAUDE.md`.

**Architecture:** `e2e/` es una suite pytest independiente que habla con `https://localhost` exactamente como un navegador:
- httpx con cookies y TLS verificado con la CA de mkcert;
- `websockets` (cliente síncrono) con el protocolo de `shared.crypto`.

El admin se crea con el CLI de `auth` (`--password-stdin`). El VPS usa el mismo Compose, con certificados de Let's Encrypt copiados por un hook de renovación.

**Tech Stack:** pytest, httpx, websockets, pyotp, shared.crypto/testing · Docker Compose · certbot · Ubuntu 24.04.

**Spec:** `docs/specs/2026-10-12-chat-seguro-design.md` §12.4, §13, §16.2–§16.4, §18, §20.

```python
"""Pruebas de punta a punta contra el stack completo (spec §16.2).

Requisitos: `docker compose -f deploy/docker-compose.yml up -d --build` con todo healthy y mkcert instalado.
"""

import json
import os
import re
import secrets
import ssl
import subprocess
import time
from pathlib import Path

import httpx
import pyotp
import pytest
from cryptography.hazmat.primitives.asymmetric import ec
from websockets.sync.client import connect

from shared.crypto import (
    CURVE,
    b64d,
    b64e,
    decrypt_frame,
    derive_session_key,
    encrypt_frame,
    hello_transcript,
    load_public_key,
    public_bytes,
    verify_p1363,
)

ROOT = Path(__file__).resolve().parents[1]
BASE = os.environ.get("E2E_BASE", "https://localhost")
WS_URL = BASE.replace("https://", "wss://", 1) + "/ws"
COMPOSE = ["docker", "compose", "-f", str(ROOT / "deploy" / "docker-compose.yml")]
ROOM_KEY = "Clave-E2E-2026!"  # clave de sala de prueba


def ca_file() -> str:
    if os.environ.get("E2E_CAFILE"):
        return os.environ["E2E_CAFILE"]
    caroot = subprocess.run(["mkcert", "-CAROOT"], capture_output=True, text=True, check=True).stdout.strip()
    return str(Path(caroot) / "rootCA.pem")


def retry_429(send, attempts: int = 8):
    """El gateway limita login y join a 1 r/s (ráfaga 5): las pruebas esperan en vez de fallar."""
    response = send()
    for _ in range(attempts):
        if response.status_code != 429:
            return response
        time.sleep(1.2)
        response = send()
    return response


@pytest.fixture(scope="session")
def tls() -> ssl.SSLContext:
    return ssl.create_default_context(cafile=ca_file())


@pytest.fixture(scope="session")
def admin_creds() -> tuple[str, str, str]:
    username = f"e2e{secrets.token_hex(3)}"
    password = f"E2e-{secrets.token_urlsafe(12)}!"
    result = subprocess.run(
        [*COMPOSE, "exec", "-T", "auth", "python", "-m", "auth_svc.create_admin", username, "--password-stdin"],
        input=password + "\n",
        capture_output=True,
        text=True,
        encoding="utf-8",
        check=True,
    )
    secret = re.search(r"TOTP_SECRET=(\w+)", result.stdout).group(1)
    return username, password, secret


@pytest.fixture(scope="session")
def admin(tls, admin_creds) -> httpx.Client:
    username, password, secret = admin_creds
    client = httpx.Client(base_url=BASE, verify=tls, headers={"Origin": BASE})
    login = retry_429(lambda: client.post("/api/auth/login", json={"username": username, "password": password}))
    assert login.status_code == 204, login.text
    code = pyotp.TOTP(secret).now()
    assert retry_429(lambda: client.post("/api/auth/totp", json={"code": code})).status_code == 204
    return client


@pytest.fixture
def room(admin):
    code = f"e2e-{secrets.token_hex(3)}"
    r = admin.post("/api/admin/rooms", json={"code": code, "key": ROOM_KEY, "max_participants": 10, "mode": "both"})
    assert r.status_code == 201, r.text
    yield r.json()
    admin.delete(f"/api/admin/rooms/{r.json()['id']}")


class Participant:
    """Un navegador: su propio jar de cookies (= dispositivo) y el lado cliente del protocolo."""

    def __init__(self, tls: ssl.SSLContext, room: dict, alias: str):
        self.tls, self.alias, self.room = tls, alias, room
        self.http = httpx.Client(base_url=BASE, verify=tls, headers={"Origin": BASE})
        assert self.http.get("/api/device").status_code == 204
        self.join_response = retry_429(
            lambda: self.http.post("/api/rooms/join", json={"code": room["code"], "key": ROOM_KEY, "alias": alias})
        )
        if self.join_response.status_code == 200:
            self.session_id = self.join_response.json()["session_id"]
            self.room_id = self.join_response.json()["room"]["id"]
        self.sign_key = load_public_key(b64d(self.http.get("/chat-key.json").json()["pub"]))
        self.key, self.seq, self.recv_seq = None, 0, 0

    def cookie_header(self) -> str:
        return "; ".join(f"{name}={value}" for name, value in self.http.cookies.items())

    def raw_connect(self, origin: str = BASE):
        return connect(WS_URL, ssl=self.tls, origin=origin, additional_headers={"Cookie": self.cookie_header()})

    def connect(self):
        ws = self.raw_connect()
        private = ec.generate_private_key(CURVE)
        pub = b64e(public_bytes(private))
        ws.send(json.dumps({"t": "hello", "pub": pub}))
        reply = json.loads(ws.recv(timeout=10))
        transcript = hello_transcript(self.room_id, self.session_id, pub, reply["pub"], reply["salt"])
        assert verify_p1363(self.sign_key, b64d(reply["sig"]), transcript), "firma del hello inválida"
        shared = private.exchange(ec.ECDH(), load_public_key(b64d(reply["pub"])))
        self.key = derive_session_key(shared, b64d(reply["salt"]), self.room_id, self.session_id)
        self.seq = self.recv_seq = 0
        return ws

    def send(self, ws, payload: dict) -> None:
        self.seq += 1
        ws.send(json.dumps(encrypt_frame(self.key, self.room_id, self.session_id, self.seq, "c2s", payload)))

    def recv_until(self, ws, kind: str, **match) -> dict:
        while True:
            seq, payload = decrypt_frame(self.key, self.room_id, self.session_id, "s2c", json.loads(ws.recv(timeout=10)))
            assert seq > self.recv_seq
            self.recv_seq = seq
            if payload.get("t") == kind and all(payload.get(k) == v for k, v in match.items()):
                return payload
```

```python
from conftest import Participant


def test_chat_cifrado_de_punta_a_punta(tls, room):
    ana, beto = Participant(tls, room, "ana"), Participant(tls, room, "beto")
    with ana.connect() as wa, beto.connect() as wb:
        ana.recv_until(wa, "history")
```

```python
from conftest import Participant

from shared import testing

CLEAN = testing.png_bytes(testing.natural_image(0))
STEGO = testing.png_bytes(testing.embed_lsb(testing.natural_image(1), 0.10, "seq"))


def upload(participant: Participant, data: bytes):
    return participant.http.post("/api/media/files", files={"file": ("foto.png", data, "image/png")})


def test_r12_imagen_limpia_se_publica_y_solo_la_baja_su_destinatario(tls, room):
    ana, beto = Participant(tls, room, "ana"), Participant(tls, room, "beto")
    # Todo dentro del `with`: cerrar el WS termina la sesión y la descarga exige sesión viva.
    with ana.connect() as wa, beto.connect() as wb:
        ana.recv_until(wa, "history")
        beto.recv_until(wb, "history")
        r = upload(ana, CLEAN)
        assert r.json()["status"] == "clean", r.text
        event_for_beto = beto.recv_until(wb, "file")
        event_for_ana = ana.recv_until(wa, "file")
        image = beto.http.get(event_for_beto["url"])
        assert (image.status_code, image.headers["content-type"]) == (200, "image/png")
        assert beto.http.get(event_for_ana["url"]).status_code == 404  # firmada para otra sesión


def test_reenvio_de_imagen_descargada(tls, room):
    ana = Participant(tls, room, "ana")
    with ana.connect() as ws:
        ana.recv_until(ws, "history")
        upload(ana, CLEAN)
        downloaded = ana.http.get(ana.recv_until(ws, "file")["url"]).content
        assert upload(ana, downloaded).json()["status"] == "clean"
```

````markdown
# Despliegue en un VPS (spec §18, S3)

Requisitos:
- Ubuntu 24.04 con ≥ 4 GB de RAM (ClamAV usa ~1.5–3 GB).
- Un dominio con registro A hacia la IP del VPS.
- Puertos 22, 80 y 443 abiertos.

## 1. Preparar el servidor
1. Instala Docker Engine y el plugin compose siguiendo https://docs.docker.com/engine/install/ubuntu/.
2. Firewall:
   ```bash
   sudo ufw allow OpenSSH && sudo ufw allow 80,443/tcp && sudo ufw enable
   ```
3. Dependencias para generar secretos y certificados:
   ```bash
   sudo apt install -y python3-cryptography certbot git
   ```

## 2. Código y secretos
```bash
git clone https://github.com/Steft91/SecureShop_CDM.git /srv/chat && cd /srv/chat
python3 deploy/gen_secrets.py
chmod 700 deploy/secrets
```

## 3. Certificado (Let's Encrypt)
```bash
export DOMAIN=chat.tu-dominio.com
mkdir -p deploy/certs
sudo certbot certonly --standalone -d "$DOMAIN" \
  --pre-hook "docker compose -f /srv/chat/deploy/docker-compose.yml stop gateway" \
  --post-hook "cp -L /etc/letsencrypt/live/$DOMAIN/fullchain.pem /etc/letsencrypt/live/$DOMAIN/privkey.pem /srv/chat/deploy/certs/ && docker compose -f /srv/chat/deploy/docker-compose.yml start gateway"
```
certbot guarda los hooks: cada renovación (cada ~60 días) detiene el gateway unos segundos, copia los certificados nuevos y lo vuelve a levantar. Prueba la renovación con `sudo certbot renew --dry-run`.

## 4. Configuración no secreta
```bash
echo "ALLOWED_ORIGINS=https://$DOMAIN" > deploy/.env
```
En ARM (por ejemplo, Oracle Cloud Free), ClamAV necesita la imagen multiarquitectura:
```bash
echo "CLAMAV_IMAGE=clamav/clamav-debian:1.4" >> deploy/.env
```
(Comprueba la arquitectura con `docker manifest inspect clamav/clamav:1.4 | grep arm64`.)

## 5. Levantar y crear el admin
```bash
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml exec auth python -m auth_svc.create_admin admin
```

## 6. Verificar
```bash
curl -sI http://$DOMAIN/ | head -1
curl -s --tlsv1.2 --tls-max 1.2 https://$DOMAIN/ -o /dev/null; echo "exit=$?"
curl -s https://$DOMAIN/internal/verify-admin
```
Expected: `301`, `exit` distinto de 0 y `{"error":"no encontrado"}`. Opcional: https://www.ssllabs.com/ssltest/ debería dar A o A+.

## Actualizar
```bash

```
Para redesplegar un solo servicio: `... up -d --build <servicio>`.
````
