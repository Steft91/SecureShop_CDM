# 09 · Pruebas de punta a punta, despliegue y cierre — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Demostrar contra el stack real lo que cruza servicios:
- chat cifrado de punta a punta entre usuarios registrados;
- cuentas: registro con el código que llega por correo (leído de Mailpit), alias en el primer ingreso; sin cuenta no se entra a una sala, la misma cuenta no inicia sesión desde un segundo dispositivo y cerrar sesión corta el WebSocket;
- salas: canal general para todas las cuentas y membresía permanente (volver a entrar sin la clave);
- reglas del gateway: `/internal` cerrado, identidad no falsificable (incluidas `X-User-*`), TLS 1.3 obligatorio;
- archivos publicados, en cuarentena o rechazados, con su alerta.

Además: desplegar en un VPS con certificado válido, calibrar el estegoanálisis con fotos y grabaciones reales, dejar la trazabilidad R1–R17 completa, el guion de la demo y el estado de `CLAUDE.md`, y medir los requisitos no funcionales de la Actividad 3 (E2E-4: carga, tiempos, respaldos, reinicio, disponibilidad y pruebas con personas).

**Architecture:** `e2e/` es una suite pytest independiente que habla con `https://localhost` exactamente como un navegador:
- httpx con cookies y TLS verificado con la CA de mkcert;
- `websockets` (cliente síncrono) con el protocolo de `shared.crypto`.

El admin se crea con el CLI de `auth` (`--password-stdin`). Las cuentas de usuario se registran por la API una sola vez por corrida (fixture `accounts`), porque el registro tiene tope por IP: el código de verificación se lee de la API de Mailpit (`http://127.0.0.1:8025`, solo en local) y cada cuenta elige su alias. Cada `Participant` es un navegador nuevo (su propio jar de cookies = un dispositivo) que inicia sesión, se une a la sala con código y clave, entra y, al terminar, sale y cierra la sesión para liberar la cuenta. El VPS usa el mismo Compose, con certificados de Let's Encrypt copiados por un hook de renovación.

**Tech Stack:** pytest, httpx, websockets, pyotp, shared.crypto/testing · Docker Compose · certbot · Ubuntu 24.04.

**Spec:** `docs/specs/2026-10-12-chat-seguro-design.md` §9.2, §12, §13, §16.2–§16.4, §18, §20.

```python
Requisitos: `docker compose -f deploy/docker-compose.yml up -d --build` con todo healthy y mkcert instalado.
Los códigos de verificación se leen de la API de Mailpit (http://127.0.0.1:8025, solo en local).

ROOT = Path(__file__).resolve().parents[1]

COMPOSE = ["docker", "compose", "-f", str(ROOT / "deploy" / "docker-compose.yml")]

ROOM_KEY = "Clave-E2E-2026!"  # clave de sala de prueba


def ca_file() -> str:
    if os.environ.get("E2E_CAFILE"):
        return os.environ["E2E_CAFILE"]
    caroot = subprocess.run(
        ["mkcert", "-CAROOT"], capture_output=True, text=True, check=True
    ).stdout.strip()
    return str(Path(caroot) / "rootCA.pem")


def retry_429(send, attempts: int = 8):
    """El gateway limita login y join a 1 r/s (ráfaga 5): las pruebas esperan en vez de fallar."""
    response = send()
    for _ in range(attempts):
        if response.status_code != 429:
            return response
        time.sleep(1.2)
        response = send()
    return response


@pytest.fixture(scope="session")

def new_browser(tls: ssl.SSLContext) -> httpx.Client:
    """Un navegador nuevo: su propio jar de cookies, o sea, un dispositivo nuevo."""
    client = httpx.Client(base_url=BASE, verify=tls, headers={"Origin": BASE})
    assert client.get("/api/device").status_code == 204
    return client


def mailed_code(email: str, timeout: float = 15.0) -> str:
    """El último código de 6 dígitos que recibió `email` en Mailpit."""
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        found = httpx.get(f"{MAILPIT}/api/v1/search", params={"query": f'to:"{email}"'}).json()
        if found["messages"]:
            message = httpx.get(f"{MAILPIT}/api/v1/message/{found['messages'][0]['ID']}").json()
            return re.search(r"\b(\d{6})\b", message["Text"]).group(1)
        time.sleep(0.5)
    raise AssertionError(f"no llegó el código a {email}")


def register_account(tls, email: str, password: str, alias: str | None) -> None:
    """Registro, código del correo, login y alias; termina con la sesión cerrada."""
    browser = new_browser(tls)
    payload = {"email": email, "password": password}
    r = retry_429(partial(browser.post, "/api/users/register", json=payload))
    assert r.status_code == 202, r.text
    verify = {"email": email, "code": mailed_code(email)}
    assert retry_429(partial(browser.post, "/api/users/verify", json=verify)).status_code == 204
    if alias:
        assert retry_429(partial(browser.post, "/api/users/login", json=payload)).status_code == 200
        assert browser.post("/api/users/alias", json={"alias": alias}).status_code == 200
        assert browser.post("/api/users/logout").status_code == 204
    browser.close()

class Participant:
    """Una cuenta en un navegador: inicia sesión, se une a la sala con código y clave, entra y habla
    el lado cliente del protocolo."""

    def __init__(self, tls: ssl.SSLContext, room: dict | None, account: tuple[str, str, str]):
        self.tls, self.room = tls, room
        self.email, self.password, self.alias = account
        self.http = new_browser(tls)
        self.login_response = self.login()
        self.enter_response = None
        if self.login_response.status_code == 200 and room is not None:
            joined = retry_429(
                lambda: self.http.post(
                    "/api/rooms/join", json={"code": room["code"], "key": ROOM_KEY}
                )
            )
            assert joined.status_code == 200, joined.text
            self.enter(room["id"])
        self.sign_key = load_public_key(b64d(self.http.get("/chat-key.json").json()["pub"]))
        self.key, self.seq, self.recv_seq = None, 0, 0

    def login(self) -> httpx.Response:
        payload = {"email": self.email, "password": self.password}
        return retry_429(lambda: self.http.post("/api/users/login", json=payload))

    def enter(self, room_id: str) -> httpx.Response:
        self.enter_response = self.http.post(f"/api/rooms/{room_id}/enter")
        if self.enter_response.status_code == 200:
            self.session_id = self.enter_response.json()["session_id"]
            self.room_id = self.enter_response.json()["room"]["id"]
        return self.enter_response

    def close(self) -> None:
        """Sale de la sala y cierra la sesión: la cuenta queda libre para otro dispositivo."""
        self.http.post("/api/rooms/leave")
        self.http.post("/api/users/logout")
        self.http.close()

    def cookie_header(self) -> str:
        return "; ".join(f"{name}={value}" for name, value in self.http.cookies.items())

    def raw_connect(self, origin: str = BASE):
        return connect(
            WS_URL, ssl=self.tls, origin=origin, additional_headers={"Cookie": self.cookie_header()}
        )

    def connect(self):
        ws = self.raw_connect()
        private = ec.generate_private_key(CURVE)
        pub = b64e(public_bytes(private))
        ws.send(json.dumps({"t": "hello", "pub": pub}))
        reply = json.loads(ws.recv(timeout=10))
        transcript = hello_transcript(
            self.room_id, self.session_id, pub, reply["pub"], reply["salt"]
        )
        assert verify_p1363(self.sign_key, b64d(reply["sig"]), transcript), (
            "firma del hello inválida"
        )
        shared = private.exchange(ec.ECDH(), load_public_key(b64d(reply["pub"])))
        self.key = derive_session_key(shared, b64d(reply["salt"]), self.room_id, self.session_id)
        self.seq = self.recv_seq = 0
        return ws

    def send(self, ws, payload: dict) -> None:
        self.seq += 1
        ws.send(
            json.dumps(
                encrypt_frame(self.key, self.room_id, self.session_id, self.seq, "c2s", payload)
            )
        )

    def recv_until(self, ws, kind: str, **match) -> dict:
        while True:
            seq, payload = decrypt_frame(
                self.key, self.room_id, self.session_id, "s2c", json.loads(ws.recv(timeout=10))
            )
            assert seq > self.recv_seq
            self.recv_seq = seq
            if payload.get("t") == kind and all(payload.get(k) == v for k, v in match.items()):
                return payload


@pytest.fixture
def participant(tls, room, accounts):
    """Fábrica: participant("ana") inicia sesión con esa cuenta en un navegador nuevo y entra a `room`."""
    created: list[Participant] = []

    def make(name: str) -> Participant:
        created.append(Participant(tls, room, accounts[name]))
        return created[-1]

    yield make
    for each in reversed(created):
        each.close()
```

```python
def test_chat_cifrado_de_punta_a_punta(participant):
```

````markdown
Requisitos:

   ```bash

## 3. Certificado (Let's Encrypt)
```bash
export DOMAIN=chat.tu-dominio.com
````

`perf/carga.py`:
```python
"""Prueba de carga contra el stack completo (spec §21; RNF-01, RNF-02 y RNF-06).

Cada proceso maneja hasta 20 participantes (el gateway admite 20 WebSocket por IP, R10): para
500 conexiones se lanzan 25 contenedores, cada uno con su IP (perf/docker-compose.perf.yml).

    PERF_PASSWORD='<contraseña de las cuentas>' python perf/carga.py --accounts cuentas.txt \
        --room sala-carga --key '<clave>' --participants 20 --rate 4 --seconds 120 --out resultado.json

`cuentas.txt` sale de `python -m auth_svc.seed_users` (un correo por línea); --offset elige el
tramo de cuentas de este proceso. Mide:
- entrada concurrente a la sala (cuenta, membresía, cupo y dispositivo): percentil 95 ≤ 2 s
  (RNF-02). Unirse con código y clave ocurre una sola vez por cuenta y queda fuera de la medición,
  porque el gateway limita esa ruta a 1 por segundo por IP (R8);
- latencia de extremo a extremo de cada mensaje, del envío a la recepción en los demás
  participantes, con el cifrado de las tramas incluido: percentil 95 ≤ 500 ms (RNF-01).
"""

import argparse
import asyncio
import json
import os
import ssl
import sys
import time
from uuid import uuid4

import httpx
from cryptography.hazmat.primitives.asymmetric import ec
from websockets.asyncio.client import connect

from shared.crypto import (
    CURVE,
    b64d,
    b64e,
    decrypt_frame,
    derive_session_key,
    encrypt_frame,
    hello_transcript,
    load_public_key,
    public_bytes,
    verify_p1363,
)

BASE = os.environ.get("PERF_BASE", "https://localhost")


def p95(values: list[float]) -> float | None:
    ordered = sorted(values)
    return ordered[min(len(ordered) - 1, int(0.95 * len(ordered)))] if ordered else None


class Bot:
    def __init__(self, tls: ssl.SSLContext, email: str, password: str) -> None:
        self.tls, self.email, self.password = tls, email, password
        self.http = httpx.AsyncClient(
            base_url=BASE, verify=tls, headers={"Origin": BASE}, timeout=30
        )
        self.seq = self.recv_seq = 0

    async def prepare(self, code: str, key: str) -> None:
        """Login y membresía (fuera de la medición). Respeta el 429 del gateway reintentando."""
        await self.http.get("/api/device")
        payload = {"email": self.email, "password": self.password}
        for path, body in (
            ("/api/users/login", payload),
            ("/api/rooms/join", {"code": code, "key": key}),
        ):
            response = await self.http.post(path, json=body)
            while response.status_code == 429:
                await asyncio.sleep(1.2)
                response = await self.http.post(path, json=body)
            response.raise_for_status()
        self.room_id = response.json()["room"]["id"]

    async def enter(self) -> float:
        started = time.perf_counter()
        entered = await self.http.post(f"/api/rooms/{self.room_id}/enter")
        entered.raise_for_status()
        self.session_id = entered.json()["session_id"]
        return time.perf_counter() - started

    async def connect(self, sign_key) -> None:
        cookies = "; ".join(f"{k}={v}" for k, v in self.http.cookies.items())
        url = BASE.replace("https://", "wss://", 1) + "/ws"
        self.ws = await connect(
            url, ssl=self.tls, origin=BASE, additional_headers={"Cookie": cookies}
        )
        private = ec.generate_private_key(CURVE)
        pub = b64e(public_bytes(private))
        await self.ws.send(json.dumps({"t": "hello", "pub": pub}))
        reply = json.loads(await self.ws.recv())
        transcript = hello_transcript(
            self.room_id, self.session_id, pub, reply["pub"], reply["salt"]
        )
        if not verify_p1363(sign_key, b64d(reply["sig"]), transcript):
            raise RuntimeError("firma del hello inválida")
        shared = private.exchange(ec.ECDH(), load_public_key(b64d(reply["pub"])))
        self.key = derive_session_key(shared, b64d(reply["salt"]), self.room_id, self.session_id)

    async def send(self, body: str) -> None:
        self.seq += 1
        frame = encrypt_frame(
            self.key, self.room_id, self.session_id, self.seq, "c2s", {"t": "msg", "body": body}
        )
        await self.ws.send(json.dumps(frame))

    async def listen(self, sent: dict[str, float], latencies: list[float], until: float) -> None:
        while time.monotonic() < until:
            try:
                raw = await asyncio.wait_for(self.ws.recv(), timeout=1)
            except TimeoutError:
                continue
            seq, payload = decrypt_frame(
                self.key, self.room_id, self.session_id, "s2c", json.loads(raw)
            )
            self.recv_seq = seq
            if payload.get("t") == "msg" and payload["body"] in sent:
                latencies.append(time.monotonic() - sent[payload["body"]])

    async def close(self) -> None:
        await self.ws.close()
        await self.http.post("/api/rooms/leave")
        await self.http.post("/api/users/logout")
        await self.http.aclose()


async def talk(bot: Bot, sent: dict[str, float], per_bot_rate: float, until: float) -> None:
    while time.monotonic() < until:
        body = f"carga {uuid4().hex}"
        sent[body] = time.monotonic()
        await bot.send(body)
        await asyncio.sleep(1 / per_bot_rate)


async def run(args, emails: list[str], password: str) -> dict:
    tls = (
        ssl.create_default_context(cafile=args.cafile)
        if args.cafile
        else ssl.create_default_context()
    )
    bots = [Bot(tls, email, password) for email in emails]
    for bot in bots:  # en serie: login y unirse tienen límite por IP
        await bot.prepare(args.room, args.key)
    enter_times = await asyncio.gather(*(bot.enter() for bot in bots))
    async with httpx.AsyncClient(base_url=BASE, verify=tls) as http:
        sign_key = load_public_key(b64d((await http.get("/chat-key.json")).json()["pub"]))
    await asyncio.gather(*(bot.connect(sign_key) for bot in bots))
    sent: dict[str, float] = {}
    latencies: list[float] = []
    until = time.monotonic() + args.seconds
    per_bot = args.rate / len(bots)
    await asyncio.gather(
        *(talk(bot, sent, per_bot, until) for bot in bots),
        *(bot.listen(sent, latencies, until + 5) for bot in bots),
    )
    await asyncio.gather(*(bot.close() for bot in bots))
    return {
        "participants": len(bots),
        "messages_sent": len(sent),
        "deliveries": len(latencies),
        "enter_p95_s": p95(list(enter_times)),
        "latency_p95_ms": None if not latencies else round(p95(latencies) * 1000, 1),
    }


def main() -> None:
    parser = argparse.ArgumentParser(description="Carga del chat (RNF-01, RNF-02, RNF-06)")
    parser.add_argument("--accounts", required=True)
    parser.add_argument("--room", required=True)
    parser.add_argument("--key", required=True)
    parser.add_argument("--participants", type=int, default=20)
    parser.add_argument("--offset", type=int, default=0)
    parser.add_argument(
        "--rate", type=float, default=4.0, help="mensajes por segundo de este proceso"
    )
    parser.add_argument("--seconds", type=int, default=120)
    parser.add_argument("--cafile", default=os.environ.get("PERF_CAFILE"))
    parser.add_argument("--out", default="resultado.json")
    args = parser.parse_args()
    if not 1 <= args.participants <= 20:
        sys.exit("entre 1 y 20 participantes por proceso (límite de conexiones por IP del gateway)")
    with open(args.accounts, encoding="utf-8") as handle:
        emails = [line.strip() for line in handle if line.strip()]
    emails = emails[args.offset : args.offset + args.participants]
    password = os.environ.get("PERF_PASSWORD")
    if not password:
        sys.exit("falta PERF_PASSWORD (la contraseña de las cuentas de seed_users)")
    result = asyncio.run(run(args, emails, password))
    result["ok"] = (result["enter_p95_s"] or 0) <= 2.0 and (result["latency_p95_ms"] or 0) <= 500
    with open(args.out, "w", encoding="utf-8") as handle:
        json.dump(result, handle, indent=2)
    print(json.dumps(result, indent=2))
    sys.exit(0 if result["ok"] else 1)


if __name__ == "__main__":
    main()
```

`deploy/backup.sh`:
```sh
#!/bin/sh
# Respaldo cifrado de las 5 BD y del volumen de archivos (spec §21.4, RNF-16).
# Uso (desde la raíz del repo):  sh deploy/backup.sh <carpeta-destino>
# Cifra con age para los destinatarios de deploy/backup-recipients.txt (claves públicas): la clave
# privada NO vive en el servidor. Los secretos (KEK, claves de firma) se respaldan aparte, fuera de
# línea: sin la KEK, el respaldo de la BD no permite leer los mensajes (R2).
set -eu
dest="${1:?uso: backup.sh <carpeta-destino>}"
compose="docker compose -f deploy/docker-compose.yml"
stamp="$(date -u +%Y%m%dT%H%M%SZ)"
work="$(mktemp -d)"
trap 'rm -rf "$work"' EXIT

$compose exec -T db pg_dumpall -U postgres --clean --if-exists > "$work/db.sql"
docker run --rm -v chat-seguro_media_data:/data:ro alpine:3.20 tar -C /data -czf - . > "$work/media.tgz"
sha256sum "$work/db.sql" "$work/media.tgz" | sed "s#$work/##" > "$work/SHA256SUMS"
mkdir -p "$dest"
tar -C "$work" -cf - db.sql media.tgz SHA256SUMS | age -R deploy/backup-recipients.txt > "$dest/chat-$stamp.tar.age"
find "$dest" -name 'chat-*.tar.age' -mtime +14 -delete   # 14 días de retención
echo "respaldo: $dest/chat-$stamp.tar.age"
```

`deploy/restore.sh`:
```sh
#!/bin/sh
# Restaura un respaldo de backup.sh en un entorno con los MISMOS secretos (spec §21.4, RNF-16).
# Uso (desde la raíz del repo):  sh deploy/restore.sh <archivo.tar.age> <identidad-age>
# Después: verificar la cadena de auditoría en el panel (GET /api/admin/audit/verify) y abrir una
# sala con historial: los mensajes deben descifrarse con la KEK restaurada.
set -eu
backup="${1:?uso: restore.sh <archivo.tar.age> <identidad-age>}"
identity="${2:?falta la identidad de age (clave privada)}"
compose="docker compose -f deploy/docker-compose.yml"
work="$(mktemp -d)"
trap 'rm -rf "$work"' EXIT

age -d -i "$identity" "$backup" | tar -C "$work" -xf -
(cd "$work" && sha256sum -c SHA256SUMS)
$compose stop gateway auth rooms chat media audit
$compose up -d db
$compose exec -T db psql -U postgres -v ON_ERROR_STOP=1 -q -f - < "$work/db.sql"
docker run --rm -i -v chat-seguro_media_data:/data alpine:3.20 sh -c 'rm -rf /data/* && tar -C /data -xzf -' < "$work/media.tgz"
$compose up -d
echo "restaurado: verifica la cadena de auditoría y el historial de una sala"
```

Genera el par de claves de `age` **fuera del servidor** (`age-keygen -o respaldo.key`) y guarda en `deploy/backup-recipients.txt` solo la línea de la clave pública (`age1…`). En el VPS, un temporizador diario:
```bash
sudo tee /etc/cron.d/chat-respaldo >/dev/null <<'CRON'
30 3 * * * root cd /srv/chat && sh deploy/backup.sh /var/backups/chat >> /var/log/chat-respaldo.log 2>&1
CRON
```
Simulacro (en un equipo limpio con los mismos `deploy/secrets/`): `sh deploy/restore.sh chat-<fecha>.tar.age respaldo.key`, y mide cuánto tarda.
Expected: restauración en ≤ 1 h; *Verificar cadena* responde íntegra y el historial de una sala se descifra (la KEK restaurada sirve). Pérdida máxima: 24 h.
