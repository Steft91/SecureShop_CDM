# 06 · Servicio `chat` — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Canal de chat por WebSocket con estas propiedades:
- *hello* firmado (ECDSA) + ECDH por conexión → AES-256-GCM con AAD y anti-replay (R7, R14);
- límites de tamaño y de ritmo (R10);
- mensajes y eventos de archivo cifrados en reposo con una DEK por sala envuelta por una KEK rotable (R2);
- historial;
- URLs firmadas por destinatario para los archivos;
- coordinación con `rooms` (fin de sesión, heartbeat, expulsión).

**Architecture:**
- `ws.py` maneja el ciclo de una conexión: validación de identidad y `Origin`, handshake, historial, bucle de tramas y cierre.
- `hub.py` guarda las conexiones vivas en memoria (una réplica) y difunde re-cifrando por destinatario.
- `store.py` persiste con envelope encryption.
- `internal.py` recibe `kick` (de rooms) y archivos publicados (de media).
- `tasks.py` corre cada 30 s: inactividad y heartbeat a `rooms` con reconciliación.

**Tech Stack:** Python 3.13, FastAPI/Starlette WebSocket, cryptography (vía `shared.crypto`), SQLAlchemy async, httpx, pytest (`TestClient` con `with`).

**Spec:** `docs/specs/2026-10-12-chat-seguro-design.md` §7.3, §8.2, §9.3–§9.6, §10, §11.2–§11.3, §16.4 (R2, R7, R10, R11, R14, R16).

## Global Constraints

Las del índice (`2026-10-13-00-indice.md`). En particular:
- Mensaje ≤ 2000 caracteres sin controles salvo `\n`/`\t`.
- Trama ≤ 16384.
- Remitente y sala salen de la identidad del gateway, nunca de la trama.
- `text()` con parámetros nombrados.
- Commits en español, sin atribución.

## Review Focus

Casos del índice que se prueban aquí:
- **#1 Mensajes largos multibyte:** `test_mensaje_largo_multibyte_no_cierra` (CHAT-3).
- **#5 Cierre de pestaña (WS 1001):** `test_cierre_1001_termina_la_sesion` (CHAT-4).

**Nota sobre el `TestClient` de Starlette:** al salir del `with` de un WebSocket, cancela la tarea del servidor. Todo efecto que el servidor produce **después** de un cierre (por ejemplo, avisar a `rooms`) se verifica **dentro** del `with`, con `eventually(...)` o leyendo un evento que el servidor envía después de ese efecto.

`services/chat/chat_svc/hub.py`:
```python
"""Conexiones WebSocket vivas, en memoria (spec §4.6: una sola réplica de chat)."""

import asyncio
import logging
import time
from collections.abc import Callable
from contextlib import suppress
from dataclasses import dataclass, field

from starlette.websockets import WebSocket

from shared.crypto import encrypt_frame
from shared.ratelimit import TokenBucket

log = logging.getLogger("chat.hub")


@dataclass(eq=False)
class Connection:
    ws: WebSocket
    session_id: str
    room_id: str
    alias: str
    mode: str
    key: bytes  # K de esta conexión (solo en memoria)
    ip: str | None
    bucket: TokenBucket
    recv_seq: int = 0
    send_seq: int = 0
    last_activity: float = field(default_factory=time.monotonic)
    lock: asyncio.Lock = field(default_factory=asyncio.Lock)


Payload = dict | Callable[[Connection], dict]


class Hub:
    # ponytail: difusión en memoria de una réplica; para escalar hace falta pub/sub (spec §4.6).
    def __init__(self) -> None:
        self.connections: dict[str, Connection] = {}

    def add(self, conn: Connection) -> Connection | None:
        """Registra la conexión; devuelve la anterior de la misma sesión (a cerrar con 4409)."""
        previous = self.connections.get(conn.session_id)
        self.connections[conn.session_id] = conn
        return previous

    def discard(self, conn: Connection) -> bool:
        """True solo si `conn` seguía siendo la conexión vigente de su sesión."""
        if self.connections.get(conn.session_id) is conn:
            del self.connections[conn.session_id]
            return True
        return False

    def in_room(self, room_id: str) -> list[Connection]:
        return [conn for conn in self.connections.values() if conn.room_id == room_id]

    async def send(self, conn: Connection, payload: dict) -> None:
        async with conn.lock:  # el seq s2c debe salir en orden
            conn.send_seq += 1
            await conn.ws.send_json(
                encrypt_frame(conn.key, conn.room_id, conn.session_id, conn.send_seq, "s2c", payload)
            )

    async def broadcast(self, room_id: str, payload: Payload) -> None:
        """Re-cifra para cada destinatario con SU clave y SU contador."""
        for conn in self.in_room(room_id):
            try:
                await self.send(conn, payload(conn) if callable(payload) else payload)
            except Exception:  # una conexión caída no frena la difusión al resto
                log.info("no se pudo enviar a la sesión %s", conn.session_id)

    async def close(self, session_id: str, code: int) -> Connection | None:
        """Saca la conexión del hub y la cierra; quien llama decide si avisa 'leave'."""
        conn = self.connections.pop(session_id, None)
        if conn is not None:
            with suppress(Exception):
                await conn.ws.close(code)
        return conn
```

```python
"""Servicio chat (spec §9.4)."""

import asyncio
from contextlib import asynccontextmanager, suppress

import httpx
from fastapi import FastAPI
from sqlalchemy.ext.asyncio import AsyncEngine, create_async_engine

from chat_svc import internal, tasks, ws
from chat_svc.config import Settings, load_settings
from chat_svc.hub import Hub
from shared.audit_client import AuditClient
from shared.service_auth import ServiceAuth, ServiceClient
from shared.web import create_base_app


@asynccontextmanager
async def lifespan(app: FastAPI):
    maintenance = asyncio.create_task(tasks.maintenance_loop(app))
    try:
        yield
    finally:
        maintenance.cancel()
        with suppress(asyncio.CancelledError):
            await maintenance


def create_app(
    settings: Settings | None = None,
    *,
    engine: AsyncEngine | None = None,
    service_auth: ServiceAuth | None = None,
    transport: httpx.AsyncBaseTransport | None = None,
) -> FastAPI:
    settings = settings or load_settings()
    service_auth = service_auth or ServiceAuth.from_secrets("chat", needs_token=True)
    peers = ServiceClient(service_auth, {"audit": settings.audit_url, "rooms": settings.rooms_url}, transport)
    app = create_base_app(
        title="chat",
        settings=settings,
        engine=engine or create_async_engine(settings.database_url, pool_pre_ping=True),
        service_auth=service_auth,
        audit=AuditClient(peers),
        lifespan=lifespan,
    )
    app.state.peers = peers
    app.state.hub = Hub()
    for module in (ws, internal):
        app.include_router(module.router)
    return app
```

```python
class Participant:
    """Un navegador de prueba: identidad que pone el gateway + lado cliente del protocolo."""

    def __init__(self, client, alias, room_id=ROOM_A, mode="both", session_id=None):
        self.client, self.alias, self.room_id, self.mode = client, alias, room_id, mode
        self.session_id = session_id or str(uuid4())
        self.key: bytes | None = None
        self.seq = self.recv_seq = 0

    def headers(self, origin: str = testing.ORIGIN) -> dict:
        return {
            **testing.session_headers(self.session_id, self.room_id, self.alias, self.mode),
            "origin": origin,
        }

    def connect(self, origin: str = testing.ORIGIN):
        return self.client.websocket_connect("/ws", headers=self.headers(origin))

    def handshake(self, ws) -> None:
        private = ec.generate_private_key(CURVE)
        pub = b64e(public_bytes(private))
        ws.send_json({"t": "hello", "pub": pub})
        reply = ws.receive_json()
        transcript = hello_transcript(self.room_id, self.session_id, pub, reply["pub"], reply["salt"])
        assert verify_p1363(SIGN_KEY.public_key(), b64d(reply["sig"]), transcript)
        shared = private.exchange(ec.ECDH(), load_public_key(b64d(reply["pub"])))
        self.key = derive_session_key(shared, b64d(reply["salt"]), self.room_id, self.session_id)
        self.seq = self.recv_seq = 0

    def join(self, ws) -> list:
        """Handshake + historial + su propio evento 'join'. Devuelve los ítems del historial."""
        self.handshake(ws)
        history = self.recv_until(ws, "history")["items"]
        self.recv_until(ws, "system", event="join", alias=self.alias)
        return history

    def send(self, ws, payload: dict) -> None:
        self.seq += 1
        ws.send_json(encrypt_frame(self.key, self.room_id, self.session_id, self.seq, "c2s", payload))

    def recv(self, ws) -> dict:
        seq, payload = decrypt_frame(self.key, self.room_id, self.session_id, "s2c", ws.receive_json())
        assert seq > self.recv_seq
        self.recv_seq = seq
        return payload

    def recv_until(self, ws, kind: str, **match) -> dict:
        while True:
            payload = self.recv(ws)
            if payload.get("t") == kind and all(payload.get(k) == v for k, v in match.items()):
                return payload


def closed_with(ws) -> int:
    """Lee tramas hasta que el servidor cierre; devuelve el código de cierre."""
    with pytest.raises(WebSocketDisconnect) as closed:
        while True:
            ws.receive_json()
    return closed.value.code


def eventually(predicate, timeout: float = 3.0) -> bool:
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        if predicate():
            return True
        time.sleep(0.02)
    return predicate()


def end_calls(peers) -> list:
    return [call for call in peers.to("/internal/sessions/") if call.path.endswith("/end")]


def signed_for(url: str, file_id: str, session_id: str) -> bool:
```

```python
"""Persistencia cifrada de mensajes con envelope encryption (spec §7.3, §11.2; riesgo 2)."""

import json

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncConnection

from shared.crypto import dek_aad, encode_payload, msg_aad, new_key, seal, unseal

# Consultas constantes por modo de bloqueo (nunca se arma SQL con datos).
_SELECT_DEK = {
    None: "SELECT dek_wrapped, kek_version FROM room_keys WHERE room_id = :room",
    "share": "SELECT dek_wrapped, kek_version FROM room_keys WHERE room_id = :room FOR SHARE",
    "update": "SELECT dek_wrapped, kek_version FROM room_keys WHERE room_id = :room FOR UPDATE",
}


async def room_dek(
    conn: AsyncConnection, settings, room_id: str, *, create: bool = False, lock: str | None = None
) -> bytes | None:
    """DEK de la sala desenvuelta con la KEK que la protege. `create` la genera si no existe.

    Escribir mensajes toma FOR SHARE y la rotación FOR UPDATE: un mensaje nunca queda cifrado
    con una DEK recién reemplazada.
    """
    row = (await conn.execute(text(_SELECT_DEK[lock]), {"room": room_id})).first()
    if row is None:
        if not create:
            return None
        await conn.execute(
            text(
                "INSERT INTO room_keys (room_id, dek_wrapped, kek_version) VALUES (:room, :wrapped, :version) "
                "ON CONFLICT (room_id) DO NOTHING"
            ),
            {
                "room": room_id,
                "wrapped": seal(settings.kek, new_key(), dek_aad(room_id)),
                "version": settings.current_kek_version,
            },
        )
        row = (await conn.execute(text(_SELECT_DEK[lock]), {"room": room_id})).first()  # pudo ganar otro
    return unseal(settings.keks[row.kek_version], bytes(row.dek_wrapped), dek_aad(room_id))


async def save_message(
    conn: AsyncConnection,
    settings,
    room_id: str,
    session_id: str,
    kind: str,
    data: dict,
    file_id: str | None = None,
) -> int:
    dek = await room_dek(conn, settings, room_id, create=True, lock="share")
    payload = seal(dek, encode_payload(data), msg_aad(room_id, session_id))
    result = await conn.execute(
        text(
            "INSERT INTO messages (room_id, session_id, kind, file_id, payload) "
            "VALUES (:room, :session, :kind, :file, :payload) RETURNING id"
        ),
        {"room": room_id, "session": session_id, "kind": kind, "file": file_id, "payload": payload},
    )
    return result.scalar_one()


async def history(conn: AsyncConnection, settings, room_id: str, limit: int) -> list[dict]:
    dek = await room_dek(conn, settings, room_id)
    if dek is None:
        return []
    rows = (
        await conn.execute(
            text(
                "SELECT id, session_id::text AS session_id, kind, payload FROM messages "
                "WHERE room_id = :room ORDER BY id DESC LIMIT :limit"
            ),
            {"room": room_id, "limit": limit},
        )
    ).all()
    items = []
    for row in reversed(rows):
        data = json.loads(unseal(dek, bytes(row.payload), msg_aad(room_id, row.session_id)))
        items.append({"id": row.id, "kind": row.kind, **data})
    return items


async def file_in_room(conn: AsyncConnection, file_id: str, room_id: str) -> bool:
    result = await conn.execute(
        text("SELECT 1 FROM messages WHERE file_id = :file AND room_id = :room LIMIT 1"),
        {"file": file_id, "room": room_id},
    )
    return result.first() is not None
```

```python
"""Rotación de claves del chat (spec §11.3).

  python -m chat_svc.rotate kek              re-envuelve todas las DEK con la KEK vigente
  python -m chat_svc.rotate room <room_id>   DEK nueva para una sala y re-cifrado de sus mensajes
"""

import argparse
import asyncio

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine, create_async_engine

from chat_svc import store
from chat_svc.config import load_settings
from shared.audit_client import AuditClient
from shared.crypto import dek_aad, msg_aad, new_key, seal, unseal
from shared.service_auth import ServiceAuth, ServiceClient


async def rotate_kek(engine: AsyncEngine, settings, audit) -> int:
    target = settings.current_kek_version
    async with engine.begin() as conn:
        rows = (
            await conn.execute(
                text(
                    "SELECT room_id::text AS room_id, dek_wrapped, kek_version FROM room_keys "
                    "WHERE kek_version <> :v FOR UPDATE"
                ),
                {"v": target},
            )
        ).all()
        for row in rows:
            aad = dek_aad(row.room_id)
            dek = unseal(settings.keks[row.kek_version], bytes(row.dek_wrapped), aad)
            await conn.execute(
                text("UPDATE room_keys SET dek_wrapped = :wrapped, kek_version = :v WHERE room_id = :room"),
                {"wrapped": seal(settings.kek, dek, aad), "v": target, "room": row.room_id},
            )
        if rows:
            await audit.emit(
                "info", "key.rotate.chat", actor="system",
                details={"kind": "kek", "to": target, "rooms": len(rows)}, required=True,
            )
    return len(rows)


async def rotate_room(engine: AsyncEngine, settings, audit, room_id: str) -> int:
    async with engine.begin() as conn:
        old = await store.room_dek(conn, settings, room_id, lock="update")
        if old is None:
            raise ValueError("la sala no tiene mensajes")
        new = new_key()
        rows = (
            await conn.execute(
                text(
                    "SELECT id, session_id::text AS session_id, payload FROM messages "
                    "WHERE room_id = :room FOR UPDATE"
                ),
                {"room": room_id},
            )
        ).all()
        for row in rows:
            aad = msg_aad(room_id, row.session_id)
            await conn.execute(
                text("UPDATE messages SET payload = :payload WHERE id = :id"),
                {"payload": seal(new, unseal(old, bytes(row.payload), aad), aad), "id": row.id},
            )
        await conn.execute(
            text("UPDATE room_keys SET dek_wrapped = :wrapped, kek_version = :v WHERE room_id = :room"),
            {
                "wrapped": seal(settings.kek, new, dek_aad(room_id)),
                "v": settings.current_kek_version,
                "room": room_id,
            },
        )
        await audit.emit(
            "info", "key.rotate.chat", actor="system",
            details={"kind": "room", "room_id": room_id, "messages": len(rows)}, required=True,
        )
    return len(rows)


async def _main(args: argparse.Namespace) -> int:
    settings = load_settings()
    engine = create_async_engine(settings.database_url)
    peers = ServiceClient(ServiceAuth.from_secrets("chat", needs_token=True), {"audit": settings.audit_url})
    try:
        if args.what == "kek":
            return await rotate_kek(engine, settings, AuditClient(peers))
        return await rotate_room(engine, settings, AuditClient(peers), args.room_id)
    finally:
        await engine.dispose()


def main() -> None:
    parser = argparse.ArgumentParser(description="Rotación de claves del chat")
    sub = parser.add_subparsers(dest="what", required=True)
    sub.add_parser("kek")
    room = sub.add_parser("room")
    room.add_argument("room_id")
    count = asyncio.run(_main(parser.parse_args()))
    print(f"listo: {count} elementos re-cifrados")


if __name__ == "__main__":
    main()
```

```python
class HandshakeError(Exception):

def file_url(settings, file_id: str, session_id: str) -> str:
    """URL firmada para UN destinatario (spec §9.6)."""
    exp = int(time.time()) + settings.signed_url_ttl_s
    sig = sign_url(settings.url_signing_key, file_id, session_id, exp)
    return f"/api/media/files/{file_id}?exp={exp}&sig={sig}"


def leave_event(conn: Connection) -> dict:
    return {"t": "system", "event": "leave", "alias": conn.alias}


def valid_body(body) -> bool:
    return (
        isinstance(body, str)
        and 0 < len(body) <= 2000
        and body.strip() != ""
        and all(c in "\n\t" or unicodedata.category(c) not in ("Cc", "Cs") for c in body)
    )


async def end_in_rooms(app, session_id: str, reason: str) -> None:
    try:
        await app.state.peers.post("rooms", f"/internal/sessions/{session_id}/end", json={"reason": reason})
    except httpx.HTTPError:
        log.warning("rooms no respondió al fin de %s; la barrerá tras el período de gracia", session_id)


async def reject(app, ws: WebSocket, who: SessionIdentity | None, ip, code: int, action: str, details=None) -> None:
    actor = f"session:{who.session_id}" if who else f"ip:{ip}"
    await app.state.audit.emit("warning", action, actor=actor, ip=ip, details={"close": code, **(details or {})})
    with suppress(Exception):
        await ws.close(code)


async def violation(app, conn: Connection, code: int, action: str, severity="warning", details=None) -> int:
    await app.state.audit.emit(
        severity, action, actor=f"session:{conn.session_id}", ip=conn.ip,
        details={"close": code, **(details or {})},
    )
    return code


async def handshake(app, ws: WebSocket, who: SessionIdentity, ip) -> Connection:
    settings = app.state.settings
    try:
        message = await asyncio.wait_for(ws.receive(), settings.handshake_timeout_s)
    except TimeoutError:
        raise HandshakeError("sin hello a tiempo") from None
    raw = message.get("text") if message["type"] == "websocket.receive" else None
    if not raw or len(raw) > MAX_HELLO:
        raise HandshakeError("sin hello")
    try:
        hello = json.loads(raw)
        if not isinstance(hello, dict) or hello.get("t") != "hello" or not isinstance(hello.get("pub"), str):
            raise ValueError("hello malformado")
        result = server_hello(hello["pub"], who.room_id, who.session_id, settings.sign_key)
    except ValueError as exc:
        raise HandshakeError(str(exc)) from None
    await ws.send_json(result.reply)
    return Connection(
        ws=ws,
        session_id=who.session_id,
        room_id=who.room_id,
        alias=who.alias,
        mode=who.mode,
        key=result.key,
        ip=ip,
        bucket=TokenBucket(settings.ws_rate_per_s, settings.ws_burst),
    )


async def send_history(app, conn: Connection) -> None:
    settings = app.state.settings
    async with app.state.engine.connect() as db:
        rows = await store.history(db, settings, conn.room_id, settings.history_size)
    items = [
        {"t": "msg", "id": r["id"], "from": r["from"], "body": r["body"], "ts": r["ts"]}
        if r["kind"] == "text"
        else {
            "t": "file",
            "id": r["file_id"],
            "from": r["from"],
            "url": file_url(settings, r["file_id"], conn.session_id),
            "ts": r["ts"],
        }
        for r in rows
    ]
    await app.state.hub.send(conn, {"t": "history", "items": items})


async def on_text(app, conn: Connection, payload: dict) -> int | None:
    if conn.mode not in ("text", "both"):
        return await violation(app, conn, 4403, "ws.reject.forbidden")
    body = payload.get("body")
    if not valid_body(body):
        return await violation(app, conn, 4400, "ws.reject.malformed")
    ts = datetime.now(UTC).isoformat()
    async with app.state.engine.begin() as db:
        message_id = await store.save_message(
            db, app.state.settings, conn.room_id, conn.session_id, "text",
            {"from": conn.alias, "body": body, "ts": ts},
        )
    conn.last_activity = time.monotonic()
    # R14: el remitente es el alias de la sesión; cualquier "from" de la trama se ignora.
    await app.state.hub.broadcast(
        conn.room_id, {"t": "msg", "id": message_id, "from": conn.alias, "body": body, "ts": ts}
    )
    return None


async def on_file_url(app, conn: Connection, payload: dict) -> int | None:
    try:
        file_id = str(UUID(str(payload.get("file_id"))))
    except ValueError:
        return await violation(app, conn, 4400, "ws.reject.malformed")
    async with app.state.engine.connect() as db:
        allowed = await store.file_in_room(db, file_id, conn.room_id)
    if not allowed:
        return await violation(app, conn, 4403, "ws.reject.forbidden", details={"file_id": file_id})
    url = file_url(app.state.settings, file_id, conn.session_id)
    await app.state.hub.send(conn, {"t": "file_url", "file_id": file_id, "url": url})
    return None


async def handle_frame(app, conn: Connection, raw: str | None) -> int | None:
    """Devuelve un código de cierre si la trama viola el protocolo; None si se procesó."""
    settings = app.state.settings
    if raw is None:
        return await violation(app, conn, 4400, "ws.reject.malformed")
    if len(raw) > settings.ws_max_frame:
        return await violation(app, conn, 4413, "ws.reject.size")
    if not conn.bucket.allow():
        return await violation(app, conn, 4429, "ws.reject.rate")
    try:
        frame = json.loads(raw)
        if not isinstance(frame, dict):
            raise ValueError("la trama no es un objeto")
        seq = frame.get("seq")
        if type(seq) is int and seq <= conn.recv_seq:
            return await violation(app, conn, 4408, "ws.reject.replay")
        seq, payload = decrypt_frame(conn.key, conn.room_id, conn.session_id, "c2s", frame)
    except InvalidTag:
        return await violation(app, conn, 4400, "ws.tamper", severity="critical")
    except (ValueError, RecursionError):
        return await violation(app, conn, 4400, "ws.reject.malformed")
    conn.recv_seq = seq
    kind = payload.get("t")
    if kind == "msg":
        return await on_text(app, conn, payload)
    if kind == "file_url":
        return await on_file_url(app, conn, payload)
    return await violation(app, conn, 4400, "ws.reject.malformed")


async def receive_loop(app, conn: Connection) -> str:
    """'closed' (cierre limpio del cliente), 'dropped' (caída) o 'violation' (cerró el servidor)."""
    while True:
        message = await conn.ws.receive()
        if message["type"] == "websocket.disconnect":
            return "closed" if message.get("code", 1000) in CLEAN_CLOSE else "dropped"
        code = await handle_frame(app, conn, message.get("text"))
        if code is not None:
            with suppress(Exception):
                await conn.ws.close(code)
            return "violation"


@router.websocket("/ws")
async def chat_socket(ws: WebSocket) -> None:
    app = ws.app
    settings, hub, ip = app.state.settings, app.state.hub, client_ip(ws)
    await ws.accept()
    if ws.state.caller != "gateway":  # R16: solo el gateway abre conexiones de usuario
        await app.state.audit.emit(
            "warning", "svc.reject.token", actor=f"svc:{ws.state.caller}", target="/ws", ip=ip
        )
        await ws.close(4403)
        return
    who = session_from_headers(ws)
    if who is None:
        await reject(app, ws, None, ip, 4400, "ws.reject.handshake", {"motivo": "sin identidad"})
        return
    origin = ws.headers.get("origin")
    if origin not in settings.allowed_origins:
        await reject(app, ws, who, ip, 4403, "ws.reject.origin", {"origin": origin})
        return
    try:
        conn = await handshake(app, ws, who, ip)
    except HandshakeError as exc:
        await reject(app, ws, who, ip, 4400, "ws.reject.handshake", {"motivo": str(exc)})
        return
    previous = hub.add(conn)
    if previous is not None:
        with suppress(Exception):
            await previous.ws.close(4409)
    reason = "dropped"
    try:
        await send_history(app, conn)
        await hub.broadcast(conn.room_id, {"t": "system", "event": "join", "alias": conn.alias})
        reason = await receive_loop(app, conn)
    finally:
        if hub.discard(conn):  # si otra conexión la reemplazó o rooms la expulsó, no hay nada que hacer
            if reason in ("closed", "violation"):
                await end_in_rooms(app, conn.session_id, reason)
            await hub.broadcast(conn.room_id, leave_event(conn))
```

```python
class KickIn(BaseModel):

class FileEventIn(BaseModel):
    file_id: UUID
    session_id: UUID
```

```python
"""Mantenimiento periódico: inactividad y heartbeat de reconciliación con rooms (spec §9.3–§9.4)."""

import asyncio
import logging
import time

import httpx

from chat_svc.ws import end_in_rooms, leave_event

log = logging.getLogger("chat.tasks")


async def maintenance(app) -> None:
    settings, hub = app.state.settings, app.state.hub
    now = time.monotonic()
    for conn in list(hub.connections.values()):
        if now - conn.last_activity > settings.idle_min * 60:
            if await hub.close(conn.session_id, 4410) is not None:
                await end_in_rooms(app, conn.session_id, "idle")
                await hub.broadcast(conn.room_id, leave_event(conn))
    session_ids = list(hub.connections)
    if not session_ids:
        return
    try:
        response = await app.state.peers.post(
            "rooms", "/internal/sessions/heartbeat", json={"session_ids": session_ids}
        )
    except httpx.HTTPError:
        log.warning("heartbeat a rooms falló; se reintenta en el próximo ciclo")
        return
    if response.status_code != 200:
        return
    for session_id in response.json().get("ended", []):  # rooms ya las terminó: reconciliar
        conn = await hub.close(session_id, 4401)
        if conn is not None:
            await hub.broadcast(conn.room_id, leave_event(conn))


async def maintenance_loop(app) -> None:
    while True:
        await asyncio.sleep(app.state.settings.heartbeat_interval_s)
        try:
            await maintenance(app)
        except Exception:
            log.exception("falló el ciclo de mantenimiento del chat")
```
